## 封面风格：白底大字高亮（新增 `covers-highlight.html`）

- **命名**：小红书「大字报封面 / 高亮标题封面」。设计谱系 = Swiss 排版骨架（无衬线·居中·留白）+ 荧光笔高亮（色块垫字）+ 手绘 Zine 插画。
- **六层语法**：①纯白底无边框无阴影 ②主标超大无衬线居中、行距 1.1 ③**高亮块垫底但字仍是黑色**（唯一语法底线，改白字就变按钮）④副标与主标落差 ≥2.5:1 ⑤手绘波浪线全图仅 1 处 ⑥底部插画约 1/3 高，不承载主信息。
- **产品化参数**：卡片 1080×1440（3:4）；主标 116px/800、副标 64px/500、padding 96×84；高亮色板 紫#D96FE0 / 黄#FFD84D / 绿#9FE0A0 / 蓝#8FD0FF / 粉#FFA0C4 / 橙#FFC078；**一条封面只用一种高亮色、只高亮一行**。
- **导出方式**：`.card{zoom:.3}` → 改成 `zoom:1` 后逐张截图（文件内已写明）。
- **三套语言的分工**（不要混）：新粗野=产品 UI(ADR-0044 2px 墨黑)；新孟菲斯=`covers-neo-memphis.html`（轻快但信息密度低、缩略图会糊）；**白底大字高亮更适合本账号** —— 内容要被"搜到并一眼看懂"，不是被欣赏。
- **关键判断**：此风格适用**封面**（情绪钩子拉点击率），成果线 A / 方法线 B 直接用；评审线 C 封面可同用，但**内页必须换清单/表格**（C 线目标是收藏不是点击）。

## 内容方向再修正：叙事线（「我和搭档一起做」）

用户要求内容围绕**原因 → 经过 → 结果 → 那个瞬间**，要有愉快的过程和做成的喜悦，**感染人而非生硬介绍**。产出 `docs/marketing/story-notes.md`（S1–S5 五篇完整正文），封面已加进 `covers-highlight.html`（叙事线 S1–S5 一组）。

- **叙事 vs 介绍**：介绍=读者是旁观者（会评估防备）；叙事=读者是见证者（会代入共情）。要别人咨询，本质是让人相信「你能做成事」—— 结果只能证明结果，**过程才能证明可靠**。
- **「我们」优于「我」的三个理由**：①自动消解人设三选一（一线教师/构建者/双重）—— 两人合起来才是完整角色；②天然有戏剧性（对话、分歧、互相补位）；③有第二人背书，可信度更高。**此前的人设分叉问题就此自然解决。**
- **情绪曲线**：S1 起因(平) → S2 转机(起) → S3 把关(轻微回落) → S4 结果(最高点但克制) → S5 余韵(温暖收尾)。
