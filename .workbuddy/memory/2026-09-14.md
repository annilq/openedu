## token 过期 → 自动跳登录页（403 根因修复）

- 根因：`backend/app/core/errors.py` 把 `AUTH_INVALID_TOKEN`（JWT 过期/失效）映射成 **403**，而前端 `dio_network_service.dart` 只对 **401** 抛 `UnauthorizedException`、对 403 走通用 HttpException → 用户只看到"凭证校验失败，请重新登录"却无任何跳转。
- 后端：`AUTH_INVALID_TOKEN` 状态码 403 → **401**（语义正确：失效 token=未认证，与缺 token 的 UNAUTHORIZED 一致）。真实越权（TASK_NOT_OWNED/AUTH_PARENT_ONLY 等）保持 403，绝不因此误踢已登录用户。
- 前端：新增 `auth_guard_provider.dart`（`authExpiredProvider` StateNotifier 计数信号）；`DioNetworkService` 构造注入 `onUnauthorized` 回调，401 时触发；`core_providers` 把 `authExpiredProvider.notifier.signal` 注入；`MyApp` `ref.listen` 该信号 → `_onAuthExpired()` 清登录态回登录页（`_logout` 复用），带 `_authExpiredHandled` 防重入、登录成功后重置。
- 校验：后端 ruff 通过；前端 `flutter analyze` 四文件无 issue；全量 grep 确认无测试断言 `AUTH_INVALID_TOKEN==403`。pytest 受沙箱 SIGTERM 未跑（项目已知 sandbox 限制 + .env broker 拦截）。
- 待用户真机验证：过期 token 触发后是否自动回登录页。
