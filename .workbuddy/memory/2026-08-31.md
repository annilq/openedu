## 修复：MasteryBoard 空状态/掌握度条在窄卡内溢出
- 现象：`mastery_board.dart:32` 的 `Row` 在约束宽 ~68px 时右侧溢出 4px（=52 图标+20 间距−68）。
- 根因：`AppCard` 是 `ShadCard` 套 `Container(margin)`；`ShadCard` 内部把 child 包进 `Row(mainAxisSize:min)+Flexible+Column+Flexible+Row`，卡片会收缩到内容宽度。当上层把这张卡压到 ~132px 时，空状态那行固定「52 图标 + AppSpacing.xl(20) 间距」的最小固有宽 72 > 68 → 溢出。
- 修复（`mastery_board.dart`）：① 空状态改用 `LayoutBuilder`，`maxWidth<220` 时图标与文案纵向堆叠（文案居中）；② `_MasteryBar` 表头改用 `LayoutBuilder`，`maxWidth<300` 时分数+等级徽章换到第二行，避免固定尾列溢出。两端均 `flutter analyze` 零警告。
- 可复用经验：本项目所有 `AppCard`/`ShadCard` 内容里**不要写依赖固定横向宽度的 Row**；凡含固定宽图标/徽章/分数的行，统一用 `LayoutBuilder` 断点改纵向，或把可变文字用 `Expanded` 包住。

## 修正：Genkit 栈兼容性论断错误
- 用户指正：Genkit 有 Python 版，可经 `genkit-fastapi` 在 FastAPI 进程内挂 flow（无 Node 依赖）。已查官方文档确认：`genkit`+`genkit-fastapi`→`serve_flow` 返回 APIRouter；`Accept: text/event-stream` 即 SSE；`chunk_type` 支持字段级结构化流式。
- 之前在 grill 中把「Genkit 需 Node/TS 服务、与 Python/FastAPI 栈冲突」当成否决理由是**错误**的（那是看 Flutter 端 `genkit/client.dart` 想当然而来）。已修正 ADR-0015「背景」与「备选」两处，并把 Genkit 从「否决」改为「栈兼容的未来候选」；术语表补 Genkit 词条。
- 注意：错误理由被移除后，Genkit 与 v1 方案（LangChainProvider 扩展 + 轻量 SSE）的真正取舍只剩「是否引入第二套 AI 框架（违背 ADR-003 单 Provider 抽象）」；Genkit 的 `chunk_type` 字段级结构化流式对「出题逐张题卡」其实比手搓 LangChain chunk 更顺手。是否改用 Genkit 待用户定。

## 修复：ADR-0015 后端流式链路 6 个测试失败（全绿：119 passed / 1 skipped，ruff clean）
- 背景：v1 改用 Genkit Python 编排流式 flow 后，新增 `app/ai/engine.py`/`flows.py`、`/models`、`/stream` 路由与 5 个测试文件，初跑 6 failed。
- 根因与修复：
  1. **`Ollama` 构造签名**：`genkit_ollama` 的 `Ollama.__init__` 用 `server_address=`（不是 `base_url`）→ `engine._get_or_build` 改 `Ollama(server_address=...)`；`OpenAI(**openai_params)` 透传 kwargs（api_key/base_url 不变）。
  2. **`resolve_engine` 对内置 id 崩溃**：内置模型 id（如 "local-llama"）非 UUID，直接 `session.get(ModelConfig, model_ref)` 触发 UUID 类型 `.hex` 处理器报错 → 新增 `_as_uuid()` 守卫，仅合法 UUID 才查 `ModelConfig` 表，否则走内置/全局分支。
  3. **路由顺序坑**：`/models/{model_id}`（PUT/DELETE）注册在 `/models/default` 之前，导致 `PUT /models/default` 被捕获为 `model_id="default"`→422，且 `GET /models/{uuid}` 无 GET handler→405。修复=把 `/default`(GET+PUT) 提到 `/{model_id}`(GET+PUT+DELETE) 之前，并补 `GET /models/{model_id}`（越权/不存在→404）。
  4. **测试传字符串 id 给 `db.get`**：JSON 返回的 `id` 是字符串，`db.get(ModelConfig, str)` 触发 UUID `.hex` 报错 → 测试里 `uuid.UUID(mid)` 包裹。
  5. **mock 出题回退忽略 `count`**：`stream.tasks_generate_stream` 每 spec 只生成 1 题 → 改为 `for _ in range(sp.count)` 逐题 yield，对齐 `generate_questions_stream`。
  6. **conftest 清理漏 `ModelConfig`**：session 级 `db` fixture 的 delete 列表补 `ModelConfig`，避免跨测试残留。
- 复用经验：① Genkit Python 各插件构造签名需查 `site-packages` 源码（Ollama=server_address，OpenAI=透传）；② FastAPI 动态 `/{id}` 路由务必排在字面兄弟路由（如 `/default`）之后；③ `uuid.UUID` 主键列，凡从 JSON 拿到的 id 字符串都要 `uuid.UUID()` 转回再 `db.get`，否则 `.hex` 炸。
