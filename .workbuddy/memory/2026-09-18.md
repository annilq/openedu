## 分析过程确认的架构事实（供后续引用）
- 路由优先级即功能：`guide` 20 > `query` 12 > `question` 0 > `tutor` -10；改 priority = 改功能。
- 全链路：router(HTTP) → service(编排+落库) → runtime(decide/run) → subagent → provider → adapters/genkit；只 query 跑 tool loop，question 走 schema 约束解码，tutor 单调用，guide 不调模型。
- 三类硬失败：TOOL_UNSUPPORTED / PROVIDER_ERROR / TOOL_TURN_LIMIT；`classify_failure` 是唯一归因点，批改旁路 `grade_open` 也复用。
