# 2026-09-21

## 分析：家长端「个人信息页被任务详情遮挡」（只诊断未改码）

- 根因：`home_screen.dart` 的覆盖层清理不对称。`_parentTap()`（侧栏）显式清 `_reviewingTask`/`_editingChild`，
  `_onProfileTap()`（底部「我的」/ `AdaptiveUserBlock`）只置 `_showProfile = true`，**不清覆盖层**。
- 链路：任务卡 → `_navigateToReview` → `_reviewingTask ≠ null` → `_buildParentDetail()` 返回审核页 →
  `AdaptiveShell._singleColumn = widget.detail ?? widget.body`，中屏/紧凑档 detail **整幅顶替 body**，
  `_buildParentPage()` 里的 `ProfileScreen` 压根没进树（不是被盖，是没渲染）。大屏 ≥1200 是 5:8 双栏，表现不同。
- 同病三处（都绕过 `_parentTap` 就没清层）：`_onProfileTap`(117) / `_onNavigateToAddChild`(124，清了 editing 没清 reviewing) /
  `_onNavigateToEditChild`(146，`_buildParentDetail` 优先级 review > edit → 审核中编辑娃娃资料被吞)。
- 附带：进个人信息时 `_parentNavIndex` 未复位 → 侧栏「任务」与「我的」同时高亮。
- 修法方向：把「清覆盖层」收口成一个 `_clearOverlays()`（或让所有导航入口统一走 `_parentTap`），
  profile 视作一个伪索引而不是与 `_parentNavIndex` 并列的布尔。

## 修复：复习页「返回」→ 白屏 + 热重启报 `_history.isNotEmpty`（3 commit）

- **根因**：`ReviewScreen` 在娃娃端是 `IndexedStack` 页签、**不是 push 路由**，页内两处
  `Navigator.of(context).pop()`（空态「返回」/ 完成卡「返回首页」）弹的是**根导航栈最后一条路由（整个 App）**。
  弹空后界面全白但**不立即报错**（没人再触发 Navigator 重建），按 R 热重启触发 reassembly 才炸
  `NavigatorState.build: assert(_history.isNotEmpty)`（navigator.dart:5950）。
- **判据**：`NavigatorState.build` 断言 `_history.isNotEmpty` + «MediaQuery 是 error-causing widget»
  （`main/app.dart:155` 包在 `CupertinoApp.builder` 里）＝ 根 Navigator 被弹空，**别去查 MediaQuery**。
- **修法**：出口回调注入（`ReviewScreen.onExit` / `ReviewEmptyView.onBack`），home 翻成 `_switchChildTab(0)`；
  未注入时退 `Navigator.maybePop`（根栈只剩一条路由时 `canPop=false` → no-op，与 `AppTopBar`/`AppPushedPage` 同口径）。
- **同批两处遗留**：① `_done` 永久为真（页签常驻不重建 → 复习完一次后新到期题再也进不来），
  判据用 `DueReviewLoading`（`answer()` 直接给 `DueReviewLoaded`，不经 Loading，故不会误清完成卡）；
  ② 顶栏 trailing 塞「打印图标 + 题号 chip」溢出 40px 槽位 32px（右缘外被裁）→ 计数并入标题「复习 1/3」。
- **守卫**：新增 `test/tab_screen_no_root_pop_test.dart`（静态扫壳内页签文件禁裸 `pop`）+
  `test/review_tab_exit_test.dart`（把页面放进「只挂一条路由」的 MaterialApp，点返回后断言占位内容还在——
  只断言按钮存在测不出「pop 弹错栈」）。
- ⚠️ **通用纪律**：任何「非 push 路由」的页面（壳页签 / 覆盖层）都**不得**直接 `Navigator.pop`，
  只能 `maybePop` 或走注入回调；`flutter analyze` 完全照不出来。
