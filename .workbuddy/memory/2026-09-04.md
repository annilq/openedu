## 娃娃端 Tab 切换不刷新的根因与修复
- 问题：娃娃端做完题切回「错题本/掌握度」页面数据为空且不刷新，大部分页面都有此现象。
- 根因：`_buildChildView` 把 5 个娃娃页全部塞进同一个 `IndexedStack` 常驻挂载，每个页的
  `initState`(内含 `load()`) 只在 App 启动那一刻跑一次（此时还没做题→空快照）；切 Tab 只翻转
  `_childNavIndex` 不重跑 initState。且 `_navigateToPractice` 的 `onDone` 只刷新 `todayTasks`，
  漏刷 `childWrongQuestions`/`mastery`/`dueReview`。
- 修复（`home_screen.dart`）：
  - 新增 `_switchChildTab(index)` 替换 `_onChildNavTap`：切 Tab 时按索引派发对应 provider 的
    `load()`（`_refreshChildTab`）；已在当前页则跳过避免重复加载。首页/复习/错题本/掌握度/AI伴学分别映射。
  - `practice` 的 `onDone` 补刷 `todayTasks/dueReview/childWrongQuestions/mastery`，覆盖"做题 pop 回首页"
    这条没有 Tab 切换事件的路径。
  - 首页内的"去复习/错题本/AI伴学"按钮回调也改用 `_switchChildTab`。
- 决策：不引入全局事件总线，沿用「每页 provider + 进页面 load()」架构，最小侵入。
- 验证：`flutter analyze home_screen.dart` 无 issue。注意 `flutter analyze` 全量仍有 13 个
  pre-existing 错误（test mock 的 `NetworkService.delete` 签名缺可选 body 参数等），与本次无关，未动。

  - 相似度 = 归一化文本 → 字符 4-gram → Jaccard 重叠；阈值默认 0.5；命中即退出码 1 阻断。
  - 入参：`--db`(questions 表: knowledge_point/stem/answer/explanation) / `--json`(内容列表) / `--protected`(语料文件或目录) / `--threshold` / `--report` / `--skip-if-no-corpus` / `--self-test`。

## 清零 flutter analyze 全量错误（已完成）
- 原 12 个 analyze 问题（用户称 13，实为 12=11 error+1 info）根因两类：
  1. **`NetworkService.delete` 签名变更**：`Future<dynamic> delete(String)` → `delete(String, {Map<String, dynamic>? body})`（network_service.dart:10）。6 个测试 mock（`_SilentNetwork`/`_NoopNetwork`/`FakeNetwork`×2/`_ThrowingNetwork`/`_BusinessErrorNetwork`/`FakePutNetwork`）未同步，override 报错。改法：给 mock 的 `delete` 加可选命名参数 `body`。涉及 `children_notifier_test`/`genkit_client_test`/`review_notifier_test`/`tutor_notifier_test`(4 处)。
  2. **`genkit_client_test._FakeGenkit` 用错 `ActionStream` 构造**：genkit 0.15.1 的 `ActionStream<Chunk,Response>` 构造签名为 `ActionStream(super.stream)`（仅收一个 `Stream<Chunk>` 位置参数），末帧 `Response` 经公共方法 `setResult()` 在流结束后注入；原测试错传 `(Future.result, Stream)` 两位置参数。改法：用 `StreamController` + `Stream.fromIterable(chunks).listen(controller.add, onDone: () { stream.setResult(result); controller.close(); })`，与真实 `defineRemoteAction().stream()` 行为一致；`onResult` 为懒创建 completer。同时移除多余的 `package:mocktail/mocktail.dart` import（flutter_test 已导出 `Fake`，unnecessary_import）。
- 验证：`flutter analyze` → **No issues found!**（前端质量门禁清零，满足 ADR-0020 CI 前置）。
- ⚠️ 测试运行未能在本沙箱验证：`flutter test` 报 "Unable to connect to flutter_tester: WebSocketException: Invalid WebSocket upgrade request" —— 属 flutter_tester 无法启动的环境限制（无测试设备后端），非代码问题。需在真机/模拟器/桌面端补跑 `flutter test` 确认 `_FakeGenkit` 运行时行为。
