## 娃娃端 Tab 切换不刷新的根因与修复
- 问题：娃娃端做完题切回「错题本/掌握度」页面数据为空且不刷新，大部分页面都有此现象。
- 根因：`_buildChildView` 把 5 个娃娃页全部塞进同一个 `IndexedStack` 常驻挂载，每个页的
  `initState`(内含 `load()`) 只在 App 启动那一刻跑一次（此时还没做题→空快照）；切 Tab 只翻转
  `_childNavIndex` 不重跑 initState。且 `_navigateToPractice` 的 `onDone` 只刷新 `todayTasks`，
  漏刷 `childWrongQuestions`/`mastery`/`dueReview`。
- 修复（`home_screen.dart`）：
  - 新增 `_switchChildTab(index)` 替换 `_onChildNavTap`：切 Tab 时按索引派发对应 provider 的
    `load()`（`_refreshChildTab`）；已在当前页则跳过避免重复加载。首页/复习/错题本/掌握度/AI伴学分别映射。
  - `practice` 的 `onDone` 补刷 `todayTasks/dueReview/childWrongQuestions/mastery`，覆盖"做题 pop 回首页"
    这条没有 Tab 切换事件的路径。
  - 首页内的"去复习/错题本/AI伴学"按钮回调也改用 `_switchChildTab`。
- 决策：不引入全局事件总线，沿用「每页 provider + 进页面 load()」架构，最小侵入。
- 验证：`flutter analyze home_screen.dart` 无 issue。注意 `flutter analyze` 全量仍有 13 个
  pre-existing 错误（test mock 的 `NetworkService.delete` 签名缺可选 body 参数等），与本次无关，未动。
