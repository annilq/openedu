- **新建 `frontend/scripts/patch_voice_permissions.py`**：幂等补齐三端语音权限——iOS/macOS Info.plist 的 `NSMicrophoneUsageDescription` + `NSSpeechRecognitionUsageDescription`、macOS entitlements 的 `com.apple.security.device.audio-input`、Android manifest 的 `RECORD_AUDIO`。
- ⚠️ **macOS `com.apple.security.device.audio-input` 是硬需求**：本项目 `app-sandbox=true`，沙盒下缺该项麦克风被系统直接拒且**不抛错**（两个 entitlements 文件都要补）。
- **`--check` 模式**（只检查不写入、缺则退 1）是给 CI 用的：原生权限缺失是**静默失效**（门禁判 `unsupported` → 麦按钮不渲染 → 界面零异常），只有 --check 能把它变成会失败的检查。
- **Android 插入位置**：`uses-permission` 必须是 `<manifest>` 的**直接子元素**、在 `<application>` 之外（放进 application 不生效）。正则匹配 `<manifest[^>]*>` 开标签行后插入，改完用 `ElementTree` 回验。
- **实测**：`--check` 识别 7 项缺失退 1 → 补齐 → 二次运行 7 项全 `[ok]`、`--check` 退 0。manifest XML 合法、子元素顺序 `uses-permission, application, queries` ✅。

## ⚠️⭐ 更正上一条：insteadOf 对 SwiftPM **无效**；真正解法是 SwiftPM mirror（已实测通过）
- **为什么「配了 gitconfig 还是报同样的错」**：`url.<x>.insteadOf` 是 **git 命令行**的特性，SwiftPM 走 **libgit2**，而 libgit2 **不实现 insteadOf** → 它照旧直连 github。上一轮「`git ls-remote` 0.011s 命中 ⇒ 预期对 SwiftPM 生效」是错误推断：那个验证只证明命令行生效。
- **第二根暗桩（不解决就换汤不换药）**：全局 gitconfig 的 `safe.bareRepository = explicit` 会让 libgit2 拒绝打开 SwiftPM 的**裸**缓存仓库 → `fatal: cannot use bare repository '…' (safe.bareRepository is 'explicit')`，症状与「Couldn't get the list of tags」完全相同，但根因已在本地。已 unset（回到 git 默认 `all`）。
- **解法（本机实测通过）**：SwiftPM 官方 mirror，把远程 URL 映射到本机 bare 仓库
  - 落点三处：全局 `~/.swiftpm/configuration/mirrors.json`；工程级 `macos/Runner.xcworkspace/xcshareddata/swiftpm/configuration/mirrors.json` 与 `macos/Runner.xcodeproj/project.xcworkspace/…/mirrors.json`（两个 workspace 都写，省得猜 xcodebuild 用哪个）。
  - ⚠️ **schema 以 `swift package config set-mirror` 的实际输出为准**：`{"version":1,"object":[{"mirror":…,"original":…}]}`。网上老资料的 `{"object":{"mirrors":[…]}}` 直接崩 `DecodingError.typeMismatch: expected Array<Any> … Path: object`（实测踩到）。别凭记忆写，跑一次官方命令看输出。
  - 实测：清空 `.build` 且只留全局配置，`swift package resolve --disable-sandbox` → `Fetching file:///Users/annilq/.openedu-deps/CwlCatchException.git` → `resolved at 2.2.1`（revision `07b2ba21…`，与官方 tag 一致），约 2s，零网络。
