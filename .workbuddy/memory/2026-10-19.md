## 23:10 用户报告「IAAI 对话不返回知识点场景、只显示描述」根因（只读排查）

- **主因是路由不是渲染**：DB 实证（`backend/app.db` 会话 `225f4373...`）三条消息全部 `routing=伴学答疑`、`tool=tutor_explain`，题卡 0 张落库（payload 仅 `rag_sources`），AI 以纯文本讲解作答并引用 RAG 教材原文（四年级下册.pdf）。
- **机制**：`出道` 是触发词但 `出一道` 不含它（子串不覆盖）；`出一道/出一道题/来一道/出一题` 规则与启发式全落空 → 兜底给 `priority=-10`、`hints=[]` 的 tutor（manifest 注释明示这是设计兜底）。真实 `classify()` 实测：上述短语 → tutor(fallback)；`帮我出/出道/出几道` → question。**main 与 ADR-0098 合并版同样缺这些词**；`6489a97` 的串台修复未覆盖。
- **次生缺口（即使路由正确也存在）**：① 流式题卡从不带 `scene_spec`——`GeneratedQuestion` 无此字段、`generate_questions` 不构建；但前端 `AssistantQuestionCard` 已能渲染 `scene_spec`、`QuestionPreview` 已透传、落库 `tasks/service.py:616-633` 甚至优先用前端回传的「出题时已算好的」→ 生成端缺生产者，聊天题卡永远无图（只有落库后的任务/题库页读 `scene_spec_for_read`）。② 聊天题卡 options 走 `cardStr`（`{text,figure_key}` dict 会渲染成 map 字符串），而 `QuizOption.parseList` 只在 `QuestionPreview` 用；前端题卡测试用 string options，与后端形状不一致（潜伏）。
