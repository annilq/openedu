## 范围

同一个「几何」现在有三种写法，而它们本该是同一个东西：场景规格把顶点摊平在自己顶层；
场景规格里那组选项条目用另一套字段名带一份顶点；通用图形类型带了身份键却是第三套名字。
结果读写两侧对同一份几何各有各的认识——生成侧按「顶层覆盖」合并，渲染侧按「条目解析」读取。

身份缺失已造成真实缺陷：选项条目不带图库身份键，图形画廊只能拿**展示名**当身份用。
教师改一次图形名，卡片角标与高亮的映射就断了；同名图形还会被静默合并。

## 为什么是 wide refactor（不是普通垂直切片）

爆炸半径：后端 17 个文件含 `scene_spec`、前端 17 个文件含 `sceneSpec / optionGroup / points`。
场景规格是 JSON 列、前端是裸字典——**改形不会编译报错，只会静默画空**。
所以「后端先改 / 前端后改」各自都绿不了（后端出新形 + 前端读旧形 = 画廊空白），
而 ADR-0091 又明确**不做双读**。

故排成 **expand–contract + 集成分支**：先纯新增，再分批改各层，最后由集成票统一承诺绿。
（技能对「批次各自绿不了」的明文处置：共享集成分支，green is promised only there。）

## 依赖链

```
01 图形类型与归一化校验入口（expand，纯新增）──（无前置）
02 后端生产端改形 ────────────────────────── 01
03 后端消费端与端点改形（端点级接缝）───────── 02
04 前端类型化与解释器改形（修身份缺陷）─────── 01
05 存量快照迁移脚本（幂等 + 干跑，不真跑）─── 01
06 集成验证：真跑迁移 + 全量回归 + 删旧形契约 ── 03, 04, 05
```

- 02 / 03 与 04、05 **可并行**（都以 01 为唯一前置）；06 收口，被全部阻塞。
- **绿只在 06 承诺**；02–05 在集成分支上合，中间态不单独发布。

## 共同纪律

- 全量 `flutter test` 无回归；静态检查以输出里的「No issues found!」为准（该命令退出码常非 0）。
- 改 `features/*/service.py` 必跑分层不变量测试（归属判定只许走 `core.guard`）。
- 单文件 ≤400 行（ADR-0058，超限抽 part，**不**直接上调基线）。
- **禁止在测试里做截图装置**（无真实合成器会挂死，实测把前端测试从约 46 秒拖到 17 分钟）→ 一律几何断言。
- 渲染只吃 `points` / `edges`；身份键只用于身份 / 溯源 / 校验，运行时零图库依赖。
- 学生侧观感不变：图形画廊点卡片仍弹出可拖轴的对折演示。
