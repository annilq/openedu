# 01: 图形类型与归一化校验入口

**What to build:** 几何从此只有一个载体。新增**纯数据的图形类型**（身份键 + 中文名 + 顶点 + 连接关系），与前端既有的通用图形模型同构；配套一个**归一化 / 校验入口**：新形直读、**旧形（顶点摊平在场景规格顶层）被拒绝**而不是静默适配成旧形。本票 **expand 步骤**：不接任何生产或消费路径，因此 CI 必然全绿，可以立刻开工。

**Blocked by:** 无（可立即开工；整条链的 expand 基础）

**Status:** ready-for-agent

## 验收

- [ ] 图形类型是纯数据、零业务依赖，字段为 `{key, label, points, edges}`，与前端通用图形模型同构（前端需补连接关系字段才能同构，补在 04）。
- [ ] 校验入口支持**新形直读**：合法的图形对象原样返回。
- [ ] 校验入口**拒绝旧形**：顶层摊平的顶点形状返回空 / 拒绝，且有断言（不是静默适配）。
- [ ] 身份键缺失 → 拒绝；顶点或连接关系为空 → 拒绝。
- [ ] **渲染期的最后兜底图形不参与落库**（它只在渲染时兜底，不得写成快照）。
- [ ] 单测覆盖三态：合法 / 旧形 / 缺身份键。
- [ ] 本票不改任何生产或消费路径；全量后端测试与静态检查无回归。

## 纪律

- 不接生产端、不接消费端、不改端点（那是 02 / 03）。
- 不做双读兼容：旧形一律拒绝，不留适配分支。
- 交互参数（`kind` 的轴初值 / 控件 / 引导语）不进图形类型——它们归交互外壳。
