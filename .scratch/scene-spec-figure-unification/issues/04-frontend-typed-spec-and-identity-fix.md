# 04: 前端类型化与解释器改形：修身份缺陷

**What to build:** 从教师视角，改图形名之后课件与题目里的卡片角标**不再错位**；从开发者视角，场景规格第一次拥有类型（此前它只是一张裸字典，解析散落在两处——这正是两套解析的根源）。通用图形模型补齐连接关系字段以与后端同构，图形画廊改用**真正的身份键**做角标与高亮，展示名回归它本来的用途：显示。

**Blocked by:** 01（图形类型与校验入口）

**Status:** done

## 验收

- [ ] 通用图形模型含**连接关系**字段，与后端图形类型同构（此前前端只有顶点、按序闭合）。
- [ ] 场景规格是**类型**而非裸字典；解析只在一处。
- [ ] **身份缺陷回归（本次修复的缺陷，必须有断言）**：改图形的展示名后，画廊角标映射与高亮不变。
- [ ] 同名不再被静默合并（身份键不同即为两个图形）。
- [ ] 旧选项条目投影类型与**旧形兼容适配层**已删除。
- [ ] 学生侧观感不变：点卡片仍弹出可拖轴的对折演示；轴初值继续由 `kind` 交互外壳给出。
- [ ] 渲染只吃顶点与连接关系，**不消费身份键**（身份键只用于身份 / 溯源）。
- [ ] 几何断言而非截图装置；全量前端测试与静态检查（认「No issues found!」）无回归。

## 纪律

- 禁止在测试里做截图装置（无真实合成器会挂死）。
- 单文件 ≤400 行（ADR-0058，超限抽 part，不直接上调基线）。
- 渲染层零图库依赖：不因为有了身份键就去回查数据源。
