# 02: 后端生产端改形：场景规格持有图形

**What to build:** 从开发者视角，三个生产场景规格的函数只产**一种**形状——顶点不再摊平在场景规格顶层，而是装进一个主图形；选项组从「另一套字段名的条目数组」变成**图形数组**。顺带摘掉「扫选项文字反猜图形」的调用（它的驱动对象由后续 AI 链路票接回）。

**Blocked by:** 01（图形类型与校验入口）

**Status:** ready-for-agent

## 验收

- [ ] 三个生产函数产出的场景规格均为新形：`kind` + 一个主图形 +（可选）一组选项图形。
- [ ] 场景规格顶层**不再有摊平的顶点 / 连接关系字段**。
- [ ] 合并语义由「顶层字段覆盖」改为「**替换主图形**」。
- [ ] 不再有任何从选项文字反猜图形的代码路径（该能力由 AI 链路的「模型引用身份键 + 盖章」接回）。
- [ ] 来源标记字段与旧选项条目投影类型已从生产端移除。
- [ ] 知识点场景配置仍是**唯一事实源**；场景库注册表不被回查（它是派生视图）。
- [ ] 课件环节里教师编排的图形顺序被严格保留。
- [ ] 后端分层不变量测试通过；全量后端测试与静态检查无回归。

## 纪律

- 本票只管**生产端**；消费端与端点是 03。
- 不做双读：旧形不兼容、不回写。
- 交互参数不进规格，继续由 `kind` 交互外壳提供。
