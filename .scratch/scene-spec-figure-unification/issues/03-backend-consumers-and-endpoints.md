# 03: 后端消费端与端点改形（端点级接缝）

**What to build:** 从调用方视角，题库 / 任务 / 复习 / 错题的响应侧改读新形并在端点**照原样下发**——端点路径与契约名一个都不变，变的只是里头场景规格的形状。这是本目录的**测试接缝**：形状类断言走端点级而不是服务级（历史教训：只测服务会漏掉某个端点整段忘了下发）。

**Blocked by:** 02（后端生产端改形）

**Status:** ready-for-agent

## 验收

- [ ] 题目详情 / 任务详情 / 错题本**三个端点按端点断言**下发新形：顶点在主图形里、选项组是图形数组。
- [ ] **快照不可变**：改图形几何库里的顶点后，已落库的顶点不变（不许回写）。
- [ ] 端点路径与契约名不变（前端依赖的字段名不新增、不改名）。
- [ ] 资料域的知识点场景读写路径同步改读新形。
- [ ] 无几何的场景规格 → 端点照常返回，不抛错（空态由前端负责）。
- [ ] 分层不变量测试通过；全量后端测试与静态检查无回归。

## 纪律

- 契约名与端点路径一律不动，只改形状。
- 不做双读：代码只认新形。
- 形状断言在**端点级**，不要退化成服务级单测。
