# 05: 存量快照一次性迁移脚本

**What to build:** 一个**可重复执行、可先干跑**的一次性脚本，把四处存量快照从旧形改写成新形。旧快照本来没有身份键 → 按顶点反查图形几何库取键；查不到 → 生成自绘前缀键。**本票只交付并测试脚本，不在开发库上真跑**（真跑在 06，那时全链路已改完）。

**Blocked by:** 01（图形类型与校验入口）

**Status:** ready-for-agent

## 验收

- [ ] 覆盖范围完整：题目与任务题的场景规格列、知识点场景配置、课件环节内嵌场景。
- [ ] 旧形样本 → 新形，且**顶点反查拿到了身份键**。
- [ ] 反查不到 → 生成自绘前缀键（不是直接丢弃，也不是用展示名凑）。
- [ ] **幂等**：连续跑两次结果相同。
- [ ] **干跑开关**：只出报告不写库。
- [ ] 渲染期的最后兜底图形**不参与落库**。
- [ ] 课件环节里教师编排的图形顺序迁移后严格保留。
- [ ] 全量后端测试与静态检查无回归。

## 纪律

- 不在本票真跑开发库（避免与其他会话共享的开发库互相干扰）。
- 脚本先读结构再决定改写（SQLite 加列 ≠ 加约束，别想当然）。
- 不做双读：脚本是**一次性改写**，不是运行时适配。
