# 03: 速览层 workbench_glance.dart（scope=all 图表化）

**What to build:** 工作台进入即看的速览区段。复用 `analyticsNotifier` 在 `scope=all` 下的取数结果，渲染三块图表卡——掌握度环形仪表、薄弱知识点横向条形（按 `accuracy` 分级配色：红<60 / 琥珀 60–85 / 绿>85，点击钻取分析层）、正确率分组条；并补齐错题分布，取代现有概览页的纯文字「掌握度概览 + 薄弱知识点」。保留概览最有价值的转化入口——薄弱知识点的「就这个出题」行动钩子（跳转出题并预填知识点）。孤儿「未知」错题组以警示色条显式保留（ADR-0064 / ADR-0070 §2.4.3），禁止丢弃或混入有效分组。

**Blocked by:** 02 (图表适配器层)

**Status:** ready-for-agent

- [ ] 速览层渲染三块图表 + 错题分布，数据来自 `scope=all` 的现有聚合端点，不新增后端逻辑。
- [ ] 薄弱知识点按 `activeWrong` 降序、按 accuracy 分级配色；点击触发钻取回调（本张只验证回调触发，钻取落地在 05）。
- [ ] 「就这个出题」钩子保留并可点，预填知识点链路不破坏。
- [ ] 孤儿「未知」组以警示色条出现；widget 测试断言其存在且不混入有效分组。
- [ ] 暗色模式与令牌正确；`flutter analyze` 与 glance widget 测试通过。
