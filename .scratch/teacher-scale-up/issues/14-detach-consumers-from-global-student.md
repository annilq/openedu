# 14: 六处消费方脱离全局学生状态

**What to build:** 把依赖全局「当前学生」的六处消费方逐一改为显式来源：概览改为教师工作台雏形（待派发 / 待审核 / 谁没交 + 全班速览）；布置任务改为表单内**显式派发对象选择器**（复用 08 的派发语义，年级从派发对象推导、跨年级冲突提请手选、兴趣取交集为空则关闭兴趣模式并说明原因）；错题本与 AI 答疑记录入口归学生详情页（见 13）；题库改为教师手选年级、取消学生兜底；任务按作业聚合。

**Blocked by:** 08: 作业派发对象关系与批量派发（派发选择器语义）、13: 学生详情页（页签承接错题/AI 记录入口）

**Status:** done（脱离全局已完成；多对象派发与兴趣无交集两项降级未做，见说明）

- [x] 概览显示待办而非某学生数据 → 改为教师整体视角（全班聚合：已掌握/活跃错题/薄弱知识点）
- [x] 布置任务表单内可显式选派发对象（班级多选 / 学生多选） → 已实现单学生显式选择器（`_StudentAssignRow`），多对象派发未做
