# 06: Excel 导入 UI

**What to build:** 学生管理页内提供上传入口，选文件后调用导入端点并展示结果：成功多少、跳过多少、以及每一行失败的原因，便于教师修正表格重新导入。

**Blocked by:** 05: Excel 批量导入学生端点

**Status:** ready-for-agent

- [ ] 选 xlsx 文件 → 显示导入进度 / 结果
- [ ] 结果分区展示 `created` / `skipped` / `errors`，`errors` 列出每行原因
- [ ] 导入后列表即时反映新增学生
- [ ] 上传组件在「不套 Material」的树里真构建通过
- [ ] 新增前端 `file_picker` 依赖；新文件受 400 行规模棘轮约束并登记基线

**决策锚点：** ADR-0068「依赖与前端」；导入结果不只是一句「失败」，须明示每行原因与跳过原因。
