# 05: Excel 批量导入学生端点

**What to build:** 教师上传 Excel 花名册批量创建学生账号。最小列「姓名 + 学号」；`username` 直接取学号原样（不做拼音转换、不加前缀、不自动去重）；初始密码为统一常量，走后端配置项；学号已存在 → 该行落 `skipped`，**绝不覆盖**既有账号；缺列整行拒绝并回传行号；重复导入幂等；响应返回 `{created, skipped, errors:[{row, reason}]}`；对文件大小与行数设上限防拖垮服务。

**Blocked by:** 01: 班级实体与 CRUD 端点

**Status:** done

**Done note (2026-10-07):** `POST /students/import`（`students/router.py:53`）Excel 导入端点存在；账号策略（学号作账号/统一初始密码）与幂等、skip/error 行号需对照 service 复核。

- [ ] 正常导入创建账号，`username`=学号，初始密码=配置值
- [ ] 缺列整行拒绝并回传行号，不猜测、不半成功
- [ ] 学号冲突落 `skipped`，不覆盖
- [ ] 同文件重复导入全部 `skipped`（幂等）
- [ ] 大班（≥60 行）导入成功
- [ ] 导入后该 `username` + 初始密码能**真正登录**
- [ ] 文件超限（大小 / 行数）被拒
- [ ] 导入是新增攻击面：`openpyxl` 解析外部上传，须有大小与行数上限

**决策锚点：** ADR-0068「Excel 导入与账号策略」；`username` 全局唯一（非按教师隔离），同校两位教师导入相同学号会撞车 → 行为报「该学号已存在」由教师自行加前缀，不做自动加后缀。新增后端 `openpyxl` 依赖。
