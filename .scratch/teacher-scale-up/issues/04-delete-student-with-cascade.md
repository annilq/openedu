# 04: 删除学生账号与级联清理

**What to build:** 教师可删除建错的学生账号。删除在单个事务内**硬删**并级联清理其作答记录、打卡记录、错题记录，响应回传各表清理行数，让教师确认没有误删。采用硬删而非 `is_active` 软删（软删会污染登录/派发/统计/列表全部过滤条件，极易漏）。

**Blocked by:** 01: 班级实体与 CRUD 端点

**Status:** done

**Done note (2026-10-07):** `DELETE /students/{student_id}`（`students/router.py:183`）端点存在；级联清理与回传各表行数在 service，需复核。

- [ ] 级联在事务内，失败整体回滚
