# 03: 批量移入/移出班级

**What to build:** 教师可批量把一批学生移入某班级、或移出班级变未分班，无需逐个人点编辑。服务于学期初分班与学期末清空分班。

**Blocked by:** 01: 班级实体与 CRUD 端点、02: 学生管理页与列表过滤/搜索

**Status:** done

**Done note (2026-10-07):** `POST /students/batch-reassign`（`students/router.py:165`）+ 前端选择模式移入/移出班级（`student_management_screen.dart` `_moveToClass`）。

- [ ] 勾选多名学生 → 移入某班级成功，这些学生出现在该班分组
- [ ] 批量移出班级成功，学生归入「未分班」
- [ ] 越权 / 非法班级被拒
- [ ] 批量操作在单个事务内完成，部分失败时整体回滚
- [ ] 操作后学生管理页的分组人数即时刷新正确

**决策锚点：** ADR-0068；批量移动为独立端点，不在单学生编辑里堆叠。
