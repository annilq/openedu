# 02: 学生管理页与列表过滤/搜索

**What to build:** 教师从侧栏进入独立的**学生管理页**，学生按班级分组展示（含「未分班」分组），每组显示人数；支持按班级筛选、按姓名/学号搜索。列表每行直接显示该学生的活跃错题数，并提供行内入口直达其详情页错题页签——以此补偿「切学生即看错题」这条高频路径被拉长的问题。后端学生列表端点支持 `class_id` 过滤与姓名/学号搜索。

**Blocked by:** 01: 班级实体与 CRUD 端点

**Status:** done

**Done note (2026-10-07):** `GET /students?class_id=` 支持班级筛选（`students/router.py:118`）；`student_management_screen.dart` 按班级分组（含未分班）、显示人数、关键词走后端搜索。验收需复核班人数与行内错题数一致。

- [ ] 学生管理页按班级分组，「未分班」单独成组，每组显示人数
- [ ] 按班级筛选只显示该班学生；按姓名 / 学号搜索可定位单人或少数人
- [ ] 每行显示该学生活跃错题数（醒目，弥补导航重构后多看两层）
- [ ] 行内入口跳转学生详情页错题页签
- [ ] 大班（≥60 学生）下列表渲染与筛选无卡顿
- [ ] 页面在「不套 Material」的树里真构建一次通过（`flutter analyze` 查不出缺 Material 祖先的崩溃）

**决策锚点：** ADR-0068、ADR-0070；行内错题数是代价补偿（ADR-0070 §Solution）。单文件 ≤400 行、一个文件只暴露一个公开物（规模棘轮）。
