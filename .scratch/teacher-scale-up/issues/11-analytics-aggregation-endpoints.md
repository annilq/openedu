# 11: 学情统计聚合端点

**What to build:** 三个统计聚合端点（错题分布 / 正确率 / 掌握度），作用域三态（单学生 / 单班级 / 全体学生）× 维度（学科 / 年级 / 学期 / 知识点）。数据无需新表：作答记录与错题 JOIN 题目即可拿到四个维度。钉死四项口径（本 spec 最易翻车处）：① 年级取**题目的年级**，不取学生的年级；② 学期取值收敛为常量，空值归入「整学年」不单列空白组；③ 孤儿错题（原题已被 ADR-0064 硬删）归入「未知」分组并**显式标注数量**；④ 掌握度跨学生必须**批量聚合端点**，严禁循环调用单学生掌握度接口（否则 N 次全量扫作答记录）。正确率按来源（练习 / 复习）可分看。越权隔离。

**Blocked by:** 01: 班级实体与 CRUD 端点（班级作用域需要班级实体）

**Status:** done

> 验证注：`backend/app/features/analytics/`（router/service/schemas）已提交，三态作用域×四维聚合端点已落地。代码已提交。四项口径（题目年级 / 空学期归整学年 / 孤儿错题归未知并标注 / 批量聚合不循环单生 mastery）待 E2E 验收。

- [ ] 三态作用域（学生 / 班级 / 全体）均返回正确分组
- [ ] 四维各自分组求和等于总数（防 JOIN 丢行或重复计数）
- [ ] **孤儿错题**落「未知」并标注数量
- [ ] **空学期**归「整学年」，不产生空白分组
- [ ] **跨年级班级**（班级自带年级但学生可跨年级）下题目年级与学生年级不混淆
- [ ] 活跃错题与已毕业错题分开计数
- [ ] 练习 / 复习两种来源正确率分看
- [ ] 大班（≥60 学生）下响应时间可接受——这是批量聚合是否被正确实现的唯一判据
- [ ] 别教师的学生不出现在我的统计里

**决策锚点：** ADR-0070「四项必须钉死的口径」；学期无字典表须收敛常量；本轮不修硬删行为、不引入掌握度快照表、不循环单生 mastery。
