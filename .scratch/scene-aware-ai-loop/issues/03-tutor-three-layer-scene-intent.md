# 03: 答疑侧：三层识别（门控 / 模型 / 校验）

**What to build:** 从学生视角，问「平行四边形是轴对称图形吗」时答疑**直接给出可交互图形**，且图形先于讲解正文出现；而问作业、问定义、纯计算时**不弹任何场景卡**。从开发者视角，伴学链路里「从提问文字反猜图形名」的代码连同整个抽取模块一起消失，换成确定性门控 → 模型结构化判定 → 后端校验盖章。

**Blocked by:** 02（出题侧：选项内嵌图形）

**Status:** done（提交 1ccb6d3；删 scene_extract.py 整族文本抽取，改三层识别）

## 验收

- [ ] **L0 门控（不调模型）**：能解析出知识点（课件 / 题目 / 学生当前知识点；都没有则走资料片段检索命中知识点）**且**能投影出非空图形目录 → 才发起调用。断言**微调用次数为 0**（不是断言结果）。
- [ ] ⚠️ **门控不用意图关键词**——那仍是猜；知识点场景是教师显式配置的、更强且零成本的信号。
- [ ] **L1 模型判定**：一次结构化微调用，输入只有四样——知识点名、图形目录（只给键与中文名）、学生原话、（有则）上下文；提示词必给**反例**（问作业 / 问读音 / 纯计算 → 不出）。
- [ ] **L2 后端校验盖章**：`should_show` 与 `figure_key` 必须自洽（冲突取保守）、键必须在目录内、图库必须有这一行——任一不过就不发射。断言**四态**全部不发射。
- [ ] **异常态**：微调用抛错 → 不发射**且讲解正文完整照常**（绝不吞主功能）。
- [ ] 场景卡 DATA 帧**先于正文**到达（端到端断言顺序）。
- [ ] **去重**：同一会话内与上一条已发射的身份键相同 → 不重复发射。
- [ ] `kind` **不由模型输出**（它是稳定契约；首版恒为轴对称）。
- [ ] 「扫提问文字反猜图形」的代码路径、整个抽取模块及其测试已删除；「按身份键取权威几何」的原语**改掉「兜底 / 默认」命名**（它会误导后人以为那是降级路径）。
- [ ] 端到端一整轮答疑循环测试（含命中与未命中两条）。

## 纪律

- **模型有建议权，没有决定权**：决定权在后端校验层，这与「防臆造」是同一条纪律。
- 粒度分工：知识点级（这一类配不配演示）由**数据**答；提问级（这一问要不要）由**模型**答。
- 未命中 / 异常一律不发射，且不得回退到关键词猜测。
