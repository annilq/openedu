# 02: 出题侧：选项内嵌图形（删文本反猜，改结构化发射）

**What to build:** 从教师视角，AI 出的图形选择题**每个选项都渲染成平面图形**，学生看图而不是读描述；我在画板里自绘的图形也能被出题引用。从开发者视角，后端从此不再有任何「从选项文字反猜图形」的代码——模型只引用身份键，顶点绝不由模型产出。

**Blocked by:** 01（目录投影 / 校验 / 盖章）、另一目录 `scene-spec-figure-unification` 的 06（集成验证）

**Status:** ready-for-agent

## 验收

- [ ] 出题的结构化输出增加每项的**图形身份键**（只给键，不给顶点）；出题提示词注入「可用图形清单」。
- [ ] 落库前校验 + 盖章；题目与任务详情端点按端点断言下发 `options[].figure`（几何内联）。
- [ ] **快照不可变**：改图形几何库的顶点后，已落库的顶点不变。
- [ ] **全-or-无**：部分选项有图 → 整题退化纯文字（不是只给部分选项配图）。
- [ ] 选项文字 `text` 恒存在且保留选项前缀（去掉前缀会破坏判题比对）；判题改走「取选项文字」。
- [ ] 选项列用**容错读取**过渡（字符串 → 包成带空图形的对象）；同一列，**无 DDL 迁移**。
- [ ] 选项图形**不带 `kind`**（演示类型取题目级场景规格）。
- [ ] 「扫选项文字反猜图形」的代码路径已删除。
- [ ] 分层不变量测试通过；全量后端测试与静态检查无回归。

## 纪律

- 模型绝不输出顶点——提示词里只出现身份键与中文名。
- 不新增列、不改端点路径与契约名（只加字段）。
- 删抽取逻辑时**连根删**：留一半等于留一半猜测逻辑。
