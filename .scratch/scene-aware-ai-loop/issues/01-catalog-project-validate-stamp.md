# 01: 图形目录投影 / 校验 / 盖章模块

**What to build:** 出题与答疑共用的一套逻辑：给定知识点，投影出**本次可用的图形目录**；对模型给出的身份键做**校验**；通过后按身份键从图形几何库取权威几何**盖章**成内联图形。它**不新增任何关联表或列**——知识点场景本来就是知识点与场景的关联，场景库只是它的派生视图。本票是纯新增，无破坏，CI 全绿。

**Blocked by:** 另一目录 `scene-spec-figure-unification` 的 01（图形类型与校验入口）

**Status:** done

## 验收

- [ ] 目录投影：输入知识点场景（优先教师已配置的图形），无配置时回落图形几何库全量；返回非空目录的判定有断言。
- [ ] 目录条目是**「身份键 + 中文名」的轻量类型**，不是图形本身——类型层面保证顶点进不了提示词。
- [ ] **盖章**：合法身份键 → 顶点与连接关系内联进图形对象，顺序等于传入顺序。
- [ ] **全-or-无在校验层**：部分条目有图 → 整组全部丢弃（半套图会把「图不对」误导成「答错了」）。
- [ ] 未知身份键 / 图库里没有这一行 → 丢弃，且不抛错。
- [ ] **不新增任何关联表或列**；场景库注册表不被回查。
- [ ] 教师自绘图形与自编知识点都能进入目录（旧词表只认内置图形，这是本次的能力增量）。
- [ ] 单测覆盖三态：合法 / 部分有图 / 未知键。

## 纪律

- 只装三件事：投影、校验、盖章。不做提示词拼装、不做发射（那是 02 / 03）。
- 顶点永远来自图形几何库这一处权威，不由调用方传入。
- 目录投影用轻量类型，绝不把图形对象序列化进提示词。
