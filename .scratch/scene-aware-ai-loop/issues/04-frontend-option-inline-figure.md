# 04: 前端：选项行内渲染图形

**What to build:** 从学生视角，选择题的**选项行里直接画出平面图形**（不是题下方单独一组卡片），点一下图形就弹出可拖轴的对折演示，我亲手验证而不是看答案。选项模型持有图形——**复用前端已有的通用图形模型，零新增类型**。

**Blocked by:** 02（出题侧：选项内嵌图形）、另一目录 `scene-spec-figure-unification` 的 04（前端类型化与解释器改形）

**Status:** ready-for-agent

## 验收

- [ ] 选项模型持图形：解析支持「字符串 → 带空图形的对象」，字符串选项的老路径不回归。
- [ ] 选项行内渲染平面图形；**点击弹对折演示**（可拖轴），与既有交互一致。
- [ ] 无图形的选项照常渲染为纯文字（不是空白块）。
- [ ] 判断题未揭示时，图形下方的答案与解析保持隐藏。
- [ ] 复用既有通用图形模型，**零新增图形类型**。
- [ ] 几何断言而非截图装置；全量前端测试与静态检查（认「No issues found!」）无回归。

## 纪律

- 禁止在测试里做截图装置（无真实合成器会挂死）。
- 单文件 ≤400 行（ADR-0058，超限抽 part，不直接上调基线）。
- 全仓禁 Material 控件；可点区一律 `AppFocusableAction`；并排元素注意固定高度控件的描边画在盒外。
- 渲染只吃顶点与连接关系，不消费身份键。
