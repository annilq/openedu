## 一句话

删掉整族文本抽取（几何改由 **AI 显式引用身份键 + 后端盖章**产生），图形**内嵌进选项本身**；
答疑侧改为**三层识别**：确定性门控 → 模型结构化微调用 → 后端校验盖章。

## 前置

**被 `../scene-spec-figure-unification/` 阻塞**（那边 06 集成验证完成）。本目录不新增任何关联表或列——
知识点场景本来就是知识点与场景的关联，场景库只是它的派生视图。

## 决策锚点（钉死，勿再开讨论）

| # | 决策 |
|---|---|
| 1 | 删掉整族文本抽取：扫选项文字的函数、扫提问的函数、整个抽取模块及其测试。留任何一个都等于留一半猜测逻辑 |
| 2 | 模型**只引用身份键，绝不输出顶点**；几何始终来自图形几何库这一处权威 |
| 3 | 目录条目用**「身份键 + 中文名」的轻量类型**而不是图形本身——类型层面保证顶点进不了提示词 |
| 4 | 选项 = 文字 + 可选图形：`text` 恒存在（判题唯一依据、前缀保留）、几何**内联**、**不带 `kind`**（取题目级）、**全-or-无挪到校验层** |
| 5 | 选项列用**容错读取**过渡（字符串 → 包成对象），判题改走「取选项文字」；同一列，无 DDL |
| 6 | 答疑三层：**不用意图关键词**做门控（那仍是猜）；知识点级由数据答，提问级由模型答 |
| 7 | **模型有建议权，没有决定权**：决定权在后端校验层 |
| 8 | 部分选项有图 → 整题退化纯文字；未命中 / 异常 → 不发射且讲解正文照常 |

## 能力不回退

旧路径里「没配模板但题面点名了图形也会出图」这个能力，由「AI 发射身份键 → 盖章」承接，
而且教师自绘图形**第一次**可用（旧词表只认内置的那些）。
