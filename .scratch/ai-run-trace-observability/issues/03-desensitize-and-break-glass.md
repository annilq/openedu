# Ticket 03 — 内容默认脱敏 + 破窗访问留痕

- **What to build**: 在运行轨迹页与 debug 端点落实儿童合规红线。默认展示：步级结构、路由、模型、token、延迟、安全标记——但 tool 参数与结果中的学生 PII（姓名/学号/作答内容）做脱敏展示（如掩码）。「查看对话原文」走破窗：触发一次显式访问，后台记录访问者、目标 conversation、时间、理由，留痕落库（落库位置见 ADR-0088 §7 开放问题，待定）。默认管理员对全文内容不可见，只有破窗解密——避免「站着就能读所有孩子对话」。依赖 ticket 00（admin 角色）与 ticket 02（轨迹页渲染）。
- **Blocked by**: 00, 02
- **Status**: done
- **验收清单**:
  - 默认视图：步级/模型/token/延迟/安全标记可见；tool 参数与结果里的学生 PII 脱敏（掩码），原文不可见。
  - 破窗：走显式访问后原文可见；访问被记录（访问者/目标/时间/理由）。
  - 未授权全文访问（非 admin、或非破窗路径）被拒（403/404）。
  - 访问留痕落库可查（落库位置按 ADR-0088 §7 决议，先以独立审计表或既有日志表承载）。
  - 脱敏不破坏轨迹页既有渲染与导航单源；`flutter analyze` + `flutter test` 0 回归。

## 决策锚点

- **默认脱敏 + 破窗留痕**：对齐主流企业/教育产品的「审计 + 脱敏 + break-glass」模式（ChatGPT Enterprise / Claude for Work admin console）；默认不提供「站着就能读全文」的角色。
- **落痕不落明文风险**：访问留痕记录「谁在何时看了什么」，但不把对话原文外发到独立观测后端；原文始终在业务 DB 内。
- **admin 口令从环境变量读、绝不写死**（ticket 00 已落实），本票在其之上加内容层合规。
