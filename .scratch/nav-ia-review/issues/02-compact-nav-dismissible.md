# 02: 紧凑档导航可关闭性

**What to build:** 教师端在窄宽度下点汉堡打开抽屉后，**点任意菜单项抽屉自动关闭**、遮罩消失、目标页已切换；并支持在抽屉上左滑关闭。移动端「打开菜单 → 选一项 → 看到内容」这条最基本的手感成立。

**Blocked by:** 无（可立即开工）

**Status:** ready-for-agent

## 验收

- [ ] 点抽屉内任一菜单项 → 抽屉关闭 **且** 目标页已切换（两者都要发生）
- [ ] 点「我的」同样关闭（该入口两个角色共用，两端各走一遍）
- [ ] 左滑手势可关闭抽屉，阈值与动画时长与既有展开/收起一致
- [ ] 点遮罩关闭仍然有效（回归项，不得被本票弄丢）
- [ ] 关闭动画尊重 reduce-motion（开启时时长为零）
- [ ] 关闭过程中不触发目标页的重复加载
- [ ] widget 测试覆盖「点项后抽屉关闭」与「左滑关闭」两条路径

## 纪律

- 抽屉内的导航项**仍然**走可聚焦动作组件：左滑手势只是补充，不得替换可点区域，否则桌面端 Tab 跳不过去。
- 关闭动作要发生在导航**之后**，避免动画途中抽屉与内容同时重排。
- 本票不动抽屉的视觉（底色 / 描边 / 选中语言），也不动学生端底栏（那是 06）。
