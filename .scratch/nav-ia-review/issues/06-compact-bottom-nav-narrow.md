# 06: 学生端底栏窄屏适配

**What to build:** 小屏（<360px 可用宽度）下底部五个入口不截断、不挤压，图标与文字都完整可读。常规宽度下的排布与现状完全一致。

**Blocked by:** 无（可立即开工）

**Status:** ready-for-agent

## 验收

- [ ] <360px 可用宽度下，五个入口的文字不被省略号截断
- [ ] 五个入口的命中区仍满足最小可点尺寸
- [ ] 选中态语言不变（仍是 accent 图标 + 加重文字）
- [ ] ≥360px 的排布与现状逐像素一致（纯回归项）
- [ ] widget 测试覆盖窄屏与常规屏两档

## 纪律

- 判定依据只有**可用宽度**，禁止用设备形态或屏幕朝向判定。
- 降级方案优先「只留图标」或「自然分布 + 可收缩」，不要靠缩小字号到 11px 以下。
