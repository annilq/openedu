# 01: 页面标题与图标收进单一映射表

**What to build:** 教师端每一个页面（含下钻页）的标题与图标只在唯一一处定义。侧栏菜单、紧凑档顶栏、未来的路径恢复都从这份映射取值，代码里不再散落硬编码的中文标题。新增页面忘记登记标题会编译失败，而不是运行时显示空白。

**Blocked by:** 无（可立即开工；后续改名与可见性两票的前置）

**Status:** ready-for-agent

## 验收

- [ ] 每个教师端页面类型有且仅有一个标题定义、一个图标定义
- [ ] 侧栏目的地改为从映射取值，目的地构造器内不再出现硬编码中文标题
- [ ] 下钻页（草稿审核 / 编辑学生 / 学生详情 / 场景库详情 / 场景编辑器 / 运行轨迹详情）也各有标题，供顶栏与路径恢复使用
- [ ] 新增页面忘记登记 → 编译失败（映射是穷尽的 `switch` 或完整 Map，穷尽性由编译器保证）
- [ ] 学生端四个页签 + 「我的」同样进入同一处收口
- [ ] 本票是纯搬移：所有页面显示效果与现状逐字一致
- [ ] `flutter analyze` 无告警、`flutter test` 无回归

## 纪律

- 只搬不动：本票不改名、不调序、不改任何可见行为（改名在 07）。
- 遵守既有「枚举 → 文案只在 `labels.dart` 写一次」的约定，widget 内不出现 `switch (page) => 文案`。
- 下钻页的标题用**页面自身**的口径（"编辑学生"），不用父级口径（"学生"）。
