# 04: 学生端「我的」进常驻槽位

**What to build:** 学生端「我的」与四个页签**常驻共存**。从首页滚到中部再切「我的」、再切回首页，滚动位置、已加载数据、局部展开态都还在——不会因为看了一眼个人信息就把四个页签整棵销毁重建。

**Blocked by:** 无（可立即开工）

**Status:** ready-for-agent

## 验收

- [ ] 「我的」成为导航状态的第五个槽位，与四个页签同构（不再走独立分支）
- [ ] 首页滚动到中部 → 切「我的」→ 切回首页，滚动偏移未归零
- [ ] 页签与「我的」不会同时高亮（显示「我的」时四个页签一律取消高亮）
- [ ] 底栏「我的」与侧栏底部用户区两个入口行为一致（该回调两个角色共用，两端各走一遍）
- [ ] 个人信息页自身不需要常驻（它的 State 可随槽位销毁重建）
- [ ] widget 测试：切走再切回，页签页 State 未被重建（用滚动偏移或局部计数断言）

## 纪律

- 本票**不改刷新时机**（那是 13）；切页签时的取数行为与现状保持一致，只修「状态被销毁」这一件事。
- 不得为了省事把「我的」塞进某个已有页签内部——它是与页签同级的导航状态，不是某个页签的子页面。
