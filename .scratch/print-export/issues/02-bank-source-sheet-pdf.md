# 02 — 服务端产出第一份学生卷（题库来源）

**What to build:** 家长把自己题库里的题目 id 传上来，服务端返回一份可以直接打印的 A4 学生卷 PDF。

新增 `export` feature（schemas / repository / service / router 四件套，沿用 `questions` 的
「模块级函数 + 显式传 session」约定）并注册到 API 主路由，端点 `POST /api/v1/export/sheet`，
首个来源 `source=bank`。

这一票要把服务端该负责的事一次性做完整：

- **归属**走 `core.guard`——不允许手写 `parent_id ==` 判定；别人的题目一律 `403`（不返回 404，不给是否存在的信息）。
- **导出文档**的装配：题号跨节连续、题库来源按学科分节（带学科几何标记 ■ ● ▲）、
  只勾单一学科时不产生多余的分节标题、选项里重复的 `A. ` 前缀要去掉、
  按题型给作答留白、`EXPORT_MAX_QUESTIONS` 硬上限 `400`。
- **内容纯净**：文档模型里**不存在** `answer` / `explanation` 字段——答案不是被过滤掉，而是从来没有进来过。
- **题干降级**：剥掉 Markdown 标记与 `$...$` 定界符，保留内部文本（`1/2`、`x^2`）。
- **完整版面**：A4 纵向、页边距左右 20mm 上 18mm 下 16mm、页眉左标题右「姓名 ____ 日期 ____」（不预填娃娃名）、
  题干 12pt / 选项 11pt / 页眉 9pt、行高 1.5；**轻装饰**——墨黑描边与学科几何标记保留，**不铺任何彩色填充**
  （家长很可能用黑白打印机，色块会印成脏灰）。
- 编译是 CPU 密集，**必须走线程池**，不占事件循环。
