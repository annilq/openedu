# 05 — 错题本与复习来源：打通两个入口

**What to build:** 家长能在错题本页导出娃娃的错题汇总卷，也能在复习页一键导出今天该复习的题——屏幕上是什么，纸上就是什么。

后端新增 `source=wrong_book`，带 `due_only` 开关。这一条路线与前两个来源的关键差别是**归属维度变了**：
题库与任务是家长自己的资源，错题挂在**儿童账户**下，所以必须先经 `core.guard` 的娃娃归属校验，
确认这个娃娃属于当前家长，再按娃娃取数。

**三个来源不是四个**：复习页的「当前到期复习项」与错题本页勾了「只看今天到期」是同一份查询
（同一张错题表 + 到期时间过滤），复用同一个 source 加开关即可；只有实现时发现两页取数语义确有差异，才拆成独立来源。

注意「毕业」不是一个布尔字段——毕业的错题行会被移除，所以「全部未毕业错题」就是这张表里现有的行。
