## 范围

让课件「讲课」页能**同屏摆出多张图形**（教师勾选、有序），学生**对比找规律**；展示态**只读**且**不标答案**，每张右上角 play 点开才进可编辑的对折演示。

**核心前提（决定工作量）**：这件能力的主体已在仓库里。

| 已存在 | 位置 |
|---|---|
| spec 带 `optionGroup` 即渲染多图画廊（而非单场景） | `scene_interpreter.dart:51-61` |
| 只读缩略图网格（静态 CustomPaint，无滑块无判定） | `reflection_figure_gallery.dart:245-298` |
| 点击弹 `ReflectionSceneDialog` → 内含同一个可交互 `ReflectionSceneWidget` | `scene_interpreter.dart:144-156` |
| 课件 `scene` 是裸 dict 透传，能塞 `optionGroup` | `backend/.../schemas.py:58` |
| 讲课页直连 `SceneInterpreter`，分支自动生效（零改造） | `courseware_present_widgets.dart:132` |

所以本轮**只有三个真实缺口**：① 课件语境下没人供给图形列表；② 不支持教师编排子集与顺序（现硬编码整库 11 个）；③ 卡片没有显式 play 提示。

## 分劈原则（to-tickets 拍板）

- **先证伪**：01 验的是全案前提「环节场景透传、后端零改动」。若结论是需要改后端，**停下回 ADR-0076 重估**，后四票规模随之变化。
- **测试跟着切片走**，不堆在末票：三态测试属**输出侧主接缝**（并入 03），勾选产出测试属**输入侧接缝**（并入 04）。每票完工即可自证，05 只剩端到端与回归。
- **04 不被 03 真正 gate**：编辑器产出的是数据，用假仓库断言保存出去的内容即可自证，可与 02/03 并行开工。
- 只写本地 `.scratch` 文件，**未建 GitHub issue**（用户本轮指定）。
