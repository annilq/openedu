### 共享 Map 疑点：核查结论 = **不是缺陷，无需修**

疑点是「环节 scene 与知识点模板共用同一 Map 实例」。核对下来前半句成立、后半句的
风险不成立：

- 实例确实共用：`resolvedScene => scene` 只取顶层（同一实例），`_associateScene`
  与 `_commit` 都是 `Map.from` 的**浅拷贝**，所以嵌套的 `optionGroup` / `points`
  是被共享的对象。
- 但**没有任何就地写**。唯一写入点是 `SectionSceneFiguresPicker._commit`：它先
  `Map.from(widget.scene)` 拿副本，再**整体替换** `optionGroup`（新建的 Map），
  「<2 张」的删键走的是副本上的 `remove`。共享的嵌套对象从未被改写——顶层换键、
  嵌套新建，浅拷贝在这两处都足够。

原有那条零回写用例（`section_scene_figures_picker_test.dart`）的模板**不带**
`optionGroup`，因此抓不到「嵌套共享被就地改」这一路。故补了上面这个新文件：模板
自带 `optionGroup`，两条分支（≥2 张写入 / <2 张删键）都断言写完后模板快照逐字段
不变。**两条用例都验证过牙齿**——把 `Map.from` 去掉改成就地写，它们立刻红（实际
跑过一次并已还原，业务代码 diff 仍为空）。
