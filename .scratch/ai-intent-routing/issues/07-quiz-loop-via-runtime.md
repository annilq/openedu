# T07 — 判断题闭环走运行时（含前端帧兼容）

**What to build:** 判断题闭环不再直连出题管线，改由**运行时**以出题助手运行，
从而拿到资料库检索、学科提示、溯源引用与工具信封。答错后的判定与讲解**仍由模型给出**
（不是回到固定模板话），题面在作答前仍不带答案。前端折叠逻辑同步多忽略运行时新增的几类帧。

**Blocked by:** T06
**Status:** ready-for-agent

## 决策锚点

- 判定与讲解由模型产出是上一轮已定的方向，本票**不得**把它退回成确定性分支（不要重新引入
  「对/错词典 + 硬编码文案」那一套）。
- 题面**剥离答案与解析**是**流程性**剥离（先出题、答完揭示，答案存待判定态供模型判定），
  与角色无关、教师端同样剥离——**不要**把它和「答案可见性」的角色裁剪混为一谈，也不要一并删掉。
- 新增帧只有已知几类（用户消息帧 + 两条路由思考帧），不引入新帧类型；前端只需在现有折叠逻辑里
  多忽略几类，不用新写渲染器。

## 验收

- [ ] 判断题出题经过运行时（不再直连管线）
- [ ] 题面仍不带答案与解析（答题前不泄题）；正确答案存待判定态供模型判定
- [ ] 新增帧仅为用户消息帧与两条路由思考帧，**无新帧类型**
- [ ] 前端折叠逻辑多忽略这几类帧，题卡渲染行为不变
- [ ] 答错后的反馈由模型产出，无硬编码文案分支
- [ ] 全量后端回归 + 前端分析无新增问题
