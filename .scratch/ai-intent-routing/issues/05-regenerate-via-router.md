# T05 — 换一题走统一路由

**What to build:** 让「换一题」拿到与首次出题**同等的能力**。今天它直连出题管线、绕过运行时，
所以资料库检索、学科提示、溯源引用、工具信封**一项都没有**——教师感觉「换出来的题比第一次的差」，
那是真的差。改走统一路由后这些全部生效；教师上传的资料能真正影响重新生成的题。

落库仍在服务端一次完成（前端不增调用）；归属不符仍报「任务不存在」，
**不因改走统一路由而变成 403 或静默改写**。

**Blocked by:** T04
**Status:** ready-for-agent

## 决策锚点

- 归属校验语义**不变**：不符归属一律报「任务不存在」（资源不存在与越权不可区分，既有对外契约）。
  统一路由带来的「动作不可见 → 显式报错」是**角色可见性**的语义，与**归属校验**是两回事，不要混用。
- 一次调用完成生成 + 落库，前端无额外落库调用——这是与教师两步审阅流程的刻意不对称：
  换一题改的是已有草稿的行，不需要再走一次审阅闸门。
- 帧序列会从管线裸帧升级为运行时帧（多出工具调用/工具结果、思考标签变化），前端折叠逻辑需同批兼容。
  换 URL 不换解析器——前端本就共用同一个 SSE 帧解析器。

## 验收

- [ ] 换一题产出的题能引用教师上传的资料（资料库检索真生效），与首次出题同源
- [ ] 溯源引用随题下发
- [ ] 一次调用完成生成 + 落库，前端无额外落库调用
- [ ] 传他人任务 id → 「任务不存在」（不暴露任务存在性，语义不变）
- [ ] 换一题的帧序列是运行时帧（工具调用 / 工具结果 / 思考标签），且前端折叠兼容、题卡渲染不变
- [ ] 与首次出题对比：能力集（检索 / 学科提示 / 溯源 / 工具信封）一致，不再缺项
