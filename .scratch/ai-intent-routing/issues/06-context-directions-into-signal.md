# T06 — 课件上下文与待判定态定向迁进信号

**What to build:** 消除两处「路由算完之后再改判」。课件上下文定向与待判定态定向，
改为在**信号归一化阶段**产出动作键，由 SubAgent 清单声明归属，
路由一次的裁决结果就是最终结果，不再有事后改判。

⚠️ 必须保留的语义差别：课件练习里「出题」的归属是**任务引导**（把用户引导到页面），
助手里「出题」的归属是**出题助手**（真的出卡）。迁移时**不得把两者拍平成同一个动作键**。

**Blocked by:** T04
**Status:** ready-for-agent

## 决策锚点

- 本票的目标是「裁决点归一」，不是「减少动作数量」。若为了省事把两种「出题」合并成一个动作键，
  会立刻丢掉「课件里要引导、助手里要出卡」这个区别——这是最难发现的那类回归：功能照常跑，只是去错了地方。
- 待判定态消费后仍定向伴学答疑；判定与讲解由**模型**产出（服务端不保留尝试次数状态机），
  正确答案已落进会话历史，清空待判定态也不丢上下文。
- 与 T07 串行：两张票都要删掉对话编排里同一段的不同分支，同段并发改必冲突。

## 验收

- [ ] 对话编排里不再有「路由算完再改判业务」的分支
- [ ] 课件里说「提示」仍得到提示
- [ ] 课件里说「出题」仍被引导到页面（**不是**直接出卡）
- [ ] 助手里说「出题」仍出题卡（**不被**引导走）
- [ ] 两种「出题」各有独立动作键，未被合并
- [ ] 待判定态消费后仍定向伴学答疑，判定与讲解由模型产出
- [ ] 既有课件练习与判断题闭环用例全绿
