# 实施文档：题库复用闭环（后端）

> 关联设计：ADR-0004（Task 多学科 + 题库快照隔离）。ADR-0004 把 `Question` 表定为"题库层、可跨 Task 复用"，但**只建了写入侧**（逐题/一键/锁定自动入库），读取与复用侧从未落地，导致 `Question` 入表后成为"只写死库"。
> 本文件补齐**读 + 复用**两段，使题库形成产品闭环，并补上 owner 隔离（多租户正确性）。
> 本文件仅描述后端改动；前端改动见《实施文档：题库复用闭环（前端）》。

---

## 1. 目标与范围

| 项 | 内容 |
|---|---|
| 新增能力 | ① 题库浏览 `GET /questions`（parent 作用域、过滤分页）；② 从题库新建任务 `POST /tasks/from-bank`（选项 A）；③ 加入已有草稿 `POST /tasks/{task_id}/questions/from-bank`（选项 B）；④ 家长草稿列表 `GET /tasks`（供选项 B 的草稿选择器）。 |
| 数据模型 | `Question` 增加 `parent_id`，实现题库 owner 隔离。 |
| 复用原则 | 新建/追加的任务均**复用现有 `TaskQuestion` 快照 + `question_id` 回指源题**，下游"审核→锁定→派发→练习→错题归集"零改动。 |
| 不改动 | 现有"生成→审核→入库→锁定→派发"主链路语义不变；`regenerate`/`remove` 仅增加级联安全保护。 |

## 2. 数据模型变更

`backend/app/models.py` 的 `Question`（约 L97）增加 owner 字段：

```python
class Question(SQLModel, table=True):
    id: uuid.UUID = Field(default_factory=uuid.uuid4, primary_key=True)
    parent_id: uuid.UUID = Field(foreign_key="user.id")  # 新增：题库 owner 隔离
    subject: str
    grade: int
    knowledge_point: str
    qtype: str
    stem: str
    options: list[str] | None = Field(default=None, sa_type=JSON)
    answer: str | None = None
    explanation: str | None = None
    difficulty: str | None = None
    created_at: datetime | None = Field(
        default_factory=get_datetime_utc, sa_type=DateTime(timezone=True)
    )
```

> 说明：`parent_id` 来自其归属 Task（`Task.parent_id`）。题库是家长私有的"出题素材库"，娃娃端永不访问本题库列表（与现有"娃娃端 answer 恒为 None"防作弊口径一致）。

## 3. 数据迁移（无 Alembic，启动期轻量迁移）

项目显式"家自用：启动时建表即可，无需 Alembic 迁移流程"（`main.py` lifespan）。`SQLModel.metadata.create_all` **不会**变更已存在的表，故新增列需一次性 `ALTER` + 回填。

在 `backend/app/core/db.py` 的 `init_db()` 内、`create_all` 之后调用 `run_migrations(engine)`：

```python
from sqlalchemy import text

def run_migrations(engine) -> None:
    with engine.begin() as conn:
        if engine.dialect.name == "sqlite":
            cols = [r[1] for r in conn.execute(text("PRAGMA table_info(question)")).fetchall()]
            if "parent_id" not in cols:
                conn.execute(text("ALTER TABLE question ADD COLUMN parent_id VARCHAR(36)"))
        else:  # postgres
            conn.execute(text("ALTER TABLE question ADD COLUMN IF NOT EXISTS parent_id UUID"))
        # 回填：通过 TaskQuestion -> Task 找到原题归属家长
        conn.execute(text("""
            UPDATE question SET parent_id = (
                SELECT t.parent_id FROM task_question tq
                JOIN task t ON t.id = tq.task_id
                WHERE tq.question_id = question.id LIMIT 1
            ) WHERE parent_id IS NULL
        """))
```

> 新建库：`create_all` 直接带列，迁移为 no-op。旧库：`ALTER` 补列 + 回填（无 TaskQuestion 关联的孤儿行 `parent_id` 保持 NULL，后续作用域查询会排除——属可接受降级，dev 期可 `rm app.db` 重置）。

## 6. CRUD（`backend/app/crud.py`）

### 6.1 写入侧补 owner（现有 promote / confirm）

- `promote_task_question`（L204）：写 `Question` 时补 `parent_id`，取自 `tq -> Task.parent_id`：
  ```python
  task = session.get(Task, tq.task_id)
  q = Question(parent_id=task.parent_id, subject=tq.subject, ...)
  ```
- `confirm_task` 自动 promote-all 分支：同理把 `parent_id` 带上（复用 `promote_task_question` 即可，无需额外处理）。
- `regenerate_all_task_questions` 清空草稿时删除的 Question 均为本草稿私有，不受影响。

### 6.2 题库浏览

```python
def list_bank_questions(
    *, session: Session, parent_id: uuid.UUID,
    subject: str | None = None, grade: int | None = None,
    knowledge_point: str | None = None, qtype: str | None = None,
    keyword: str | None = None, page: int = 1, page_size: int = 20,
) -> tuple[list[Question], int]:
    stmt = select(Question).where(Question.parent_id == parent_id)
    if subject:
        stmt = stmt.where(Question.subject == subject)
    if grade is not None:
        stmt = stmt.where(Question.grade == grade)
    if knowledge_point:
        stmt = stmt.where(Question.knowledge_point == knowledge_point)
    if qtype:
        stmt = stmt.where(Question.qtype == qtype)
    if keyword:
        like = f"%{keyword}%"
        stmt = stmt.where(
            (Question.stem.ilike(like)) | (Question.knowledge_point.ilike(like))
        )
    total = len(session.exec(stmt).all())
    items = session.exec(
        stmt.order_by(Question.created_at.desc())
        .offset((max(1, page) - 1) * page_size)
        .limit(page_size)
    ).all()
    # usage_count：本页 question_id 在 TaskQuestion 中的引用计数
    ids = [q.id for q in items]
    usage = {}
    if ids:
        rows = session.exec(
            select(TaskQuestion.question_id, func.count())
            .where(TaskQuestion.question_id.in_(ids))
            .group_by(TaskQuestion.question_id)
        ).all()
        usage = {qid: c for qid, c in rows}
    for q in items:
        q._usage = usage.get(q.id, 0)   # 临时挂载，路由层读取后丢弃
    return items, total
```

> `usage_count` 为展示项（"被 X 套任务用过"），不影响主流程；若不想引入临时属性，可在路由层单独查一次聚合。

### 6.3 选项 A：从题库新建任务

```python
def create_task_from_bank(
    *, session: Session, parent_id: uuid.UUID,
    title: str, child_id: uuid.UUID | None, question_ids: list[uuid.UUID],
) -> Task:
    # 仅取"属于该家长"的题，保持传入顺序
    owned = session.exec(
        select(Question).where(
            Question.id.in_(question_ids), Question.parent_id == parent_id
        )
    ).all()
    owned_map = {q.id: q for q in owned}
    if not owned:
        raise AppErrorException(ErrCode.QUESTION_NOT_FOUND, "题库中找不到对应题目")
    if len(owned) != len(set(question_ids)):
        raise AppErrorException(ErrCode.QUESTION_ACCESS_DENIED, "部分题目不存在或无权限")
    task = Task(title=title, status="draft", parent_id=parent_id,
                child_id=child_id, specs=None)  # 无 specs → 不支持整卷重生成
    session.add(task)
    session.flush()
    for qid in question_ids:               # 按传入顺序
        q = owned_map[qid]
        session.add(TaskQuestion(
            task_id=task.id, question_id=q.id,  # 复用：回指源题
            subject=q.subject, grade=q.grade, knowledge_point=q.knowledge_point,
            qtype=q.qtype, stem=q.stem, options=q.options,
            answer=q.answer, explanation=q.explanation, difficulty=q.difficulty,
        ))
    session.commit()
    session.refresh(task)
    return task
```

### 6.4 选项 B：加入已有草稿

```python
def add_bank_questions_to_task(
    *, session: Session, task_id: uuid.UUID, question_ids: list[uuid.UUID],
) -> Task | None:
    task = session.get(Task, task_id)
    if task is None:
        return None
    existing = {tq.question_id for tq in session.exec(
        select(TaskQuestion).where(TaskQuestion.task_id == task_id))}
    owned = session.exec(select(Question).where(
        Question.id.in_(question_ids), Question.parent_id == task.parent_id)).all()
    for q in owned:
        if q.id in existing:           # 去重：同一题不重复加入本任务
            continue
        session.add(TaskQuestion(
            task_id=task.id, question_id=q.id,
            subject=q.subject, grade=q.grade, knowledge_point=q.knowledge_point,
            qtype=q.qtype, stem=q.stem, options=q.options,
            answer=q.answer, explanation=q.explanation, difficulty=q.difficulty,
        ))
    session.commit()
    session.refresh(task)
    return task
```

### 6.5 级联安全（复用题库后的必改项）

题库题被多 Task 共享后，**不能**在单任务草稿里"换一题/删除"时误删共享源题。修改两处：

- `regenerate_one_task_question`（L260）：删除旧 `Question` 前，先查引用计数：
  ```python
  ref = session.exec(select(TaskQuestion).where(
      TaskQuestion.question_id == old_qid)).all()
  if len(ref) <= 1:
      session.delete(session.get(Question, old_qid))  # 仅本任务引用才删
  # 否则：保留共享源题，仅把本题 TaskQuestion.question_id 置 None 后覆盖新字段
  ```
- `remove_task_question`（L238）：同上述引用计数守卫，仅当 `len(ref) <= 1` 才删源 `Question`。

> 这样从题库组卷的任务里"换一题/删除"只会脱离该草稿副本，不会污染题库中其他任务的同一道题。

### 7.2 `tasks.py` 新增三个端点

```python
# 选项 A：从题库新建任务
@router.post("/from-bank", response_model=TaskResp, status_code=status.HTTP_201_CREATED)
def create_from_bank(*, session: SessionDep, parent: CurrentParent,
                     payload: TaskFromBankCreate) -> TaskResp:
    if not payload.question_ids:
        raise AppErrorException(ErrCode.TASK_EMPTY_SPECS, "请至少选择一道题")
    task = create_task_from_bank(
        session=session, parent_id=parent.id, title=payload.title,
        child_id=payload.child_id, question_ids=payload.question_ids)
    return _task_to_resp(task, get_task_questions(session, task.id), include_answer=True)


# 选项 B：加入已有草稿
@router.post("/{task_id}/questions/from-bank", response_model=TaskResp)
def add_from_bank(*, session: SessionDep, parent: CurrentParent,
                  task_id: UUID, payload: BankQuestionsAdd) -> TaskResp:
    task = _parent_owns_task(task=get_task(session, task_id), parent=parent)
    _require_draft(task)
    if not payload.question_ids:
        raise AppErrorException(ErrCode.TASK_EMPTY_SPECS, "请至少选择一道题")
    updated = add_bank_questions_to_task(
        session=session, task_id=task.id, question_ids=payload.question_ids)
    if updated is None:
        raise AppErrorException(ErrCode.TASK_NOT_FOUND, "任务不存在")
    return _task_to_resp(updated, get_task_questions(session, updated.id), include_answer=True)


# 家长草稿/任务列表（供选项 B 的草稿选择器）
@router.get("", response_model=list[TaskResp])
def list_parent_tasks(*, session: SessionDep, parent: CurrentParent,
                      status: str | None = None) -> list[TaskResp]:
    stmt = select(Task).where(Task.parent_id == parent.id)
    if status:
        stmt = stmt.where(Task.status == status)
    tasks = session.exec(stmt.order_by(Task.created_at.desc())).all()
    return [_task_to_resp(t, get_task_questions(session, t.id), include_answer=True)
            for t in tasks]
```

> ⚠️ **路由顺序**：`GET ""`（list）与 `GET /today`、`GET /{task_id}` 并存。现有 `tasks.py` 已把静态路径 `/today`、`/wrong-questions`、`/children/*` 放在 `"/{task_id}"` 之前。`GET ""`（无路径参数，prefix `/tasks`）与 `POST ""`（batch-generate，已有）冲突——`from-bank`/`questions/from-bank` 是子路径无冲突；`list_parent_tasks` 用 `GET ""` 会与 `POST ""` 方法不同不冲突，但与 `GET /today` 并存时 FastAPI 按方法+路径匹配，`""` 匹配 `/tasks`，`/today` 匹配 `/tasks/today`，互不干扰。保留现有顺序约定即可。

## 8. 校验与行为一致性

- **权限**：所有读取/写入均经 `CurrentParent`；`question_ids` 必须全部 `parent_id == parent.id`，否则 `QUESTION_ACCESS_DENIED`。
- **空校验**：`question_ids` 为空 → `TASK_EMPTY_SPECS`(422)。
- **选项 B 仅 draft**：非 draft 任务 → `TASK_STATUS_DRAFT_REQUIRED`(409)。
- **复用语义**：from-bank / add-to-bank 生成的 `TaskQuestion.question_id` 均回指源 `Question` → 审核页"已入题库"徽标自动点亮、"加入题库"按钮禁用；作答/错题归集正确落到共享源题。
- **整卷重生成禁用**：from-bank 任务 `specs=None`，`ParentTaskReviewScreen` 需在 `specs.isEmpty` 时隐藏"整卷重生成"按钮（前端改动，见前端文档 §7）。
