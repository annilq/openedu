# 娃娃日常学习（OpenEdu）

> 面向中小学的错题复习工具：教师生成任务，学生作答产生错题，系统按间隔重复安排复习，直到真正掌握。

面向**平板**设计，分教师端与学生端两套界面。定位是**自用 / 小班教学环境**——一位教师、若干学生（可编入班级）。数据全部留在你自己的机器或你部署的实例上。

## 学习闭环

**教师生成任务 → 学生作答 → 答错的题入错题本 → 按间隔重复复习 → 毕业**

复习间隔为 1 / 2 / 4 / 7 / 15 天，末位阶段答对即视为掌握并毕业；已毕业的错题可以由教师重新拉回复习队列。

## 角色

- **教师（teacher）**：出题、派发任务、管理班级与学生、看学情。
- **学生（student）**：答题、复习、问 AI 老师。一个学生至多属一个班级（`class_id` 可空）。

## 教师能做什么

- **AI 出题**——选学科、年级、知识点、题型、数量，题目流式生成。生成完停在原页供逐题审阅，确认后才落库；中途可停止（保留已出的题）或整份重来
- **题库**——题目长期复用、可归档，能反查每道题被哪些任务引用过
- **任务派发**——把任务派给单个学生或整班学生，看进度、正确率、连续打卡天数
- **班级与学生管理**——创建班级、添加学生，查看单个学生的错题本与 AI 答题记录
- **资料库与知识点**——上传教材 / 卷子 / 笔记等资料，系统解析出知识点目录（无资料时落回手编骨架兜底）；资料经切分与向量化支撑答疑检索。知识点按学科 × 年级受控，可随教材上传联动可见性
- **课件与课堂**——在一个知识点上组织有序讲解环节（素材画廊 / 交互场景 / 课堂练习），用于课堂演示；课堂练习由教师代录对 / 错、AI 给分级提示，不落作答记录、不进错题本
- **教师工作台**——合并后的教师 landing 入口：任务区（待办 / 最近任务 / 学生总数）、学情**速览层**（错题分布 / 正确率 / 掌握度三块全量卡片）、**分析层**（按学科 / 年级 / 学期 / 知识点下钻）
- **错题本**——查看学生的错题（含答案与解析），把已毕业的错题重新拉回
- **打印导出**——把题库 / 任务 / 错题排成纸质练习卷（只含题干与作答留白，**不含答案**），服务端用 Typst 排版
- **AI 学习助手**——统一 AI 入口：出题、查任务、查学情、查题库、伴学；带历史会话可续接
- **模型管理**——自己填模型的 API Key

## 学生能做什么

- **今日任务**——逐题作答，自动批改并看解析，完成后打卡
- **到期复习**——系统按遗忘曲线把该复习的题推到前面
- **错题本**（不显示答案）
- **问 AI 老师**——伴学答疑，带内容安全审核
- 导出自己的错题练习卷

## 你需要自己准备模型

本项目**没有内置模型，也没有离线兜底**。教师在「模型管理」里添加自己的模型（DeepSeek / OpenAI / Ollama 等）并设为默认，AI 出题与答疑才会工作；未配置时相关功能会提示「未配置模型」。

API Key 在服务端加密保存，只有你的密钥能解开。

## 技术概览

- **前端**：Flutter（Dart ≥3.5）· Riverpod · Dio · Cupertino · shadcn_ui · 平板优先
- **后端**：Python ≥3.14 · FastAPI · SQLModel · `uv` 管理依赖
- **AI**：`agent_core` 框架无关内核 + genkit 适配器；引擎统一经 `resolve_engine` 解析（只读教师 `ModelConfig` 与其 `is_default`，无内置模型目录、无本地旁路 env）
- **数据库**：SQLite（默认零依赖）/ PostgreSQL（Docker / 云）
