# 娃娃日常学习

> 给自家孩子用的 K12 错题练习工具：家长出题，孩子在平板上做，做错的题进入错题本，按遗忘曲线安排复习，直到真正掌握。

面向**平板**设计，分家长端与娃娃端两套界面。定位是**家庭自用**——一个家长、若干个孩子，数据全部留在你自己的机器上。

## 学习闭环

**家长出题 → 孩子作答 → 答错的题入错题本 → 按间隔重复复习 → 毕业**

复习间隔为 1 / 2 / 4 / 7 / 15 天，末位阶段答对即视为掌握并毕业；已毕业的错题可以由家长重新拉回复习队列。

## 家长能做什么

- **AI 出题**——选学科、年级、知识点、题型、数量，题目流式生成。生成完停在原页供逐题审阅，确认后才落库；中途可停止（保留已出的题）或整份重来
- **题库**——题目长期复用、可归档，能反查每道题被哪些任务引用过
- **派发与跟踪**——把任务派给孩子，看进度、正确率、连续打卡天数
- **掌握度看板**——按知识点看孩子的掌握情况
- **错题本**——查看孩子的错题（含答案与解析），把已毕业的错题重新拉回
- **打印导出**——把题库 / 任务 / 错题排成纸质练习卷（只含题干与作答留白，**不含答案**）
- **AI 学习助手**——一个入口出题、查任务、查学情、查题库，带历史会话可续接
- **模型管理**——自己填模型的 API Key

## 孩子能做什么

- **今日任务**——逐题作答，自动批改并看解析，完成后打卡
- **到期复习**——系统按遗忘曲线把该复习的题推到前面
- **错题本**（不显示答案）
- **问 AI 老师**——伴学答疑，带内容安全审核
- 导出自己的错题练习卷

## 你需要自己准备模型

本项目**没有内置模型，也没有离线兜底**。家长在「模型管理」里添加自己的模型（DeepSeek / OpenAI / Ollama 等）并设为默认，AI 出题与答疑才会工作；未配置时相关功能会提示「未配置模型」。

API Key 在服务端加密保存，只有你的密钥能解开。
