# WF-6 · 兴趣注入安全护栏措辞

> 类型：grilling（HITL）｜状态：开放·前沿｜阻塞：无

## Question

兴趣注入 prompt 的边界约束如何写死，确保三道硬约束不被破坏：

1. **兴趣仅作情境调味**：绝不替换或弱化 `knowledge_point` 与 `_SYSTEM` 年龄锁；出题核心仍锚定教材知识点。
2. **自由文本兴趣不是注入攻击面**：「其他爱好」自由输入需做何种清洗（去除控制字符/提示词片段、长度上限、是否做敏感词预筛）？
3. **与既有安全层兼容**：`domain/safety.py` 双层校验（输入越狱/非学习类 + 输出敏感词）、`TutorQuota` 学科白名单仍全量生效，兴趣不参与绕过。

需产出：langchain prompt 中兴趣段的**固定约束句**（参考 WF-3 草案），以及前端/后端对自由文本兴趣的**校验清单**。

## 收口方式

grilling：与用户逐条拍板约束句与校验清单。可与 WF-3 实现并行推进（相互独立）。
