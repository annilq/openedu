# WF-4 · 「按兴趣出题」模式交互设计

> 类型：prototype（HITL）｜状态：✅ **已收口（2026-08-28）**｜阻塞：WF-1（词表）、WF-3（生成能力）

## Question

「按兴趣出题」模式的入口与交互如何设计：

- 入口放在**家长出题页（F-103 表单扩展）**还是**娃娃端**？还是两处都有？
- 娃娃如何选择兴趣主题（从自己的画像词表点选）？
- 与现有「学科 + 知识点 + 题型 + 难度 + 题量」表单的关系：**叠加开关** vs **独立入口**？
- 出题意境（如「恐龙应用题」）如何向家长预览、审阅（draft 态已可见答案）？
- 是否支持一次选多个兴趣主题生成一组题？

## 收口方式

prototype：产出交互草图 / 表单字段方案供用户反应。解锁条件：WF-1 词表定稿、WF-3 生成管线就绪。

## 草稿方案（待拍板 · v0）

### 一、入口（推荐：家长出题页为主）
- **主入口**放在家长「布置练习任务」表单（`ParentTaskFormView`），复用既有 草稿→审阅→派发 闭环，安全可控、零新页面。
- **娃娃端「兴趣挑战」快捷入口（本期建议留作下一期增强）**：娃娃点自己画像里的兴趣 → 生成一张带 `focus_interest` 的草稿 → 仍走家长审阅，不绕过审核闸。本期先不做，避免娃娃端新增出题面。

### 二、与现有表单的关系：同表单内「按兴趣出题」开关（叠加，非独立页）
在现有表单（标题/总题数下方）增加可折叠「兴趣」区：
- 开关 `按兴趣出题`（默认关）。
  - **关** → 走现有逻辑，后端按娃娃画像 `interests` 自动【轻融入】（WF-3 默认行为）。
  - **开** → 出现该娃娃的兴趣词表 chips（来自 WF-1，只读展示画像，可点选），作为 `focus_interest` 下传。
- 娃娃无兴趣画像时：开关区显示「先去娃娃资料添加兴趣」，开关禁用。
- 复用 WF-5 的采集组件做点选 UI，保持视觉一致。

### 三、主题选择交互
- 展示：当前选中娃娃的 WF-1 一级分类分组，二级可展开多选（与采集 UI 同源）。
- 选中项高亮 chip，可清空。

### 四、多主题与题量分配（待拍板）
- 推荐：多选主题，题量在所选主题间**轮询均分**（如 10 题选 2 主题→各 5 题）。
- 备选：仅单选。

### 五、审阅与预览（复用既有草稿页）
- 生成后进入现有家长审阅页（答案可见）。
- 建议在每道题卡加小标签「兴趣：恐龙」，让家长一眼识别主题题。
- 需在 `Task` 记录 `focus_interest` 供打标 → **对 WF-2 的小幅扩展**：`Task` 模型加 `focus_interest: list[str]|None`（任务级，整卷共享），实现时并入 WF-2 落地。

### 六、请求/数据契约（对齐 WF-3，并修正其一处）
- `TaskSpec` / `TaskBatchCreate` 增加可选 `focus_interest: list[str]|None`（**修正 WF-3 原草案的 `str|None` 为 `list[str]`**，以支持多选；WF-3 实现时同步调整）。
- 前端 `TaskSpecModel` 同步加 `focusInterest: List<String>?`。
- 后端 `tasks.py`：多主题时按题轮询均分给各主题（实现细节，落 WF-3 时处理）。

### 七、待拍板问题（HITL）
1. 入口：家长页为主（推荐） / 家长页+娃娃端双入口 / 仅娃娃端？
2. 与表单关系：同表单开关叠加（推荐） / 独立兴趣出题入口页？
3. 多主题：支持多选均分（推荐） / 仅单选？

## 定稿（2026-08-28 · HITL 拍板）

**决策**：家长页为主 · 同表单开关叠加 · 多选主题均分。

### 交互方案（定稿）
1. **入口**：仅家长「布置练习任务」表单（复用草稿→审阅→派发闭环）。娃娃端「兴趣挑战」留作下一期增强，不进本期。
2. **表单叠加**：标题/总题数下方加可折叠「兴趣」区 + `按兴趣出题` 开关（默认关）。
   - 关 → 现有逻辑，后端按娃娃画像 `interests` 自动【轻融入】。
   - 开 → 展示选中娃娃的 WF-1 词表 chips（只读画像、点选），作为 `focus_interest` 下传。
   - 娃娃无画像 → 开关禁用 + 提示「先去娃娃资料添加兴趣」。
3. **主题点选**：一级分类分组、二级可展开多选，选中高亮 chip、可清空；复用 WF-5 采集组件保持视觉一致。
4. **多主题均分**：支持多选，`focus_interest` 为列表；题量在所选主题间轮询均分（如 10 题选 2 主题各 5）。
5. **审阅打标**：复用现有草稿审阅页；每道题卡加「兴趣：XX」小标签。需在 `Task` 记录 `focus_interest` 供打标。

### 下游契约（写回 WF-2 / WF-3）
- **WF-3 修正**：原草案 `focus_interest: str|None` 改为 **`list[str]|None`**（支持多选）；`tasks.py` 多主题按题轮询均分给各主题，落 WF-3 实现时同步调整。
- **WF-2 扩展**：`Task` 模型加 `focus_interest: list[str]|None`（任务级，整卷共享），随 WF-2 一并落地。
- 前端 `TaskSpecModel` 加 `focusInterest: List<String>?`，`_SpecRow.toSpec()` 透传。

### 开放延伸（未决，留后续会话）
- 娃娃端「兴趣挑战」快捷入口（选兴趣→建草稿→家长审阅）。
- 审阅页「兴趣」标签的视觉样式与是否可一键整卷切换主题。
