# WF-5 · 前端兴趣采集 UI（创建 + 编辑入口）

> 类型：prototype（HITL）｜状态：✅ **已收口（2026-08-28）**｜阻塞：WF-1（词表）、WF-2（schema）

## Question

`AddChildScreen` 如何扩展兴趣采集，并补齐「编辑娃娃资料」入口：

- `AddChildScreen`（`features/children/presentation/screens/add_child_screen.dart`）：在昵称/账号/密码/年级之后，加**兴趣多选 chips（来自 WF-1 词表）+ 「其他爱好」自由输入**；自由输入如何 add/remove chip。
- **当前无编辑入口**（T13 仅做了创建）。是否新增「编辑娃娃资料」页/弹窗以改兴趣（及年级）？还是首版仅创建时设、后续再补编辑？
- 字段校验（自由文本长度上限、至少/至多选几项）、与 `UserCreate` 契约（`interests: list[str]`）对齐。
- 受 300 行单文件门禁约束：采集子模块是否拆到 `features/children/presentation/widgets/interest_picker.dart`。
- `children_remote_data_source.createChild` 与 `UserModel` 需加 `interests` 透传。

## 收口方式

prototype：产出表单扩展 + 编辑入口方案草图供用户反应。解锁条件：WF-1 词表定稿、WF-2 schema 落地。

## 草稿方案（待拍板 · v0）

### 0. 约定修正（来自 WF-1，已回写 WF-2）
- `User.interests` 取值 = `{"categories": list[str], "free_text": str|null}`。
  - `categories` = **叶子 key**（选了二级存二级如"恐龙"，只选一级存一级如"动物"）。
  - `free_text` = 「其他爱好」≤50 字，或 `None`。
- 前端 `UserModel.interests` 用 `InterestsModel { List<String> categories; String? freeText; }`（fromJson/toJson）。

### 一、AddChildScreen 扩展（创建时采集）
在「年级」下方加「兴趣（选填）」区，复用新组件 `InterestPicker`：
- **一级 chips**：WF-1 的 15 个一级分类以 `Wrap` 排列，点选高亮。
- **二级下钻**：选中某带二级的一级时，其下二级以子 `Wrap` 内联展开，可多选；最终 `categories` 收叶子 key。
- **「其他爱好」**：`AppTextField`（maxLength 50）+ 添加按钮 → 设为 `free_text`（单字段，可清除 chip）。
- **校验**：兴趣整体选填；若填，categories ≤ 10；free_text ≤ 50。全空则不下传 `interests`（null）。

### 二、编辑入口（统一表单，新增与编辑共用一页）
- **用户拍板**：创建时即允许加兴趣等信息，并允许编辑，**编辑页与新增共用一个页面**。
- 方案：将现有 `AddChildScreen` 重构为**统一 `ChildFormScreen`**（或保留名但加 `mode` + 可选 `child` 入参）：
  - `mode=create`：空白表单（昵称/账号/密码/年级/兴趣）。
  - `mode=edit`：按 `UserModel` 回填；`username`/`password` 锁定（编辑态隐藏或只读，避免改登录凭证）；可改 `display_name`/`grade`/`interests`。
  - 由娃娃列表/选择页的铅笔图标以 `mode=edit` 进入；新增入口以 `mode=create` 进入。
- **后端依赖**：当前 `children.py` 仅 `POST`/`GET`，**无更新端点** → 需新增 `PUT /children/{id}`（接受 grade/display_name/interests）。属实现依赖，落地时务必补（可单列微票）；创建路径复用既有 `POST`。

### 三、文件拆分（守 300 行单文件门禁）
- 新增 `features/children/presentation/widgets/interest_picker.dart`（`InterestPicker` 组件 + `InterestsModel`）。
- `add_child_screen.dart` 演变为统一 `ChildFormScreen`（create/edit 两模式），仅挂载 `InterestPicker` 与字段，保持精简（<300 行）；旧 `AddChildScreen` 调用点改为以 `mode=create` 进入。
- 不另建 `edit_child_screen.dart`（共用同一页）。

### 四、数据层透传
- `UserModel.interests: InterestsModel?`。
- `ChildrenRemoteDataSource.createChild(...)` 加 `InterestsModel? interests`；body 不下传 null/空。
- `children_repository` / `children_notifier.createChild` 透传。
- 新增 `updateChild(id, {displayName, grade, interests})` + 远程 `putChild` + notifier 方法。

### 五、待拍板问题（HITL）
1. 编辑入口：新建编辑页（昵称+年级+兴趣，账号密码锁）/ 仅创建时设·本期不做编辑 / 编辑页仅改兴趣+年级？
2. 二级粒度：一级+可展开二级（贴合 WF-1）/ 仅一级多选？
3. 「其他爱好」：单个 50 字字段（按 WF-1）/ 允许多个自由标签？

## 定稿（2026-08-28 · HITL 拍板）

**决策**：创建即采兴趣 + 允许编辑 + **新增与编辑共用同一页面**；一级+可展开二级；「其他爱好」单个 50 字字段。

### 交互方案（定稿）
1. **统一表单页 `ChildFormScreen`**（`mode: create|edit`，可选 `child` 回填）：
   - create：昵称/账号/密码/年级/兴趣，全可填。
   - edit：按 `UserModel` 回填；`username`/`password` 锁定（隐藏/只读）；可改 `display_name`/`grade`/`interests`。
   - 入口：新增→`mode=create`；娃娃列表/选择页铅笔图标→`mode=edit`。
2. **`InterestPicker` 组件**（新文件 `widgets/interest_picker.dart` + `InterestsModel`）：
   - 15 个一级 chips（WF-1）Wrap 排列，点选高亮；带二级的一级被选中后内联展开其二级子 Wrap，多选；`categories` 收叶子 key。
   - 「其他爱好」`AppTextField`(maxLength 50)+添加 → `free_text`（单字段，可清除）。
   - 校验：整体选填；categories ≤ 10；free_text ≤ 50；全空则不下传 `interests`。
3. **数据契约**：`UserModel.interests: InterestsModel?`；`createChild(... interests)` body 不下传 null/空；新增 `updateChild(id,{displayName,grade,interests})` + 远程 `putChild` + notifier。
4. **文件门禁**：`interest_picker.dart` 抽离；`ChildFormScreen` 仅挂载、保持 <300 行；不另建 edit 页。

### 下游依赖（实现阶段必补）
- **后端 `PUT /children/{id}`**：当前仅 `POST`/`GET`，无更新端点；需新增以支撑编辑保存（接受 grade/display_name/interests）。建议单列微票或并入实现任务。
- **WF-2 已修正**：`User.interests` 形状 = `{"categories": list[str], "free_text": str|null}`（叶子 key + 单自由文本），前端对照实现。
