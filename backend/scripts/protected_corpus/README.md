# 受保护教材语料（版权合规门禁参照集）

本目录是 `copyright_compliance_check.py` 的 `--protected` 参照语料：**用于比对「待发布内容
是否对受版权保护的教材构成实质性复制」**。

## ⚠️ 重要合规约束

- **本目录不得内置任何受版权保护的教材原文**（人教版/北师大版等现行教材的例题、章节、
  题干表述）。内置即构成侵权。
- 填入本目录的内容，必须是**你方已合法取得复制/比对权限**的文本，例如：
  - 已购授权教材的 excerpts（在授权范围内仅作比对参照）；
  - 公版/自编内容（用作「清洁基线」反向验证自编内容未抄袭受保护教材，可选）。
- 参照文本只用于**本地/CI 离线比对**，不随应用分发、不入库发布产物。

## 格式

- 每个 `.txt` / `.md` 文件 = 一段受保护文本；文件名作为来源标识打印在命中报告里。
- 可放单文件或多文件、可嵌套子目录（脚本递归读取）。
- 空目录 / 仅本 README 时，脚本会因「语料为空」放行（无参照，不误阻断）。

## 填充流程（上线前由法务/合规执行）

1. 取得目标教材的合法比对授权（或确认走公版/自编路线，见 ADR-0019）。
2. 将授权范围内的 excerpts 拆段存入本目录（建议按「学科_年级_章」命名）。
3. 调阈值（`--threshold`，默认 0.5）与 n-gram 窗口（脚本内 `shingles(n=4)`）匹配教材语言密度。
4. 跑 `python copyright_compliance_check.py --db <app.db> --protected . --threshold 0.5`。
