# 实施文档：题库复用闭环（前端）

> 关联：《实施文档：题库复用闭环（后端）》。后端补齐 `GET /questions`、`POST /tasks/from-bank`、`POST /tasks/{task_id}/questions/from-bank`、`GET /tasks` 四个能力。
> 前端目标：在**家长端侧边栏新增"题库"入口**（第 6 项），提供**年级 segment 切换 + 过滤 + 多选**，支持"用这些题生成任务"（选项 A）与"加入已有草稿"（选项 B），并**复用现有 `ParentTaskReviewScreen`** 完成后续所有动作，形成产品闭环。

---

## 1. 现有模式（务必对齐，避免违和）

| 关注点 | 现有实现 |
|---|---|
| 导航 | 单 `HomeScreen`，`_parentNavIndex` 切右栏视图；`index 0-4` = 概览/布置任务/错题本/AI答疑记录/AI管控，`5` = 加娃娃页。新增"题库"用 **`index = 6`**。 |
| 跳转审核 | `ParentTaskFormView` 生成成功后回调 `_navigateToReview(TaskModel)`，由 `HomeScreen._reviewingTask` 覆盖层展示 `ParentTaskReviewScreen`。**题库视图同样接收 `onNavigateToReview` 回调**，复用该机制。 |
| 任务生成调用 | `TaskGenNotifier.generate(childId, title, specs)` → `POST /tasks/batch-generate` → `TaskModel.fromJson`。 |
| 网络层 | `NetworkService.get/post(path, query/body)`，返回 `r.data`（FastAPI 响应体原样）。`TaskResp` 直接是对象；`Children` 端点包了 `{'data': [...]}`（特例），**新端点不要包层**。 |
| 题库归属 | 家长私有；娃娃端不涉及。 |

```dart
/// 题库列表项（GET /questions 的 items 元素）。
class BankQuestionItem {
  final String id;            // Question.id
  final String subject;
  final int grade;
  final String stem;
  final List<String>? options;
  final String qtype;
  final String knowledgePoint;
  final String? difficulty;
  final String? answer;       // 家长视图可见
  final String? explanation;
  final int usageCount;       // 被多少任务引用

  BankQuestionItem({
    required this.id,
    required this.subject,
    required this.grade,
    required this.stem,
    this.options,
    required this.qtype,
    required this.knowledgePoint,
    this.difficulty,
    this.answer,
    this.explanation,
    this.usageCount = 0,
  });

  factory BankQuestionItem.fromJson(Map<String, dynamic> json) => BankQuestionItem(
        id: json['id'] as String,
        subject: json['subject'] as String? ?? '',
        grade: json['grade'] as int? ?? 0,
        stem: json['stem'] as String,
        options: (json['options'] as List?)?.map((e) => e.toString()).toList(),
        qtype: json['qtype'] as String,
        knowledgePoint: json['knowledge_point'] as String,
        difficulty: json['difficulty'] as String?,
        answer: json['answer'] as String?,
        explanation: json['explanation'] as String?,
        usageCount: (json['usage_count'] as int?) ?? 0,
      );
}

class BankListResp {
  final List<BankQuestionItem> items;
  final int total;
  final int page;
  final int pageSize;
  BankListResp({
    required this.items, required this.total,
    required this.page, required this.pageSize,
  });
  factory BankListResp.fromJson(Map<String, dynamic> json) => BankListResp(
        items: (json['items'] as List)
            .map((e) => BankQuestionItem.fromJson(e as Map<String, dynamic>))
            .toList(),
        total: json['total'] as int,
        page: json['page'] as int,
        pageSize: json['page_size'] as int,
      );
}
```

## 3. 数据源（`lib/features/.../data/datasource/question_bank_remote_data_source.dart`）

参考 `children_remote_data_source.dart` 写法（构造注入 `NetworkService`）：

```dart
import '../../../../shared/data/remote/network_service.dart';
import '../../../../shared/domain/models/models.dart';

class QuestionBankRemoteDataSource {
  final NetworkService _network;
  QuestionBankRemoteDataSource(this._network);

  Future<BankListResp> getQuestions({
    String? subject,
    int? grade,
    String? knowledgePoint,
    String? qtype,
    String? keyword,
    int page = 1,
    int pageSize = 20,
  }) async {
    final query = <String, dynamic>{
      'page': page,
      'page_size': pageSize,
    };
    if (subject != null) query['subject'] = subject;
    if (grade != null) query['grade'] = grade;
    if (knowledgePoint != null) query['knowledge_point'] = knowledgePoint;
    if (qtype != null) query['qtype'] = qtype;
    if (keyword != null && keyword.isNotEmpty) query['keyword'] = keyword;
    final data = await _network.get('/questions', query: query);
    return BankListResp.fromJson(data as Map<String, dynamic>);
  }

  Future<TaskModel> createTaskFromBank({
    required String title,
    required String childId,
    required List<String> questionIds,
  }) async {
    final data = await _network.post('/tasks/from-bank', body: {
      'title': title,
      'child_id': childId,
      'question_ids': questionIds,
    });
    return TaskModel.fromJson(data as Map<String, dynamic>);
  }

  Future<TaskModel> addToTaskFromBank({
    required String taskId,
    required List<String> questionIds,
  }) async {
    final data = await _network.post(
      '/tasks/$taskId/questions/from-bank',
      body: {'question_ids': questionIds},
    );
    return TaskModel.fromJson(data as Map<String, dynamic>);
  }

  /// 选项 B 草稿选择器：家长草稿列表
  Future<List<TaskModel>> getDraftTasks() async {
    final data = await _network.get('/tasks', query: {'status': 'draft'});
    return (data as List)
        .map((e) => TaskModel.fromJson(e as Map<String, dynamic>))
        .toList();
  }
}
```

## 4. Notifier（`lib/features/.../presentation/providers/question_bank_notifier.dart`）

状态机参照 `TaskGenNotifier`：

```dart
sealed class BankState { const BankState(); }
class BankIdle extends BankState { const BankIdle(); }
class BankLoading extends BankState { const BankLoading(); }
class BankLoaded extends BankState {
  final BankListResp data;
  final int gradeSegment; // 当前年级 segment（-1 = 全部）
  const BankLoaded(this.data, this.gradeSegment);
}
class BankError extends BankState { final String message; const BankError(this.message); }
class BankActionLoading extends BankState { const BankActionLoading(); } // 生成/加入动作中
class BankActionSuccess extends BankState { final TaskModel task; const BankActionSuccess(this.task); }
class BankActionError extends BankState { final String message; const BankActionError(this.message); }

class QuestionBankNotifier extends StateNotifier<BankState> {
  final QuestionBankRemoteDataSource _ds;
  QuestionBankNotifier(this._ds) : super(const BankIdle());

  Future<void> load({int gradeSegment = -1}) async {
    state = const BankLoading();
    try {
      final data = await _ds.getQuestions(
        grade: gradeSegment < 0 ? null : gradeSegment,
        page: 1,
      );
      state = BankLoaded(data, gradeSegment);
    } catch (e) {
      state = BankError(e.toString());
    }
  }

  Future<void> createTaskFromBank({
    required String title, required String childId, required List<String> ids,
  }) async {
    state = const BankActionLoading();
    try {
      final task = await _ds.createTaskFromBank(
        title: title, childId: childId, questionIds: ids);
      state = BankActionSuccess(task);
    } catch (e) {
      state = BankActionError(e.toString());
    }
  }

  Future<void> addToTaskFromBank({
    required String taskId, required List<String> ids,
  }) async {
    state = const BankActionLoading();
    try {
      final task = await _ds.addToTaskFromBank(taskId: taskId, questionIds: ids);
      state = BankActionSuccess(task);
    } catch (e) {
      state = BankActionError(e.toString());
    }
  }
}

final questionBankNotifierProvider =
    StateNotifierProvider<QuestionBankNotifier, BankState>((ref) {
  final ds = QuestionBankRemoteDataSource(ref.watch(networkServiceProvider));
  return QuestionBankNotifier(ds);
});
```

## 5. 视图：`ParentQuestionBankView`（新增文件 `lib/features/home/presentation/widgets/parent/parent_question_bank_view.dart`）

布局要点（贴合 `.impeccable` 中性+靛蓝设计系统、`AppCard`/`AppSpacing`/`AppTheme` 既有令牌）：

1. **顶部工具栏**
   - 标题"题库"。
   - **年级 segment 切换（默认能力，必需）**：`AppSegmented` 风格（`ShadButton` 组或现成 segmented 控件），选项 `['全部', '1年级'…'9年级']`（共 10 个，横向可滚动）。`onSelected` → 更新 `gradeSegment` 并 `notifier.load(gradeSegment: idx)`。
   - 学科筛选（chips / `AppPickerField`，值同任务表单 `['数学','语文','英语',…]`）、题型筛选（`calc/fill/choice/open`）、关键词搜索框（`AppTextField` + 防抖 300ms）。
2. **列表**：`BankListResp.items` 渲染为卡片（题干预览 + 学科/年级/知识点/题型标签 + `usageCount` 角标"用过 X 次"）。每行带**多选 Checkbox**（选中集 `Set<String>`）。
3. **底部操作栏（选中 ≥1 时浮现）**：
   - **「用这些题生成任务」**（选项 A）→ 校验 `selectedChildProvider` 非空（否则 toast"请先在侧栏选择娃娃"）→ 弹标题输入（默认"题库组卷"）→ `createTaskFromBank` → 成功 `widget.onNavigateToReview(task)` 跳审核页。
   - **「加入已有草稿」**（选项 B）→ 拉起草稿选择底部弹层（`getDraftTasks()`）→ 选一个 → `addToTaskFromBank` → 成功 `widget.onNavigateToReview(updatedTask)` 跳该草稿审核页。
4. 加载/空/错误态：复用 `AppLoading` / `_EmptyHint` 风格（空态文案"题库还是空的，去「布置任务」生成并加入题库吧"）。

> 关键：两个动作成功后都走 `onNavigateToReview` → 复用 `ParentTaskReviewScreen`，**不新写锁定/派发/练习 UI**。

## 8. 边界与校验

- 年级 segment 默认"全部"（-1），切换即重新拉取，保留其他过滤条件。
- 多选上限可不加（家长自控）；加入草稿时对重复题由后端去重。
- "用这些题生成任务"必须先选娃娃（与 `ParentTaskFormView._generate` 一致）。
- 题库列表分页：首屏 `page=1`，滚动到底加载下一页（`page++`），追加到列表；本版可仅做基础分页，无限滚动为增强项。
