# 掌握度反馈边：从薄弱知识点显式出题，以错题为原料仿写同类题

2026-09-21 对「学习闭环」做了一次逐段审计（家长出题 → 儿童答题 → 错题 → 间隔重复 → 毕业）。六段里**只有一段真正通**，其余五段的断点中有三段本质是同一件事：**错题与掌握度被算出来、存下来、画成看板，然后没有任何东西消费它们**。本 ADR 决定接上这条反馈边，并明确写下另外三条断点本轮不做。

## 背景：闭环断在哪

| 段 | 状态 | 证据 |
|---|---|---|
| 答错即建错题 | 通 | `features/tasks/service.py:1236` 答错即 `upsert_wrong_question` |
| 出题消费错题 / 掌握度 | **断** | `ai/subagents/question/pipeline.py:45-111` 入参只有 subject/grade/knowledge_point/qtype/difficulty/interests；`Mastery` 与 `WrongQuestion` 在出题侧**零引用** |
| 掌握度 → 出题出口 | **断** | `mastery_board.dart` 纯展示，无回调无 CTA；`parent_task_form_view.dart:71` 知识点是硬编码默认值 `'两位数加减法'` |
| 纸质批改回流 | 断 | `features/export/schemas.py:14-29` 无任何答案字段；`scan|ocr|grading` 全仓零命中 |
| 复习到期触达 | 半通 | 只在 `initState` 拉一次 + 手动下拉，无推送无红点 |
| 毕业 → 复检 | 断 | `graduate()` 只打时间戳，全链路 `graduated_at.is_(None)` 出队 |

前两行是同一条边的两端：**产出端有数据，消费端没入口**。所以闭环不是"转得慢"，是**根本没闭**。

## 决策

**D1 — 入口是家长显式，不自动注入。**
掌握度看板的每个薄弱知识点给一个出口，点了跳到出题表单并预填学科 / 年级 / 知识点。**AI 出题的 prompt 不会被自动塞入薄弱点**。

理由是一个无解的意图冲突：当家长想出"第三单元测试卷"时，系统偷偷混入薄弱点，出出来的既不是单元测试卷也不是薄弱专项，而模型侧无法裁决该听哪个。家长主权优先，智能让位。ADR-0054 已有的写意图路由是同一件事的对话式入口，留作后续，不在本轮。

**D2 — 粒度是具体错题的「同类题」，不只是知识点。**
这是本 ADR 里最贵的一条决定，也是用户明确选择承担的代价。

只按知识点出题有明确的失效模式：孩子在「异分母通分」上栽了三回，系统出一堆「同分母加减」，他照样全对，正确率纹丝不动，闭环白转一圈。所以出题要以**那道真正卡住他的题**为原料。

**D3 — 仿写靠 prompt 塞样例，不做相似度检索。**
把挑选出的代表错题直接作为样例塞进出题 prompt 让模型仿写。明确**不引入**向量检索、不引入题目相似度算法、不引入变式规则引擎。

代价要说清楚：仿写质量完全依赖模型，且**没有可验证的"像不像"判据**。这是 D2 附带的风险，接受。

**D4 — 代表错题的挑选在服务端，随掌握度一起返回。**
`Mastery` 每一项附带该知识点下若干道代表错题的 id（按错误次数与复习阶段降序，上限 3）。挑哪道题最值得仿写是领域规则，不能复制一份到前端；也不新增"取代表错题"端点——掌握度本来就是家长看某个知识点的唯一入口。

## Considered Options

- **① 自动注入薄弱点到每次出题**（否决）：意图冲突见 D1。它也是最智能、最难预测、最难向家长解释的一种。
- **② 只按知识点出题、不做同类题**（否决）：成本最低，但有 D2 描述的失效模式——题出了，孩子还是全对。用户明确选择承担 D2 的成本换取更准的命中。
- **③ 引入向量检索做相似题召回**（否决）：为一个家庭规模的应用引入检索基础设施，收益不确定、运维成本确定。
- **④ 纸质批改回流 / 到期触达 / 毕业复检**（本轮不做，已考虑）：三条都是闭环上真实的断点，但都属于"让环转得更快 / 更宽"。**当前这个环根本没闭合**——先闭合，再加速。

## Consequences

**题目缺少来源标记，是本决策最实的遗留。** `Question` 表只有 `subject / grade / knowledge_point`，**没有任何字段区分一道题是 AI 生成的还是家长从教辅录入的**。而 ADR-0019 的版权合规针对的就是内容复制——**仿写会把一道题的版权风险放大成 N 道**。在系统无法分辨题目来源之前，D2 的仿写能力只能在一个前提下使用：题目由 AI 生成或家长自录。这个缺口应在仿写功能上线前补上（新增 `origin` 字段），否则版权门禁（ADR-0020）扫的是产物、分辨不出源头。

**纸质路径同步定性为辅助输出**（已落 `CONTEXT.md`）：打印导出不参与学习闭环，批改结果不回流。这是设计而非缺陷。此前 `CONTEXT.md` 给了它 5 个术语条目，权重与实际不符，容易让后来的读者（含编码代理）误判。

**掌握度的语义不变**：它仍然是一个只读聚合，不因为长出出口就变成写模型。`level` / `score` 的计算逻辑不动。
