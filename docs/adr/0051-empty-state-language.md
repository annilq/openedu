# 空态设计语言：从「暂无数据」到「下一步做什么」

`Resource<T>` 的「加载 / 错误 / 空」三态会在同一页面反复切换，但此前它们各自为政：

- 家长任务页：三个 Tab 共用一句「暂无{草稿/进行中/已完成}任务」，一个 40px 图标，贴在列表区左上角（`Align(topLeft)`）。
  用户知道没有，但不知道为什么空、下一步点哪。
- 娃娃端首页：自己手搓了一个 88 硬编码黄块 + 大图标 + 标题，没走主题令牌（`AppBrutal.yellow` 写死、
  `AppElevation.hard()` 硬编码、用 `AppRadius.card` 给装饰块）。
- 家长概览「最近任务」：退化成一行灰色小字，与「加载失败 / 尚未加载」在视觉上不可区分。
- 没有共享组件，新增空态全靠复制粘贴，三态切换时版式乱跳。

本 ADR 为「空」这一态建立统一组件与文案口径。

## 决策

- **统一空态组件 `AppEmptyState`，与 `AppError` 同骨架。**
  形状相同：88 色块 / 标题 / 说明 / 行动。这样「加载 → 错误 → 空 → 有数据」切换时不会跳版式。
  差别只在语义：错误态给「重试」，空态给「下一步做什么」。

- **空态必须回答两个问题：为什么是空的、下一步做什么。**
  禁止只写「暂无数据」或「空空如也」。文案里必须有 [message]（说明原因）与 [actionLabel/onAction]（出口），
  首次空还可以给 [steps]（流程说明）。

- **按场景使用两种变体：**
  - **`AppEmptyState`**：独占一屏 / 独占一个内容区（如家长任务列表）。居中，宽度收口
    `AppLayout.contentEmpty`（440），避免大屏下说明文字拉成长行。
  - **`AppEmptyState.inline`**：卡片内 / 概览小栏等密集区。左对齐，横向 48 色块 + 标题 + 说明 + 行动，
    周围由 `AppCard` 给出边界。88 大色块在这些位置会抢走重量。

- **色块语义由 [tone] 决定：**
  - `null` = 安静态（`surfaceContainerLow` + 墨黑边 + `onSurfaceVariant` 图标），不投影；
  - 传 `AppBrutal` 撞色 = 强调态（撞色底 + 墨黑边 + `AppBrutal.onColor` 图标），带硬阴影，
    用于娃娃端等需要情绪价值的场景。

- **强调态的图标/文字对比度必须合规。**
  亮色块只能配 `AppBrutal.ink`（已登记对比度 4.83~13.25），深色块只能配 `AppBrutal.onDark`。
  统一走 `AppBrutal.onColor()`，禁止调用方随手传一个白色前景给黄色底。

- **家长任务页按 Tab 与「是否首次空」分文案。**
  三个 Tab 的「空」含义不同：草稿空是「还没出题」或「都已派发」；进行中空是「没派发」或「都已完成」；
  已完成空是「没做完」或「没派发」。文案与出口必须按 `draftCount / assignedCount / doneCount` 动态派生，
  尤其不能把用户指进另一个空 Tab。

## Considered Options

1. **保持各页面自绘空态**：会出现三态切换乱跳的三种视觉语言，且每次新增空态都要重新决策一次。拒绝。
2. **只建一个组件但文案共用**：换图标 + 一句「暂无{名词}」——没有回答「下一步做什么」，仍是死胡同。拒绝。
3. **统一组件 + 场景化文案 + 两种变体**（采用）：同骨架保证切换稳定，分变体保证密集区不抢重量，分文案保证每个空态都有出口。

## 守卫

`frontend/test/task_empty_state_test.dart`：

- 首次空讲流程并给出入口：家长任务页一个任务都没有时，显示三步流程 +「去布置任务」按钮，点击触发回调。
- 仅当前 Tab 空时指路到有数据的 Tab：只有已完成任务时，「进行中」空态按钮为「查看已完成」，点击后切换并看到任务卡片；
  不会把用户指去空的「草稿」Tab。
- 空态居中且宽度收口：88 色块与标题水平居中，说明文字宽度 ≈ `AppLayout.contentEmpty`。
- 变体几何：完整版 88/44，内联版 48/24；强调态图标取 `AppBrutal.onColor`。
- 概览内联空态：「最近任务」空时有 `AppCard` 边界与出口，不再是一行灰字。

## 后果

- 全站空态收敛到 `AppEmptyState` / `AppEmptyState.inline`，三态切换稳定，新增页面可直接复用。
- 家长任务页的三个 Tab 都有了符合当前数据状态的文案与下一步入口。
- 娃娃端空态保留情绪化的黄色撞色块，但已走主题令牌，暗色 / 密度变化时仍安全。
- 已知代价：「错误 / 空 / 加载」三态共享同一骨架，如果产品以后要求空态和错误态视觉差异更大，
  需要重新评估这一策略。
