3 · SubAgent 一览

businesspriorityroles是否跑 tool loop产出

路由顺序 = priority 降序做 triggers 子串匹配 → hints 启发式 → 落到 priority 最低者（tutor）。改 priority = 改功能。

4 · 错误码

code含义给用户的话
INPUT_UNSAFE输入被安全闸门拦下「已拦截」而非「出错」
TOOL_UNSUPPORTED模型缺原生 function calling / 把调用写成了文本换支持工具调用的模型，或关掉思维链
PROVIDER_ERROR厂商拒绝（auth 401 / 限流 429 / 网络 / 400）策展文案，指明重填密钥或稍后重试
TOOL_TURN_LIMIT超过 max_turns（默认 3）已中止，请缩小问题范围
NO_AGENT业务键没有对应实现未找到可用助手（装配问题）
AGENT_ERROR兜底助手执行出错

三类失败一律硬失败：不降级为纯文本、不重试、不继续。厂商失败的分类默认落 PROVIDER_ERROR。

6 · 被机制守住的不变量

  • 内核不 import app.*、不 import 三方库（tests/ai/test_layering_invariants.py）
  • import genkit 全仓唯一落点，且延迟导入（同上）
  • 归属判定只经 core.guard；service 不反向依赖 router/FastAPI（同上）
  • query 工具的缺席编码 ≡ 不传；枚举必含 NO_FILTER（tests/ai/test_query_tools_contract.py）
  • 思维链不当答案、不进历史；协议标记命中即硬失败（tests/ai/test_tool_loop_bounds.py）
  • 401 不说成「不支持工具调用」；密文永不作为参数传给引擎（tests/ai/test_provider_failure_attribution.py）
  • 写意图归 guide 且优先级高于 query；guide 无工具（tests/ai/test_guide_subagent.py）
  • 前端分层 main → features → shared 单向（frontend/test/feature_boundaries_test.dart）
