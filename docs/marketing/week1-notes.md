# 笔记 1 · Day 1

**支柱** P1 · **主词** AI 出题 · **目标** 搜索占位 + 首篇定调

### 封面
```
40分钟 → 3分钟
我现在怎么出题
```

### 标题（18 字）
```
AI按知识点出题，40分钟变3分钟
```

### 正文
```
带【年级】【学科】【教龄】年，出题一直是最耗时的那件事。

以前三条路我都走过：

买卷子——进度永远对不上，讲到第三单元它还在考第一单元
拼题——从三份资料里东拼西凑，难度忽高忽低
网上找——搜出来一堆，还得一道道筛，筛完发现大半不合适

现在我改成按知识点出，流程是这样的：

选学科 → 选年级 → 选知识点 → 选题型 → 填数量
生成完，题会停在那儿等我看
我一道道过，不对的删掉
确认了才存下来
最后要么派给孩子，要么直接打印

40分钟是我自己掐表记的，3分钟是从点生成到过完20道题。

中间那一步最值钱——生成完会停在原页让我逐题看，不是直接甩给我一堆就完事。以前用别的工具，生成完直接发出去了，回头发现有道超纲，收都收不回来。

还有个意外好处：题是按知识点存的，下次复习直接调，不用重新找。

当然也有不好用的：应用题它有时候编得不像人话，题干长但不自然，这种我就手写改一遍。

你们现在是买卷子还是自己出？评论区打个1或2
```

### 标签
```
#AI出题 #教师AI工具 #按知识点出题 #备课效率 #小学教学 #智能出题
```

### 发布提示

**支柱** P1 · **主词** AI 批改作业 · **目标** 搜索占位

### 封面

AI改了半年作业
说3个真话
```

### 标题（14 字）
```
AI改作业半年，说3个真话
```

### 正文
```
AI 改作业用了半年，说点真话，不吹。

真话一：选择和填空，它比我快也比我稳
客观题自动判，判完直接给解析。这部分我现在基本不自己看了。

真话二：应用题它判不了「过程」
答案对但步骤错的，它会判对。这个坑我踩过——有个孩子结果蒙对了，过程全是错的，AI 给了满分。后来改成：应用题我自己看，AI 只帮我把错的挑出来。

真话三：作文别指望它给分
错别字和病句它能挑出来，但「写得好不好」这件事它说了不算，尤其高年级。我现在只拿它做第一遍筛。

半年下来分工基本是这样：

客观题 —— AI 判，我看都不看
应用题 —— AI 挑错，我判
作文 —— AI 改字词，我评内容

省下来的时间每周大概【X】小时，我主要拿去备课了。

要说最大的变化，不是省时间，是我终于不用在晚上十点还在改口算了。

你们现在哪些题型敢全交给 AI？
```

# 笔记 3 · Day 5

**支柱** P3 效果与边界 · **主词** AI 出题 · **目标** 建立信任（这根最值钱）

### 封面
```
AI出的题
我还是一道道看
```

### 标题（14 字）
```
AI出的题，我还要一道道看
```

### 正文
```
有同行问我：AI 出题既然这么快，你为什么还要一道道看？

因为它是「生成」，不是「检索」。它不保证对。

我实打实遇到过的：

· 题里出现这个年级还没学的概念
· 应用题算出来是负数，题目问的是「还剩几个」
· 四个选项里有两个意思重复，等于三选一
· 题干读起来别扭，不像人出的，孩子会卡在理解上

这些不会每次都出现，但出现一次就是课堂事故。而且它不会告诉你「这道题我不确定」，它永远写得很自信。

所以我的流程是：

生成完 → 停在那儿 → 一道道过 → 不对的删掉或改 → 确认了才落库

20 道题过一遍大概两三分钟。比事后收回来便宜太多。

AI 帮我把「找题」的时间省了，
但没把「判断题」的责任接走。

我的看法是：AI 出题值不值得用，取决于你愿不愿意花那两三分钟。愿意，它很省；不愿意，它就是个隐患。

你们会全盘信任 AI 出的题吗？
```

### 标签
```
#AI出题 #教育AI #教师AI工具 #AI避坑 #备课 #小学教学
```

### 发布提示
- 这篇是 Week 1 **最可能出爆款的一篇** —— 敢说 AI 不行，才有人信你说的行
- **置顶评论**：「评论区有几位问是哪类题最容易出问题，我的经验是应用题和涉及单位换算的，你们呢？」（引出第二轮讨论）
- 那四条「遇到过的」**必须是你真遇到的**，逐条替换
- 结尾的开放问题要回，且回复要带反问，把评论区聊起来

# 笔记 4 · Day 6

**支柱** P1 · **主词** 学情分析 · **目标** 搜索占位 + 展示方案深度

### 封面
```
学情报告
2小时 → 10分钟
```

### 标题（14 字）
```
学情报告从2小时压到10分钟
```

### 正文
```
以前做学情报告：翻错题本、翻作业、翻上次月考，再往 Excel 里敲，差不多两小时。

现在十分钟左右，因为我不用「回忆」了。

打开先看到三块：

错题分布 —— 哪块错得多
正确率 —— 整体什么水平
掌握度 —— 哪些知识点还没过

然后可以往下钻，按学科、按年级、按学期、按知识点。钻到某个知识点发现掌握度不够，直接就着这个知识点出题，不用再回去找题。

2小时是以前的老办法，10分钟是现在从打开到导出的时间。

最省时间的其实不是图表，是「薄弱知识点」那一行——它直接告诉我要出什么题。以前这一步是我自己拍脑袋，现在有据可依。

不过有个提醒：图表能告诉我「哪里错得多」，但「为什么错」还得我自己翻错题看。数据归数据，归因归人。上次有个孩子某知识点正确率突然掉，图表只显示掉了，我一看错题才发现是那天的题干绕，不是不会。

你们做一次学情报告要多久？
```

```

# 笔记 5 · Day 7

**支柱** P5 观点 · **主词** 教育 AI · **目标** 人设立住 + 拉评论

### 封面
```
AI再强
这三件事我不交
```

### 标题（13 字）
```
我坚决不让AI做的三件事
```

### 正文
```
用 AI 半年，我给自己划了三条线。

一、不让它直接给学生下结论

「这道题你错在没看清单位」——这话它可能说得对，但我要自己过一遍才发。语气、分寸、这个孩子今天能不能接受，它判断不了。

二、不让它替我判断孩子「会不会」

掌握度是数据。数据说「未掌握」，但有时候是那天状态不好，有时候是题干绕，有时候就是粗心。这三种情况处理方式完全不同，只有看过才知道。

三、不让它碰家长沟通

给家长的话我一个字都不用 AI 写。同样一句「最近进步不大」，家长听到的可以是责备，也可以是提醒，差别全在措辞上。这个风险我不转嫁。

还有一条底线：孩子做错的题和数据，我放在自己的实例上，不往外传。

AI 帮我省时间，但不替我担责。
这三件事我永远自己来。

你们的底线是什么？评论区聊聊
```

### 标签
```
#教育AI #教师AI工具 #AI教育 #教师日常 #家校沟通 #教师观点
```
