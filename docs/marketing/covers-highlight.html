使用说明

导出尺寸：把 .card 的 zoom:.3 改成 zoom:1，页面会变成 1080×1440 实尺，逐个在浏览器里截图即可（Chrome DevTools → 选中 .card 节点 → 右键 Capture node screenshot）。

换高亮色：改 .hl 的内联 background，可选值都在 :root 里（紫 / 黄 / 绿 / 蓝 / 粉 / 橙）。一条封面只用一种，多了就废。

换插画：.art 里的 SVG 是占位线稿，两种替换方式，二选一：

  • 产品界面截图局部（推荐）—— 裁一块最关键的区域（比如出题页、学情卡片），不要整屏，不要带手机边框。
  • 手绘贴纸 —— 网上买授权素材，或让 AI 生成同色系简笔插画，统一风格后重复使用。

字体：现在是 PingFang SC。想要更重的字（参考图那种压迫感），装「思源黑体 Heavy」或「阿里巴巴普惠体 Bold」，然后改 body 的 font-family 即可。这一步对效果的提升比调任何参数都大。

两条别踩的坑
① 高亮块里的字必须还是黑色 —— 改成白字就变成「色块按钮」，荧光笔的感觉没了，这是这个风格唯一的语法底线。
② 一条封面只高亮一行。高亮两行以上，视线就没有落点了，用户会跳过。

适合发什么：成果线（A）和方法线（B）的封面都可以用这套 —— 它们靠情绪钩子拉点击率。评审线（C）的封面同样能用，但内页必须换成清单/表格，因为 C 线的目标是收藏，不是点击。
