# 笔记 6 · Day 8

**支柱** P3 · **主词** AI 批改 · **目标** 收藏率（做成一个能存下来的清单）

### 封面
```
这3类题
AI真的判不了
```

### 标题（12 字）
```
AI批改这3类题，真不行
```

### 正文
```
上次说了我让 AI 改作业，有老师问准确率到底多少。

我做了一件笨事：拿【X】份作业，AI 判一遍，我自己判一遍，然后对答案。结果如下。

能放心交的：
· 选择题 —— 基本不用看
· 填空题（答案唯一的那种）—— 基本不用看
· 计算题（结果唯一）—— 偶尔看一眼

真的不行的三类：

一、看过程的题
结果对但步骤错的，它判对。这是最坑的一类，因为分数给了，孩子以为自己会了。

二、答案不唯一的题
一题多解、开放问答、说理由的题。它认死一个答案，别的写法全判错。

三、跟书写有关的
抄写、作图、列竖式的规范性。它看不出「写得好不好」。

我的处理办法（可以直接抄）：

判完导出一张「存疑清单」
清单里的题我自己过一遍
过完把正确结果录回去

这样我实际要看的只有那十几道，不是全部。

你们现在哪类题是坚决自己改的？
```

### 标签
```
#AI批改作业 #批改作业 #教师AI工具 #小学数学 #教师效率 #AI避坑
```

### 发布提示
- **置顶评论**：「补充：为什么我不直接改那十几道而是要导出清单——因为清单可以按错误类型排序，同类错误一起看，比一题一题翻快。」
- 这篇的收藏率应该做到 **12%+**（Week 1 的基准是 8%）。达不到就说明清单不够「可抄」
- 配图：一张手写/表格形式的「能交 / 不能交」对照表（这类图最容易被收藏）

# 笔记 7 · Day 10

**支柱** P2 智能体拆解 · **主词** 教育智能体 · **目标** 影响层（教研/教培转型/从业者）

### 封面
```
AI助教里面
到底分了几层
```

### 标题（13 字）
```
AI助教里面，到底分了几层
```

### 正文
```
我不是做技术的。但跟着搭这个 AI 助教的过程里，我搞明白了它大概分几层——用老师的话讲一遍，可能比技术文章好懂。

第一层：听懂你要干嘛

同样一句「这道题」，我说「出十道类似的」和说「这题怎么讲」，它走的地方完全不一样。这一层要是做不好，你问东它答西。

第二层：去把东西拿过来

这是我最在意的一层。它要能真的去翻我的题库、翻错题本、翻我传的教材，而不是坐在那儿凭空编。

判断一个教育 AI 靠不靠谱，我就看这一层：**它是去查了，还是在编。**

第三层：说话要过一遍

它要对学生说的话，得先过一遍安全审核。这个不能省，孩子问的问题什么都有。

第四层：记住刚才说的

一段对话能续得上，换个时间回来还能接着问。不然每次都要重新讲一遍背景。

我后来发现，最容易偷懒的是第二层。有些工具看着聪明，其实全靠模型自己编——编得像模像样，但数据不是你的。

所以现在我看一个教育 AI，先问一句：它的数据从哪来？

你们用的时候会去看这个吗？
```

### 标签
```
#教育智能体 #AI助教 #教育AI #AIAgent #教师AI工具 #教育科技
```

### 发布提示
- 这篇写给**影响层**，涨粉不一定多，但会带来同行/从业者关注 —— 这是合作线索的入口
- **⚠️ 口吻红线**：全程「我跟着搭才搞明白」，不要写成教程腔。出现「架构」「模块设计」「技术栈」这类词就出戏了
- **置顶评论**：「有老师问第二层怎么判断——最简单的办法：问它一个只有你的资料里才有的东西，它答得出来就是真查了。」
- 这条置顶评论本身就是一个很好的互动钩子，会引出追问

# 笔记 8 · Day 12

**支柱** P1 · **主词** 知识点整理 · **目标** 搜索占位 + 展示真实能力

### 封面
```
三年卷子
喂进去就出知识点
```

### 标题（17 字）
```
知识点怎么整理？我把卷子喂进去了
```

### 正文
```
以前知识点目录是我手打的：翻教参，一个个敲进去，一学期敲一次，中间改了还得改。

现在我换个办法。

把教材、卷子、我自己的笔记传进去，它自己切分、解析，然后冒出来一批知识点。

它冒出来的新知识点会先标成「待审」——可以用，但不计入掌握度统计。我看了觉得对，转正，从那以后才开始参与统计。

没有资料的时候，它会落回一份手编的骨架，不至于空着。

这一步真正的价值不是省事，是**名字统一了**。

以前我手打的时候，「分数加减」有时候写成「分数的加减法」，同一个知识点在表里是两条，统计出来是散的。现在来源统一，出题和统计才对得上。

我现在的顺序是：
先传资料 → 等它冒知识点 → 我把待审的一批过一遍转正 → 然后才用这个目录出题

（自己用的教材资料，我不往外传。）

你们的知识点目录是怎么来的？手打还是有别的办法？
```

### 标签
```
#知识点整理 #教师AI工具 #备课 #教材梳理 #学情分析 #教师效率
```

### 发布提示
- **置顶评论**：「补充：待审这个设计我觉得挺关键的——新知识点先能用、但先不进统计，等我确认了才算数。不然模型冒出来个错的知识点，我的掌握度就跟着错。」
- 「名字统一了」这段是全文最专业的一句，也是最容易被同行认可的一句，别删
- ⚠️ 配图**绝对不要出现教材内页/扫描页**（版权红线）。用知识点列表截图（打码）代替

### 正文
```
我把自己一天过了一遍，一项项标了能不能交给 AI。给同样当班主任的参考。

7:30 到校 · 收作业查谁没交
能。系统自己记，谁交了谁没交一目了然
（以前我要拿个本子记）

上课
不能。这个没商量

课间 · 学生来问问题
能一半。简单的答疑它可以接，但它答完我会扫一眼
（它有安全审核，这个我是放心的）

午休
不能，吃饭

批改作业
能一半。客观题它判，过程和作文我自己来（见上一篇）

放学前 · 今天学情小结
能。错题分布、正确率、哪些知识点没过，直接看

给家长发消息
不能。一个字都不让它写

算下来一天大概省【X】分钟。

但说实话，最省的不是时间，是我不用一直记着这些琐事——谁没交作业、哪块错得多、明天该复习什么。脑子腾出来之后，上课反而松弛了。

你们一天里最想甩出去的是哪件事？
```

### 标签
```
#教师效率 #班主任 #教师AI工具 #教师日常 #班级管理 #教师日常分享
```

### 发布提示
- 这篇要**轻松**。前面几篇都在讲方法和判断，这篇给读者喘口气，也最容易引发共鸣式评论

- **置顶评论**：「有老师问安全审核是什么意思——就是它给学生答的话会先过一遍，不合适的不往外发。这个是我敢让它接答疑的前提。」
