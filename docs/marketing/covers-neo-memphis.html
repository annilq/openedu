怎么用

  • 正面卡片是 3:4，小红书封面标准比例。导出时用浏览器缩放或直接截到 1080 × 1440。
  • 底色是可以换的。九张刻意用了八种底色，是为了让主页九宫格看起来有节奏；如果你想要更统一的调性，可以只留三四种循环。
  • 主标控制在 4–6 个字一行，最多两行。超过两行在信息流缩略图里会糊。
  • 副标是全篇的「钩子」，不要写成标题的复述——它负责让人点进来，不是解释标题。

和产品的关系

  • 这套封面是内容物料，用的是新孟菲斯：明亮、几何、轻盈、无重描边。
  • 产品 UI 用的是新粗野（ADR-0044）：高饱和撞色 + 2px 墨黑描边 + 硬阴影，有分量感。
  • 两者不冲突，也不需要统一——一个是让人放松地点进来，一个是让人专注地用工具。但不要在封面上直接截产品界面，两套语言撞在一起会都变弱；产品截图放在笔记内页即可。
