# Spec：教师端课件第二轮（编辑器 / 素材库 / 练习 / 投影深化）

> 决策依据：[ADR-0067 教师端课件（按知识点组织的有序讲解环节）](../adr/0067-teacher-courseware-by-knowledge-point.md)。
> 依赖：首轮切片（§6.1 切片 1-8）已落地——独立 Courseware 表、课件端点与 AI 起草、素材上传端点、演示页、练习上下文、导航接线、投影分辨率实测。
> 术语以 `CONTEXT.md` 为准（课件 / 讲解环节 / 课件素材 / 课堂练习）。
> Triage: ready-for-agent
> 本文件是 GitHub issue 的正文源；落库后以 issue 为准。
> 范围：ADR-0067 首轮之后、§5 明确不做之外的深化项。

## Problem Statement

首轮课件已经打通最小闭环：从知识点行进编辑器（AI 起草 → 教师调）→ 演示页投影 → 课堂练习（出题 + 判错提示），并且素材上传、练习上下文、投影分辨率都已实测通过。但每一处都还是「能跑通」的最小版：

1. **编辑器只能线性增删、不能重排。** 环节是固定顺序列表，教师想调换讲解顺序只能删了重加；话术是单文本框，多段引导、重点标注无处放。
2. **素材没有「库」。** 教师每次进课件都得重新上传同一张图；平台预置的 CC0 素材（ADR-0067 §3.5 已规划）还没入库，空态只能引导教师自己传。
3. **练习提示级别不可选。** 答错后 AI 给分级提示（决策 11 已定三级：方向 / 条件 / 下一步），但首轮只走默认档，教师没法按现场气氛选级别。
4. **投影翻页只能点按钮。** 教室常用翻页笔（蓝牙 HID），首轮没接键盘 / 遥控器事件；大屏字号档、环节切换过渡也还没做，长时间讲课容易视觉疲劳。
5. **AI 重起草是「先建后删」的硬覆盖。** 教师看不出新版相对旧版改了哪几处，只能盲接受或盲丢弃。

这些问题单独都不致命，但叠加起来让「课件」从「能讲课」到「好讲课」之间还差一轮打磨。

## Solution

在不动 ADR-0067 已定架构（独立表、kind 注册表、AI 起草 + 教师调、练习不建任务、无素材不降级）的前提下，分四个深化方向：

- **编辑器增强**：环节支持拖拽重排与批量删除；话术支持多段与轻量重点标注；素材项在环节内联增删；AI 重起草返回 diff 预览，教师逐段接受。
- **素材库闭环**：新增教师「素材库」总览（跨课件检索复用自己传过的素材）；维护期把 CC0 预置包按「逐张核授权 + 记录来源」入库，打 `source=platform_cc0` 标记，与自有素材在 picker 里并列可选。
- **练习深化**：课堂练习环节暴露「提示级别」选择（方向 / 条件 / 下一步），按所选级别调 tutor 给出对应档提示；判错反馈卡片明确「哪错、给哪级提示」，且重申不建任务、不落作答。
- **投影交互**：演示页接键盘 / 翻页笔事件翻页；字号随可用宽度升档；环节切换加轻过渡；横屏安全区与长时间演示的视觉节奏加固。

## User Stories

### 编辑器

1. 作为教师，我想拖拽环节卡片重排讲解顺序，以便把导入的新环节插到合适位置而不必删了重加。
2. 作为教师，我想一次选中多个环节批量删除，以便快速清掉草稿里整段不要的内容。
3. 作为教师，我想在话术里分多段写引导语（开场 / 追问 / 收尾），以便投影时逻辑更清楚。
4. 作为教师，我想给话术里的关键词加重点标注（加粗 / 高亮），以便投影时学生一眼看到要点。
5. 作为教师，我想在 media_gallery 环节里内联增删素材项，而不必退出到别处再回来。
6. 作为教师，我在重起草后想看到新稿相对旧稿改了哪几处（diff 预览），以便逐段决定接受还是保留原稿。
7. 作为教师，我想对 diff 逐段选择「用新版 / 留旧版」，以便 AI 起草只是辅助而不是覆盖。
8. 作为教师，我希望拖拽重排后步骤条与「n / N」计数实时更新，以便我知道当前讲到第几步。

### 素材库

9. 作为教师，我想在素材 picker 里看到我自己传过的所有素材（跨课件），以便同一张图不用传第二次。
10. 作为教师，我想按知识点或文件名检索我的素材库，以便在长列表里快速定位。
11. 作为教师，我希望平台预置的 CC0 素材出现在 picker 里并标注来源，以便我不用自己找图也能有合规素材。
12. 作为教师，我想点开 CC0 素材时看到它的授权来源与许可说明，以便我放心用在课堂。
13. 作为教师，我希望 CC0 素材与自有素材在 picker 里同一交互选择，以便不增加学习成本。
14. 作为维护者，我想在入库 CC0 素材时强制记录来源 URL 与许可类型，以便后续审计授权。
15. 作为教师，我想删除自有素材后，引用它的环节显示「素材已移除」占位（沿用首轮决策 10），以便不破坏课件结构。
16. 作为教师，我误删素材后希望仍能重新上传恢复，以便不丢内容。

### 练习深化

17. 作为教师，我想在课堂练习环节选提示级别（方向 / 条件 / 下一步），以便按现场气氛给不同强度的引导。
18. 作为教师，我选「方向」级时，希望 AI 只提醒观察方向，不给关键条件，以便保留学生思考空间。
19. 作为教师，我选「下一步」级时，希望 AI 指出下一步操作但不给最终答案，以便不替代学生推导。
20. 作为学生（被教师代录时），我希望答错后得到的是分级提示而非直接答案，以便我仍能自己想通。
21. 作为教师，我希望判错反馈卡片写明「哪错 + 给的是第几级提示」，以便课后复盘。
22. 作为教师，我希望练习环节始终不建任务、不落作答记录、不进错题本（沿用 ADR-0067 §3.6），以便课堂即时内容不留痕。
23. 作为教师，我希望未配置模型时练习环节给出明确提示（而非静默失败），以便我知道去哪配模型。

### 投影交互

24. 作为教师，我想用翻页笔（键盘右 / 左或 HID 翻页键）翻环节，以便在讲台远端也能控场。
25. 作为教师，我希望演示页在大屏下字号自动升档，以便后排学生看得清。
26. 作为教师，我希望环节切换有轻过渡（不刺眼），以便学生注意力平滑转移。
27. 作为教师，我希望横屏投影下内容不被刘海 / 安全区切掉，以便四角信息完整。
28. 作为教师，我希望投影页始终全屏、无侧栏无底栏（沿用 ADR-0059 单源），以便课堂零干扰。
29. 作为教师，我希望长时间演示后页面不出现布局漂移 / 重排跳动，以便稳定。
30. 作为教师，如果设备是触屏笔记本，我希望点按翻页也仍然可用（与键盘并存），以便不同教室设备都能用。

### 通用 / 边界

31. 作为教师，我希望上述所有改动都不引入 Material 系控件（沿用 App 根 ShadApp + CupertinoApp 约束），以便不触发真机构建崩溃。
32. 作为教师，我希望每个新增文件不超过 400 行、单一公开物（ADR-0058），以便可维护。
33. 作为教师，我希望后端改动继续走归属守卫（core.guard）与分层不变量（presentation 不 import data），以便不回归。

## Implementation Decisions

**编辑器**

- 环节顺序改为可序列化序位字段，重排即更新序位（不重建行），步骤条与「n / N」计数读序位派生。
- 话术从单字符串升级为有序段列表（每段：文本 + 可选重点标记），渲染层逐段投射到提问卡；重点标记走既有的轻量富文本（加粗 / 高亮），不引入新渲染引擎。
- 素材项在 media_gallery 环节 payload 内联增删，复用首轮已落地的素材 picker。
- AI 重起草返回「逐段 diff」（新增 / 删除 / 修改），编辑器渲染 diff 预览，教师逐段接受；接受结果写回同一课件，不新建副本。

**素材库**

- 新增教师素材库检索端点：按知识点 / 文件名过滤返回该教师全部课件素材（含自有与 CC0）。
- CC0 预置包走维护期入库（非运行时联网，符合 ADR-0067 §3.5 / §5）：每张图带 `source=platform_cc0`、来源 URL、许可类型，随仓库分发；picker 与自有素材并列、同一选择协议。
- 删除自有素材沿用决策 10：允许删，引用环节显示「素材已移除」占位，不级联、不引用计数。
- 复用首轮 asset 端点（上传 / 列表 / 删除 / file 取回），不新增独立存储。

**练习深化**

- 课堂练习环节 payload 增「提示级别」字段（方向 / 条件 / 下一步，默认方向）；演示页练习组件暴露级别选择。
- 级别经「课件练习」上下文透传给 tutor（沿用 ADR-0067 的 courseware.extra 透传机制），tutor 按级别给对应档提示（首轮已实现的 `_courseware_hint_context` 分级约束在此被显式驱动）。
- 判错反馈卡片呈现「错误点 + 提示级别」，并附「本练习不建任务、不落作答」说明（沿用 §3.6 取舍）。
- 未配置模型：practice 组件与 guide 出题同款处理，明确提示去模型管理配置。

**投影交互**

- 演示页监听键盘 / 翻页笔事件（右 / 下 / 空格 = 下一步，左 / 上 = 上一步），与现有按钮翻页并存。
- 字号档随 `AppContentFrame` 可用宽度升档（大屏取更高档），步骤条与主区同步。
- 环节切换加轻过渡（非破坏性、尊重 reduced-motion 偏好）；横屏安全区按 `MediaQuery` padding 收边。
- 全程复用首轮 `AppPushedPage` 全屏壳，不引入导航目的地、不破坏 ADR-0059 单源。

**架构纪律（继承 ADR-0067 与项目既有约束）**

- 新文件 ≤ 400 行、单一公开物（ADR-0058）；presentation 不 import data 层（R4 棘轮）；归属走 core.guard；后端分层 service/router/repository 不混写；前端单向依赖（features → shared）。
- 全仓禁用 Material 系控件（App 根 ShadApp + CupertinoApp），新增可点区一律 AppFocusableAction 或其派生。

## Testing Decisions

**主测试缝一：后端 REST 端点。** 沿用仓库既有端点测试缝——FastAPI TestClient 打真实临时 SQLite 库（夹具 `tests/conftest.py` 的 `client`，身份助手 `tests/utils/user.py`），与首轮课件测试同源。只断言外部行为：发请求看响应，再看 GET 与登录教师 / 学生视角，不直接调内部函数。

必测：环节重排后序位正确、步骤计数派生正确；素材库检索按知识点 / 文件名过滤；CC0 素材带 source 标记与来源字段；练习提示级别透传后 tutor 给对应档（用 mock provider 断言提示文本强度）；删除自有素材后引用环节返回「已移除」占位；越权（别的教师读我素材库）403。

**主测试缝二：前端 widget 测试。** 沿用首轮课件 widget 测试缝（flutter test，页面自包裹 AppPushedPage、不依赖 Material 祖先、关代理单进程避免抢 build/test_cache 锁）。只断言外部行为：拖拽重排后步骤条更新、媒体查询宽度升档后字号档变化、键盘事件翻页生效、分级提示 UI 选级后请求体带级别。

必测：1920×1080 / 1366×768 / 1024×768 三档下编辑与演示均不溢出（沿用首轮切片 8 实测）；reduced-motion 下过渡不生效；翻页笔键盘事件与按钮翻页等价。

**既有守卫（不新增 seam）**：改 `features/*/service.py` 必跑 `tests/ai/test_layering_invariants.py`（归属与分层 AST 守卫）；pytest 沙盒须 `--basetemp`。

## Out of Scope

（继承 ADR-0067 §5 明确不做，本 spec 不重新打开）

- 顶层「课件」菜单项（入口仍在知识点行内）
- 学生端查看课件
- 课件跨教师共享 / 课件市场
- 课堂练习的作答记录、错题回流、掌握度更新
- 新建「课堂练习」实体与学生端同步作答
- 运行时联网拉取素材（CC0 预置走维护期入库）
- 无素材时降级为程序化示意图形
- 视频 / 音频素材（仍只图片）
- 公式渲染（仍字面串占位）
- 「画对称轴」新交互：点击两点定轴 / 手指自由画线（演进项，不进本轮）
- 独立课堂引导能力

## Further Notes

- **编辑器重排是序位更新而非行重建**，这点和首轮「环节可增删改序」决策一致，只是把「改序」从删除重建升级为拖拽。
- **CC0 预置包是维护期入库、离线分发**，不是运行时联网——这是 ADR-0067 §5 的硬边界，任何「在线图库」思路都不在本 spec 内。
- **练习分级提示是首轮已落地能力的「前端显式化」**：后端 `_courseware_hint_context` 三档约束已就绪，本轮只是让教师能选档，不新增模型行为。
- **投影交互必须与首轮切片 8 的「不溢出」结论共存**：字号升档不得破坏 1080 居中列约束（AppPushedPage → AppContentFrame contentWide=1080），测试须钉住。
- 所有改动继续受认知约束：禁用 Material 控件、400 行棘轮、R4 不变量、归属守卫——这些是回归高发区，测试缝已覆盖。
