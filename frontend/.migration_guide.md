# 迁移契约（临时）— Material → 纯 Cupertino

目标：彻底移除 `package:flutter/material.dart`，改用 `package:cupertino_ui/cupertino_ui.dart` 纯 Cupertino 设计系统。**保持所有业务语义、流程、回调、文案、数据逻辑完全不变**，仅替换表现层。

## 1. 颜色
- 删除 `final scheme = Theme.of(context).colorScheme;`，改为 `final app = AppTheme.colorsOf(context);`
- 所有 `scheme.XXX` / `theme.colorScheme.XXX` → `app.XXX`
- 字段映射：primary,onPrimary,primaryContainer,onPrimaryContainer,secondary,onSecondary,secondaryContainer,onSecondaryContainer,tertiary,onTertiary,tertiaryContainer,onTertiaryContainer,error,onError,errorContainer,onErrorContainer,surface,onSurface,surfaceContainerLowest,surfaceContainerLow,surfaceContainer,surfaceContainerHigh,surfaceContainerHighest,onSurfaceVariant,outline,outlineVariant,inverseSurface,onInverseSurface
- 若文件已用局部变量名 `theme`，按上面同理替换。

## 2. 文字
- `Theme.of(context).textTheme.XXX` → `AppTheme.textOf(context).XXX`（返回非空 TextStyle，`?.copyWith` 仍合法）
- 可用 `final text = AppTheme.textOf(context);` 再 `text.XXX`

## 3. 组件等价替换
| Material 原写法 | Cupertino 替换 |
|---|---|
| `Card(...)` | `AppCard(padding:, margin:, color:, radius:, onTap:, child:)`（app_theme.dart） |
| `ScaffoldMessenger.of(ctx).showSnackBar(...)` | `AppToast.show(ctx, msg)` 或 `AppToast.error(ctx, msg)`（shared/widgets/app_toast.dart） |
| `FilledButton(...)` / `FilledButton.icon(...)` 主提交（整宽/加载态） | `AppPrimaryButton(label:, onPressed:, loading:)`（app_theme.dart） |
| 其它 `FilledButton.tonal` / 内联按钮 | `CupertinoButton.filled(...)`（可带 icon+Row）或 `CupertinoButton(...)` |
| `TextButton(...)` | `CupertinoButton(child: Text(...))` |
| `CircularProgressIndicator` | `CupertinoActivityIndicator(radius:)`；按钮 loading 用 `AppPrimaryButton.loading` |
| `LinearProgressIndicator` | `AppProgressBar(value:, height:, color:, trackColor:)`（app_theme.dart） |
| `Icons.XXX` | `CupertinoIcons.XXX`（映射见 §4；项目不属于 Material Icons） |
| `AlertDialog` / `showDialog` | `CupertinoAlertDialog` / `showCupertinoDialog` / `showCupertinoModalPopup`（若已如此则保留） |
| `Divider(...)` | `Padding(horizontal) + Container(height:1,color:app.outline)` |
| `Switch/Checkbox/Radio` | `CupertinoSwitch` / `Checkbox`(cupertino) / `CupertinoRadio`（cupertino_ui 提供无前缀同名类） |
| `DropdownButtonFormField` / `DropdownMenu` | `AppPickerField<T>(label:, values:, labels:, value:, onChanged:, errorText:)`（shared/widgets/app_inputs.dart） |
| `TextFormField`/`TextField`/`InputDecorator` | `AppTextField(label:, controller:, obscureText:, prefixIcon:, errorText:, hintText:, enabled:, onChanged:, onSubmitted:)`（shared/widgets/app_inputs.dart） |
| `Form`/`GlobalKey<FormState>`/`validator` | **移除**；改为手动校验并传 `errorText` 到 AppTextField/AppPickerField，验证逻辑不变 |

## 4. 图标映射选择
- check_rounded→`checkmark`，check_circle_rounded→`checkmark_circle_fill`，warning_amber_rounded→`exclamationmark_triangle`，info_outline_rounded→`info`，auto_awesome_rounded→`sparkles`，sentiment_dissatisfied→`frown`，refresh_rounded→`refresh`，person→`person`，house→`house`，home→`house`，menu→`ellipsis`，arrow_back→`chevron_left`，add→`add`，edit→`pencil`，delete→`trash`，settings→`gearshape`，timer→`clock`，stars→`star`，send→`paperplane`，mic→`mic`，attachment→`paperclip`，lock→`lock`，visibility/visibility_off→`eye`/`eye_slash`，close→`xmark`，done→`checkmark`，keyboard_arrow_*→`chevron_*`，其它按语义就近选择 `CupertinoIcons`。

## 5. import
- 删除 `import 'package:flutter/material.dart';`（全文件删除）
- 顶部新增：`import 'package:cupertino_ui/cupertino_ui.dart';`
- 保留/新增：`app_theme.dart` 的 import（若引用 AppTheme/AppColors/AppCard/AppPrimaryButton/AppProgressBar/AppSpacing/AppRadius）
- 若用 AppToast：新增 `shared/widgets/app_toast.dart` 的相对 import
- 若用 AppTextField/AppPickerField：新增 `shared/widgets/app_inputs.dart` 的相对 import
- **相对 import 基址**：仅需把同文件里已有的 `app_theme.dart` import 路径中的 `theme/app_theme.dart` 替换为 `widgets/app_toast.dart` 或 `widgets/app_inputs.dart` 即可得到正确路径。

## 6. wrapper 语法迁移（Cupertino 无 Material 专属包裹）
- `Scaffold`/`CupertinoPageScaffold` 已基本就绪；业务页若是 `CupertinoPageScaffold` 保持。
- 不要引入 Material 专属 widget（InkWell→CupertinoButton/GestureDetector、SafeArea 保留）。

## 7. 完成后
子代理完成文件后，主代理会运行 `flutter analyze --no-pub` 统一修复。请尽量让文件自洽，不遗漏 material 引用。
