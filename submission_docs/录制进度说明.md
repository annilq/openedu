# 演示视频录制进度说明（10 步版）

> 这是你录制时的**对照表 + 逐段脚本**。命令细节见 `录制方案与命令手册.md`，旁白文案见 `narration.md`（已同步改为 10 段）。
> 内容依据是当前代码里真实的页面与按钮文案，不是凭印象写的——照着点就能对上。

---

## 0. 先记住三句话

1. **总目标 ≤8 分钟**：本方案 10 段合计 **7 分 25 秒**（445 秒），留 35 秒缓冲。每段都有红线，超了就是讲太细。
2. **分段录，不要一口气录完**。`./submission_docs/record_app.sh 1` 到 `10`，一段一个文件。录坏哪段只重录哪段，不影响别的。
3. **有一条暗线不在你的 10 步里，但必须做**：第 9 步派发任务之后、第 10 步「概览」之前，要**产生真实的作答记录**，否则概览里的学情图表全是「暂无数据」。做法见 §3 第 9 段的收尾。

|---|---|---|---|---|---|---|

| 2 | 登录 | 学生学习 / 登录 | **15 s** | 0:40 | 已有账号一键进入 | >25 s = 多余 |
| 3 | 模型管理 | AI 模型管理 | **50 s** | 1:30 | 模型自己加、能测通、能设默认 | >65 s = 测连接等太久没剪 |
| 4 | 素材库 | 素材库 | **25 s** | 1:55 | 素材只收自己上传的图 | >35 s = 在上传流程上纠缠 |

| 7 | 课件（含 AI） | 课件 / 编辑器 / 演示 | **85 s** | 4:50 | 零课件 → AI 起草 → 上讲台 | >105 s = 环节编辑逐个展开 |

## 2. 录制前准备（一次性，约 30 分钟）

### 2.1 必须准备的素材

| 用途 | 准备什么 | 注意 |
|---|---|---|
| 模型管理 | **一个真实可用的 API Key**（DeepSeek 最省事） | 没有 Key，「测试连接」会变红，后面所有 AI 全崩 |
| 素材库 | **2～3 张图片**（几何图、教材插图、错题照片都行） | 你自己能用的图即可，本作品不做平台预置 |
| 资料库 | **1 份教材/试卷 PDF，1～3 页就够** | ⚠️ 别用几十页的，向量化会等很久 |
| 学生 | **想好 1 个学生**：昵称、登录账号（如 `dabao`）、密码 | 账号不能重复 |
| 注册 | **一个没用过的教师用户名** | 已经存在的会报错重录 |

### 2.2 环境检查（录之前跑一遍）

```bash
# 1) 后端起来
cd backend && uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 2) 前端起来（API_BASE 用局域网 IP，别用 127.0.0.1）
cd frontend && flutter run -d macos --dart-define=API_BASE=http://<本机局域网IP>:8000
```

- [ ] 窗口**摆好位置、调好大小**（建议 1280×800 左右），录制期间别动它
- [ ] 屏幕**干净**：关掉聊天窗口、关掉通知（勿扰模式）
- [ ] 终端已授权「屏幕录制」权限（系统设置 → 隐私与安全性 → 屏幕录制）
- [ ] 先空跑一次 `./submission_docs/record_app.sh 1`，随便录 5 秒 Ctrl-C，确认真能出片

## 3. 逐段脚本

> 每段格式：**🎯 主题** → **🖱 操作** → **⏱ 节奏** → **⚠️ 坑**
> 录制命令统一为 `./submission_docs/record_app.sh <段号>`，建议加 `DURATION=` 兜底防手滑录太久。

---

### 第 1 段 · 注册（目标 25 s）

**🎯 主题**：教师账号门槛极低——用户名、密码、昵称，三个字段开号。

**🖱 操作**
1. App 打开 → 登录页（品牌区「学生学习」）— 停 1 s
2. 点底部 `没有账号？注册教师账号` → 表单切成「注册」，标题变「注册」，出现第三个字段 `昵称` — 停 1 s
3. 依次填 `用户名` → `密码` → `昵称`（每填一个停半秒）
4. 点 `注册并进入` → 直接进教师端「工作台」

**⏱ 节奏**：填字要**慢**，让观众看清三栏。打完密码后停 1 s 再点注册。
**⚠️ 坑**
- 密码至少 4 位，别用 3 位的被拦。
- 用**没用过的用户名**，否则弹错误提示要重录。
- 注册成功会自动登录，这一段**不要**再演"登录"——登录留给第 2 段。

```bash
DURATION=40 ./submission_docs/record_app.sh 1
```

---

### 第 2 段 · 登录（目标 15 s）

**🎯 主题**：已有账号直接进。

**🖱 操作**
1. 点侧栏底部 `我的` → 页面底部主按钮 `退出登录` → 确认弹窗点确认
2. 回到登录页（此时是「登录」态，只有两个字段）— 停 1 s
3. 填 `用户名` → `密码` → 点 `登录` → 进入「工作台」

**⏱ 节奏**：这是最短的一段，别加词。填完直接点。
**⚠️ 坑**：退出登录在「我的」页里，不在侧栏其他位置。

```bash
DURATION=30 ./submission_docs/record_app.sh 2
```

---

### 第 3 段 · 模型管理（目标 50 s）

**🎯 主题**：模型**由你手动添加**、能**测通**、能设默认——不是内置一堆看不见的模型。

**🖱 操作**
1. 侧栏点 `模型管理` → 页面标题 `AI 模型管理`，此时「我的模型」是空的 — 停 1 s
2. 点 `添加模型` → 弹窗出现 — 停 1 s
3. `服务商` 下拉选 **DeepSeek** → `Base URL` 自动带出
4. 填 `模型名`（如 `deepseek-chat`）→ 填 `API Key`
5. 点 `测试连接` → **等结果条变绿**（真实调用，约 3～10 s，见下方"等待怎么处理"）
6. 打开 `设为默认模型` 开关 → 点 `保存`
7. 列表出现模型卡，带 `默认` 徽标 — 停 1 s 收尾

**⏱ 节奏**：这 50 秒里有 10 秒是等测试连接，是正常的、也是**要展示的**（证明真的连上了）。别因为等就慌。
**⚠️ 坑**
- 不填 Key 就保存 → 列表会有个连不上的模型，后面 AI 全废。
- `测试连接` 失败就重来，别继续往下录（后面全依赖它）。
- 预设里还有通义千问 / 智谱 / 豆包 / Kimi / Ollama，**不用都点**，点到 DeepSeek 就够。

```bash
DURATION=70 ./submission_docs/record_app.sh 3
```

---

### 第 4 段 · 素材库（目标 25 s）

**🎯 主题**：素材只收**你自己上传**的图片，不做平台预置。

**🖱 操作**
1. 侧栏点 `素材库` → 空态 `素材库还是空的` — 停 1 s（空态本身就是卖点，别跳过）
2. 点 `上传图片` → 从本地挑 2～3 张
3. 网格出现缩略图 — 停 1 s
4. 点其中一张 → 放大查看原图 → 关闭
5. （可选）鼠标扫过检索框 `按文件名检索素材库`，别真打字

**⏱ 节奏**：上传是瞬时的，别在这等。
**⚠️ 坑**：多选上传时**一次选完**，别来回开两次文件框（会显得笨）。

```bash
DURATION=40 ./submission_docs/record_app.sh 4
```

---

### 第 5 段 · 资料库（目标 55 s）

**🎯 主题**：**传教材 → 向量化 → 自动提取知识点**，后面出题会参考它。

**🖱 操作**
1. 侧栏点 `资料库` → 标题 `资料库`，上方显示 `资料` / `知识点管理` 两个分段 — 停 1 s
2. 点 `上传资料` → 选那份 PDF → 行出现，状态徽标先是 `未向量化`
3. 鼠标移到该行 → 点行内 `向量化` → **等状态变成已向量化**（这几秒见"等待怎么处理"）
4. 切到 `知识点管理` 分段 → 选好 `学科 / 年级 / 学期` 范围条
5. 知识点列表出现（可能是"待审"态）→ 勾选几个 → 点 `确认选中 (N)`
6. 停 1 s 收尾（这些知识点马上要在课件里用到）

**⏱ 节奏**：这是**最容易被录太长**的一段。向量化的实时等待，后期**必须加速 2～4 倍**，否则这里就吃掉 1 分钟。
**⚠️ 坑**
- **务必用 1～3 页的小 PDF**。几十页的教材向量化能等好几分钟。
- 行内操作有 `向量化 / 重提取 / 移动 / 删除` 四个，**只点 `向量化`**，别手滑点到删除。
- 如果这里没提取出知识点，**第 7 段课件就选不了知识点**——务必确认列表非空再往下录。

```bash
DURATION=90 ./submission_docs/record_app.sh 5
```

---

### 第 6 段 · 场景库（目标 35 s）

**🎯 主题**：内置**交互式讲解图形库**，随版本发布，可关联到知识点。

**🖱 操作**
1. 侧栏点 `场景库` → 列表显示若干场景卡（每卡：场景名、`kind：xxx`、`内置实例 N 个`、关联知识点标签）— 停 1.5 s
2. 点其中一张场景卡 → 进详情页 `场景实例`，能看到 `库默认演示图形` 的图形预览 — 停 1.5 s
3. 点 `关联知识点` → 选一个刚在资料库提取的知识点 → 确认
4. 停 1 s 收尾

**⏱ 节奏**：35 秒够用。重点是**让图形动一下 / 看清**，这是本作品的差异化卖点。
**⚠️ 坑**
- **别点右上角 `新增场景`**——它只会弹一句「场景由开发者登记」的说明，点了反而显得功能没做完。
- 如果详情页是空的（`还没有知识点引用...`），说明第 5 段的知识点没选好，回第 5 段补。

```bash
DURATION=50 ./submission_docs/record_app.sh 6
```

---

### 第 7 段 · 课件（含 AI）（目标 85 s）

**🎯 主题**：**零课件 → AI 起草 → 上讲台**，一条龙。

**🖱 操作**
1. 侧栏点 `课件` → 标题 `课件`，空态 `还没有课件` — 停 1 s
2. 点 `新增课件` → 弹窗：`知识点` 下拉选第 5 段提取的那个 → `课件标题`（可留空）→ 点 `创建空课件`
3. 自动进入**课件编辑器**（本作品约定：**建空课件不触发 AI**，等你主动点）— 停 1 s
4. 点 `AI 补充讲解` → **等环节草案生成**（一次性返回，非流式，几秒～十几秒）
5. 环节列表出现若干环节 — 停 1.5 s（让观众看到"AI 排好了讲课顺序"）
6. 点 `开始讲课` → 进入**全屏演示页**（侧栏消失）
7. 按 `→` 翻 2～3 页，让画面动起来 — 每页停 1 s
8. （可选，很加分）点右下角浮动的 `问 AI 老师` → 提一句问题 → 看到**流式**回答 → 返回
9. 点 `退出演示` 回到编辑器

**⏱ 节奏**：这是**最长也最重要**的一段，85 秒不算多。第 4 步的等待不要空着（见"等待怎么处理"）。
**⚠️ 坑**
- 第 4 步依赖**第 3 段的模型**。没配模型这里会提示「未配置模型」。
- 编辑器里点 `添加环节` 会开一个字段很多的弹窗——**本段不要点**，会让节奏崩掉。
- 全屏演示页没有侧栏，**退出要走 `退出演示`**，别按 Esc 乱了（Esc 不一定退）。
- 翻页用键盘方向键，比点按钮干净。

```bash
DURATION=120 ./submission_docs/record_app.sh 7
```

---

### 第 8 段 · 学生（目标 35 s）

**🎯 主题**：学生账号**由教师创建**（学生不能自己注册）。

**🖱 操作**
1. 侧栏点 `学生` → 标题 `学生管理`，右上角有 `添加学生` / `下载导入模板` / `批量导入` — 停 1 s（顺带展示"能批量导入花名册"）
2. 点 `添加学生` → 表单：`学生昵称` → `登录账号` → `密码` → `年级` 下拉
3. 点 `创建学生账号` → 列表出现该学生（显示 `学号 xxx`、`无错题`）
4. 点这个学生行 → 进详情页（`概览` / `错题本` / `AI 答疑` 三页签）— 停 1 s
5. 返回列表

**⏱ 节奏**：表单四个字段，慢填。
**⚠️ 坑**
- 登录账号不能重复；密码至少 4 位。
- 详情页现在数据是空的（新学生），很正常，**别在这里解释"怎么没数据"**——数据要靠第 9 段产生。

```bash
DURATION=50 ./submission_docs/record_app.sh 8
```

---

### 第 9 段 · 任务 / 生成题目（目标 75 s）

**🎯 主题**：选知识点 → **AI 流式出题** → 人工审核 → 派发给学生。

**🖱 操作**
1. 侧栏点 `任务` → 标题 `任务`，空态 `还没有布置过任务` + 三步流程 — 停 1 s
2. 点 `发布任务` → 进 `布置练习任务` 页 — 停 1 s
3. 选**派发目标**：班级多选 / 学生多选 → 选第 8 段建的那个学生
4. `试卷标题` 默认 `今日练习`（不用改）→ `总题数` 填 **4**
5. 学科规格行：选 `学科` + `知识点`（选第 5 段的知识点）+ `题型`
6. 选**出题模型**（下拉里选第 3 段配的那个）
7. 点 `生成` → **题卡逐张浮现**（这是 **SSE 流式**，最出彩的画面）— 不要打断
8. 点 `确认` → 落库为草稿 → 自动进 `草稿审核` 页
9. 审核页顶栏 `草稿审核`：**快速扫一眼**（别逐题改）→ 点 `锁定并派发` → 提示「已派发，学生登录后即可在「今日任务」里练习」

**⏱ 节奏**：第 7 步的流式生成是全场高光，**让它自己跑**，你只需静静看着。第 9 步审核要**快**（红线就卡在这）。
**⚠️ 坑**
- 没选班级/学生会拦「请先选择要布置的班级或学生」。
- 知识点为空会拦——回第 5 段补。
- 生成中途有个进度条可以 `停止生成`，**别点**。
- 流式结束**不落库**，必须点 `确认` 才成为草稿——这步别漏。

**⭐ 本段收尾（关键，决定第 10 段有没有数据）**

派发完，回到 `任务` 列表的 `进行中` Tab → 点这个任务 → 点 `查看练习`（默认是只读预览）→ 点 `以学生身份代答` → **答 2 题（故意一题对、一题错）** → 结束。

这样就有了真实作答记录，「错题本」「掌握度」「学情分析」才不是空的。
> 如果不想代答，替代方案：退出教师账号 → 用第 8 段建的学生账号登录 → 首页「今日任务」答题 → 再切回教师账号。多花约 1 分钟，但学生端的画面也能顺便入镜。

```bash
DURATION=120 ./submission_docs/record_app.sh 9
```

### 第 10 段 · 概览（目标 45 s）

**🎯 主题**：**闭环收尾**——待办有事做、学情有图看。

**🖱 操作**
1. 侧栏点 `概览` → 页内标题是 `工作台`，右上显示 `N 名学生` — 停 1 s
   > 注意：侧栏叫「概览」，页里叫「工作台」，不是 bug。
2. 鼠标扫过 `待办` 三张卡（`待审核` / `待派发` / `谁没交`）— 停 1 s
3. 看 `最近任务` 区块 → 能看到刚派发的任务 — 停 1 s
4. 看 `学情速览`：掌握度环形、薄弱知识点、正确率、错题分布 — 停 2 s
5. 看 `学情分析`：把 `统计范围` 从 `全体学生` 切到 `单个班级`，维度点一下 `知识点` → 图表跟着变 — 停 2 s

**⏱ 节奏**：45 秒看着长，但四个图表 + 一次切换刚好。**别逐个图表讲解**，那是红线。
**⚠️ 坑**
- 如果这里全是「暂无数据」→ 说明第 9 段的代答**没做**，回第 9 段补录收尾。
- 待办计数可能是 0（如果任务已全部处理完），正常，不用解释。

```bash
DURATION=60 ./submission_docs/record_app.sh 10
```

## 4. 等待时间怎么处理（新手最容易在这里崩节奏）

录制过程中有 4 处会**真实卡住**，加起来能吃掉 1 分钟以上：

| 位置 | 大概等多久 | 怎么办 |
|---|---|---|
| 第 3 段 `测试连接` | 3～10 s | **保留**（这是"真的连上了"的证据），结果出来后停 1 s 再继续 |
| 第 5 段 `向量化` | 10 s～数分钟 | 后期**加速 2～4 倍**，或干脆剪掉中间，留"点击 → 已向量化"两端 |
| 第 7 段 `AI 补充讲解` | 5～20 s | 后期加速 2 倍；录制时可用旁白填（见下） |
| 第 9 段 `生成` 流式出题 | 15～40 s | **不要剪、不要加速**——流式逐题浮现本身就是亮点，让它自然跑完 |

**两个技巧**
- **旁白填空白**：等待时不要沉默也不要乱动鼠标，照着 `narration.md` 那句念（后期把旁白/字幕压上去）。
- **后期统一加速**：CapCut 里对等待片段用"变速 2x"，比重新录一遍省事得多。

## 5. 怎么判断某段录长了 / 录短了

录完一段，**先别看时长**，回答这几个问题：

| 信号 | 判断 | 处理 |
|---|---|---|
| 你在这段里**说了超过 3 句话** | 太长了 | 重录，只留 1～2 句 |
| 页面**停留超过 5 秒没动作** | 太长（除非在等生成） | 加速或剪掉 |
| 观众**看不清你点了哪个按钮** | 太赶了 | 重录，动作之间停 1 秒 |
| 一段里你**没让观众看到"结果"** | 缺收尾 | 补一个"停 1 秒看结果"的镜头 |

**时长兜底**：每段用速查表里的"红线"卡。超红线就重录，别指望后期能救——**剪辑能加速，不能补镜头**。

## 6. 录完之后（照顺序做）

```bash
cd submission_docs

# 1) 先看片子在不在、时长对不对（对着速查表核对）
ls -la raw/

# 2) 生成字幕并硬烧入 → out/out_01.mp4 … out_10.mp4
python gen_subs.py --burn

# 3) 烧入后合并 → final_demo.mp4
python gen_subs.py --burn --concat
```

- 某一段重录后，把新版 `demo_0N.mov` 覆盖回 `raw/`，重跑上面命令即可（只重烧变化的部分）。
- 想加中文配音（可选）：先让助手跑 `gen_voice.py` 生成 10 个 mp3，再按手册 §4 合成。
- 成片要加标题卡 / 片尾字幕，在 CapCut 里加，别在录制阶段加。

## 7. 与旧方案（7 段）的差异

| 项 | 旧 | 新 |
|---|---|---|
| 分段数 | 7 段 | **10 段**（按你给的功能顺序） |
| 顺序 | 痛点 → 模型 → 出题 → 答疑 → 学情 → 课堂练习 → 总结 | 注册 → 登录 → 模型 → 素材 → 资料 → 场景 → 课件 → 学生 → 任务 → 概览 |
| `narration.md` | 7 段 | **已同步改为 10 段**（`gen_voice.py` / `gen_subs.py` 会自动按段号适配，无需改脚本） |
| `voice/` 里的 mp3 | `seg01..07` | 目前只有 7 个，要配音的话需重新生成 10 个 |

> ⚠️ **务必先改 `narration.md` 再跑 `gen_subs.py`**——字幕脚本是按 `narration.md` 的段落数切片的。新旧段数不一致会出现"第 8 段视频配了第 7 段字幕"的错位。
