## 0. 先记住三句话

1. **总目标 5 分 52 秒，红线 6 分钟**。14 段合计 **352 秒**，其中配音 258 秒、动作余量 94 秒。
2. **动作跟着配音走**。旁白在念的时候你就要在点，**不要等念完再动手**——这是上一版最大的问题：目标写了 7 分 25 秒，配音实际只有 3 分 23 秒，中间空转 4 分钟。
3. **分段录，不要一口气录完**。`./submission_docs/record_app.sh 1` 到 `14`，一段一个文件。录坏哪段只重录哪段。

## 2. ⚠️ 录制前必须先搞懂的一件事：学生端用哪个账号

**「复习」这一段，全新学生必然是空的。** 后端规则是 `答错 → due_at = 当天 + 1 天`（`backend/app/domain/review_scheduler.py:31`），所以**今天建的号今天答题，复习队列要明天才有题**——你今天录，它只会显示「今天没有要复习的题」。

**解决办法（推荐）：学生端五段统一用你库里已有的学生 `lsc`（四年级）。**

- 它名下已经有 **4 道到期错题**（最近答错时间 10-06 ～ 10-08，都已到期），复习队列一登录就是满的。
- 第 8 段派发任务时**就派给它**，它首页的「今日任务」也就有内容了。
- 录之前建议把它的昵称从 `lsc` 改成更像学生的名字（如「小明」）——在 学生管理 → 点进该学生 → 编辑，纯粹为了上镜好看。

**录之前跑这条命令确认到期错题还在**（应输出 `4`）：

```bash
cd backend && sqlite3 app.db \
  "select count(*) from wrongquestion w join user u on u.id=w.student_id \
   where u.username='lsc' and w.graduated_at is null and w.due_at <= datetime('now');"
```

> 如果你更希望「用第 7 段新建的那个学生」演完整条线，那**复习段就得改成展示空态**（并解释「明天进入复习队列」）。二者只能选一个，我建议选前者。

## 3. 录制前准备（一次性，约 30 分钟）

### 3.1 必须准备的素材

| 用途   | 准备什么                              | 注意                          |
| ---- | --------------------------------- | --------------------------- |
| 模型管理 | **一个真实可用的 API Key**（DeepSeek 最省事） | 没有 Key，「测试连接」会变红，后面所有 AI 全崩 |
| 素材库  | **2～3 张图片**（几何图、教材插图、错题照片都行）      | 本作品不做平台预置                   |
| 资料库  | **1 份教材/试卷 PDF，1～3 页就够**          | ⚠️ 别用几十页的，向量化会等很久           |
| 学生端  | **学生 `lsc` 的登录密码**                | 不记得就重置/另建一个学生再手动造到期错题       |
| 注册   | **一个没用过的教师用户名**                   | 已存在的会报错重录                   |

### 3.2 环境检查（录之前跑一遍）

```bash
# 1) 后端起来
cd backend && uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

# 2) 前端起来（API_BASE 用局域网 IP，别用 127.0.0.1）
cd frontend && flutter run -d macos --dart-define=API_BASE=http://<本机局域网IP>:8000
```

- [ ] 窗口**摆好位置、调好大小**——建议 **≥1280×800**。⚠️ 窗口宽度 **≥700** 时学生端才会显示**左侧栏**（和教师端一样）；窄于 700 会变成底部 Tab 栏，画面会跳，尽量别让它切档
- [ ] 屏幕**干净**：关掉聊天窗口、关掉通知（勿扰模式）
- [ ] 终端已授权「屏幕录制」权限（系统设置 → 隐私与安全性 → 屏幕录制）
- [ ] 先空跑一次 `./submission_docs/record_app.sh 1`，随便录 5 秒 Ctrl-C，确认真能出片

## 4. 逐段脚本

> 每段格式：**🎯 主题** → **🖱 操作** → **⏱ 节奏** → **⚠️ 坑**  
> 录制命令统一为 `./submission_docs/record_app.sh <段号>`，建议加 `DURATION=` 兜底防手滑录太久。

### 第 1 段 · 注册与登录（目标 23 s）

**🎯 主题**：教师账号门槛极低——用户名、密码、昵称，三个字段开号，数据在本机。

**🖱 操作**

1. App 打开 → 登录页（品牌区「学生学习」）— 停 1 s
2. 点底部 `没有账号？注册教师账号` → 表单切成「注册」，出现第三个字段 `昵称` — 停 1 s
3. 依次填 `用户名` → `密码` → `昵称`（每填一个停半秒）
4. 点 `注册并进入` → 直接进教师端「工作台」
5. 侧栏底部 `我的` → `退出登录` → 确认 → 回到登录页
6. 填 `用户名` → `密码` → 点 `登录` → 回到「工作台」

**⏱ 节奏**：填字要**慢**，让观众看清三栏。注册成功后**紧接着就演一次退出+登录**，因为注册会自动登录，不退出就演不了登录。  
**⚠️ 坑**

- 密码至少 4 位，别用 3 位的被拦。
- 用**没用过的用户名**，否则弹错误提示要重录。

```bash
DURATION=40 ./submission_docs/record_app.sh 1
```

### 第 2 段 · 模型管理（目标 38 s）

**🎯 主题**：模型**由你手动添加**、能**测通**、能设默认——不是内置一堆看不见的模型。

**🖱 操作**

1. 侧栏点 `模型管理` → 页面标题 `AI 模型管理`，此时「我的模型」是空的 — 停 1 s
2. 点 `添加模型` → 弹窗出现 — 停 1 s
3. `服务商` 下拉选 **DeepSeek** → `Base URL` 自动带出
4. 填 `模型名`（如 `deepseek-chat`）→ 填 `API Key`
5. 点 `测试连接` → **等结果条变绿**（真实调用，约 3～10 s）
6. 打开 `设为默认模型` 开关 → 点 `保存`
7. 列表出现模型卡，带 `默认` 徽标 — 停 1 s 收尾

**⏱ 节奏**：这 11 秒余量基本都是**等测试连接**，是正常的、也是**要展示的**（证明真的连上了）。  
**⚠️ 坑**

- 不填 Key 就保存 → 列表会有个连不上的模型，后面 AI 全废。
- `测试连接` 失败就重来，别继续往下录（后面全依赖它）。
- 预设里还有通义千问 / 智谱 / 豆包 / Kimi / Ollama，**不用都点**。

```bash
DURATION=60 ./submission_docs/record_app.sh 2
```

### 第 3 段 · 素材库（目标 14 s）

**🎯 主题**：素材只收**你自己上传**的图片，不做平台预置。

**🖱 操作**

2. 点 `上传图片` → 从本地**一次选完** 2～3 张
3. 网格出现缩略图 — 停 1 s
4. 点其中一张 → 放大看原图 → 关闭

**⏱ 节奏**：**最短的一段，别加词**。上传是瞬时的，别在这等。  
**⚠️ 坑**：多选上传时一次选完，别来回开两次文件框（显得笨）。

```bash
DURATION=30 ./submission_docs/record_app.sh 3
```

### 第 4 段 · 资料库（目标 28 s）

**🎯 主题**：**传教材 → 向量化 → 自动提取知识点**，后面出题会参考它。

**🖱 操作**

1. 侧栏点 `资料库` → 标题 `资料库`，上方有 `资料` / `知识点管理` 两个分段 — 停 1 s
2. 点 `上传资料` → 选那份 PDF → 行出现，状态徽标先是 `未向量化`
3. 鼠标移到该行 → 点行内 `向量化` → **等状态变成已向量化**
4. 切到 `知识点管理` 分段 → 选好 `学科 / 年级 / 学期` 范围条
5. 知识点列表出现 → 勾选几个 → 点 `确认选中 (N)`
6. 停 1 s 收尾（这些知识点马上要在课件里用到）

**⏱ 节奏**：向量化的实时等待在后期**加速 2～4 倍**，或剪掉中间只留「点击 → 已向量化」两端。  
**⚠️ 坑**

- **务必用 1～3 页的小 PDF**。几十页的教材向量化能等好几分钟。
- 行内操作有 `向量化 / 重提取 / 移动 / 删除` 四个，**只点 `向量化`**。
- 这里没提取出知识点，**第 6 段课件就选不了知识点**——务必确认列表非空再往下。

```bash
DURATION=70 ./submission_docs/record_app.sh 4
```

### 第 6 段 · 课件与 AI 备课（目标 38 s）

**🎯 主题**：**零课件 → AI 起草 → 上讲台**，一条龙。

**🖱 操作**

1. 侧栏点 `课件` → 空态 `还没有课件` — 停 1 s
2. 点 `新增课件` → 弹窗：`知识点` 下拉选第 4 段提取的那个 → 点 `创建空课件`
3. 自动进入**课件编辑器**（本作品约定：**建空课件不触发 AI**，等你主动点）— 停 1 s
4. 点 `AI 补充讲解` → **等环节草案生成**（一次性返回，非流式，几秒～十几秒）
5. 环节列表出现 — 停 1.5 s（让观众看到"AI 排好了讲课顺序"）
6. 点 `开始讲课` → 进入**全屏演示页**（侧栏消失）
7. 按 `→` 翻 2～3 页 — 每页停 1 s
8. （很加分）点右下角浮动的 `问 AI 老师` → 提一句问题 → 看到**流式**回答 → 返回
9. 点 `退出演示` 回到编辑器

**⏱ 节奏**：这是**最长也最重要**的一段。第 4 步的等待后期加速 2 倍。  
**⚠️ 坑**

- 第 4 步依赖**第 2 段的模型**。没配模型这里会提示「未配置模型」。
- 编辑器里点 `添加环节` 会开一个字段很多的弹窗——**本段不要点**，节奏会崩。
- 全屏演示页没有侧栏，**退出要走 `退出演示`**，别按 Esc（不一定退）。

```bash
DURATION=90 ./submission_docs/record_app.sh 6
```

### 第 7 段 · 学生管理（目标 23 s）

**🖱 操作**

**⚠️ 坑**

### 第 8 段 · 布置任务与智能出题（目标 39 s）

**🎯 主题**：选知识点 → **AI 流式出题** → 人工审核 → 派发给学生。

**🖱 操作**

1. 侧栏点 `任务` → 空态 `还没有布置过任务` — 停 1 s
2. 点 `发布任务` → 进 `布置练习任务` 页 — 停 1 s
3. 选**派发目标**：**勾选学生 `lsc`**（⚠️ 必须派给它，否则第 9 段首页没任务）
4. `试卷标题` 默认 `今日练习`（不用改）→ `总题数` 填 **4**
5. 学科规格行：选 `学科` + `知识点`（选第 4 段的）+ `题型`
6. 选**出题模型**（下拉里选第 2 段配的那个）
7. 点 `生成` → **题卡逐张浮现**（**SSE 流式**，最出彩的画面）— 不要打断
8. 点 `确认` → 落库为草稿 → 自动进 `草稿审核` 页
9. 审核页**快速扫一眼**（别逐题改）→ 点 `锁定并派发`

**⏱ 节奏**：第 7 步流式生成是**全场高光**——**不要剪、不要加速**，让它自然跑完。第 9 步审核要**快**（红线就卡在这）。  
**⚠️ 坑**

- 没选学生会拦「请先选择要布置的班级或学生」。
- 知识点为空会拦——回第 4 段补。
- 生成中途有 `停止生成`，**别点**。
- 流式结束**不落库**，必须点 `确认` 才成为草稿。

```bash
DURATION=90 ./submission_docs/record_app.sh 8
```

### 第 9 段 · 学生登录与首页（目标 23 s）

**🎯 主题**：同一个登录入口，**按角色自动分端**；学生首页就是任务入口。

**🖱 操作**

1. 侧栏底部 `我的` → `退出登录` → 确认
2. 在**同一个登录页**填 `lsc` 的账号密码 → 点 `登录` — ⚠️ 登录页文案仍写「注册教师账号」，**不用理会**，学生是用教师建的号登录的
3. 自动落到学生端 **`首页`**；左侧栏变成 5 项：`首页` / `复习` / `错题本` / `问 AI 老师` / `掌握度` — 停 1.5 s（**这一步是全片唯一的"分端"证据，值得停够**）
4. 顶部 `复习错题` 横幅：显示出 `今天有 N 道题要复习` + `错题本` 按钮 + `去复习` 按钮 — 停 1 s
5. 往下 `问 AI 老师` 横幅：`去提问` 按钮 — 停 1 s
6. 再往下 `今日任务`：第 8 段派的那套题，卡上有学科色条、知识点、`N题`、`开始做题` — 停 1 s
7. 点 `开始做题` → 进答题页 → 做 **2 题，故意一题对、一题错** → 提交 → 出现「完成打卡」— 停 1 s

**⏱ 节奏**：第 3 步的分端、第 7 步的答题，都要**停够**再走。  
**⚠️ 坑**

- 学生端**没有 AI 浮球**（浮球是教师端专属），学生答疑走「问 AI 老师」页签——别在找浮球。
- 故意答错的那一题，就是第 11 段「错题本」的新素材。
- 如果 `今日任务` 是空的 → 第 8 段没派给 `lsc`，回去补录。

```bash
DURATION=60 ./submission_docs/record_app.sh 9
```

### 第 10 段 · 复习（目标 22 s）

**🎯 主题**：**遗忘曲线**排队——到期才出现，答对往后推，答错重新计时。

**🖱 操作**

1. 左侧栏点 `复习` → 顶栏 `复习 N/M`，出现第 1 道到期错题 — 停 1.5 s
2. 作答 → 点 `提交复习` → 结果弹窗：答对是「复习答对啦 / 下次 N 天后复习」，答错是「答错了，重新计时」— 停 1.5 s
3. 再走 1 题（让观众看清"逐题推进"）
4. 想收得更漂亮：一直做完 → 完成态「**复习完成！答对 N 题 · 正确率 X%**」— 停 2 s
5. （可选）点顶栏打印图标 → `打印今日复习卷`

**⏱ 节奏**：22 秒里**做 1～2 题就够**，重点是让「N/M」和结果弹窗看清。  
**⚠️ 坑**

- **这一段必须用 `lsc`**（见第 2 节）。全新学生这里一定是空态「今天没有要复习的题」。
- 别把 N 道全做完——会超红线。做 1～2 题然后退出即可。

```bash
DURATION=50 ./submission_docs/record_app.sh 10
```

### 第 11 段 · 错题本（目标 17 s）

**🎯 主题**：学生**自己看得到**的错题清单——错过几次、复习到第几阶段、什么时候再复习。

**🖱 操作**

1. 左侧栏点 `错题本` → 标题 `我的错题本` — 停 1 s
2. 鼠标顺着列表往下扫：卡片上有 `学科` / `知识点` / `错过 N 次` / `复习阶段 N`，以及 `最近答错` `下次复习` 两个日期 — 停 2 s（**让标签停够，这就是本段的全部信息量**）
3. 刚才第 9 段故意答错的那道题**就在列表里**，指一下 — 停 1 s

**⏱ 节奏**：**不要滚动太久**。停 2～3 秒扫一遍标签，够。  
**⚠️ 坑**

- 学生端错题本**没有「重做」按钮、没有「已掌握/已毕业」分区、也看不到标准答案**（防作弊）。这些都在**教师端**的学生详情里——别去找，找不到不是 bug。
- 空态是「还没有错题」，如果你看到它，说明第 9 段没答错题。

```bash
DURATION=35 ./submission_docs/record_app.sh 11
```

### 第 12 段 · 问 AI 老师（目标 23 s）

**🎯 主题**：学生端**独立答疑页**，流式回答，还支持语音提问。

**🖱 操作**

1. 左侧栏点 `问 AI 老师` → 页面标题 `问 AI 老师`，空态引导「有问题就问 AI 老师吧」— 停 1 s
2. 在输入框（占位「输入你的学习问题…」）里输入一个问题，例如「这道题的等量关系怎么找？」— 停 1 s
3. 点 `发送` → **回答逐字流出来**（SSE 流式）— 不要打断，看它写完 — 停 2 s
4. （很加分）点输入栏的 `按住 说话` → 松开 → 展示语音提问 — 停 2 s

**⏱ 节奏**：流式回答**就是本段的看点**，别急着往下点。  
**⚠️ 坑**

- 依赖第 2 段的模型；没配模型会直接失败。
- 它只答学习相关内容（空态原话「只讲学习内容，其他问题不回答哦」），**别问无关问题**——会得到拒答，画面不好看。

### 第 13 段 · 掌握度（目标 18 s）

**🎯 主题**：按知识点的**掌握分与等级**，一眼看出哪儿行、哪儿得补。

**⏱ 节奏**：和错题本一样，**扫一遍标签就够**。  
**⚠️ 坑**：空态是「你还没有作答记录」——看到它说明第 9 段没答题。

### 第 14 段 · 概览与学情闭环（目标 26 s）


**🎯 主题**：**闭环收尾**——学生刚答完，教师这边数据就有了。

**🖱 操作**

## 5. 等待时间怎么处理（新手最容易在这里崩节奏）

录制过程中有 5 处会**真实卡住**，加起来约 1 分钟：

| 位置              | 大概等多久    | 怎么办                                 |
| --------------- | -------- | ----------------------------------- |
| 第 2 段 `测试连接`    | 3～10 s   | **保留**（这是"真的连上了"的证据），出来后停 1 s 再继续   |
| 第 4 段 `向量化`     | 10 s～数分钟 | 后期**加速 2～4 倍**，或剪掉中间，留"点击 → 已向量化"两端 |
| 第 6 段 `AI 补充讲解` | 5～20 s   | 后期加速 2 倍                            |
| 第 8 段 `生成` 流式出题 | 15～40 s  | **不要剪、不要加速**——逐题浮现本身就是亮点            |
| 第 12 段 AI 回答流式  | 5～20 s   | 后期加速 2 倍；它是学生段唯一的"AI 活着"的证据         |

**两个技巧**

- **旁白填空白**：等待时不要沉默也不要乱动鼠标，照着 `narration.md` 那句念。
- **后期统一加速**：CapCut 里对等待片段用"变速 2x"，比重新录一遍省事得多。

## 6. 怎么判断某段录长了 / 录短了

录完一段，**先别看时长**，回答这几个问题：

| 信号                 | 判断         | 处理               |
| ------------------ | ---------- | ---------------- |
| 你在这段里**说了超过 3 句话** | 太长了        | 重录，只留 1～2 句      |
| 页面**停留超过 5 秒没动作**  | 太长（除非在等生成） | 加速或剪掉            |
| 观众**看不清你点了哪个按钮**   | 太赶了        | 重录，动作之间停 1 秒     |
| 一段里你**没让观众看到"结果"** | 缺收尾        | 补一个"停 1 秒看结果"的镜头 |

**时长兜底**：每段用速查表里的"红线"卡。超红线就重录，别指望后期能救——**剪辑能加速，不能补镜头**。

## 7. 录完之后（照顺序做）

```bash
cd submission_docs

# 1) 先看片子在不在（应为 demo_01..14）
ls -la raw/

# 2) 一条命令出成片：出字幕 + 变速贴合 + 烧字幕 + 铺配音 + 合并 → final_demo.mp4
python gen_subs.py --all

# （可选）先渲一段试看，满意再全量
python gen_subs.py --all --only 1
```

**不用再操心"配音比目标时长短"**：脚本量的是每段**实际**录屏与配音时长，把画面变速去贴合配音  
（视频长→加速、视频短→减速并定格补足），字幕时间轴直接就是配音时长。

- 某一段重录后，把新版 `demo_0N.mov` 覆盖回 `raw/`，重跑上面命令即可（全量 14 段约 20 秒）。
- 改过 `narration.md` 就必须**先重跑 `gen_voice.py`**（配音），再跑 `gen_subs.py`，否则声音与字幕对不上。
- 嫌某段画面太快/太慢：`python gen_subs.py --all --max-speed 4.0` 或 `--min-speed 1.0` 后重跑。
