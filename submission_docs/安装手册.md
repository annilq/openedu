# 安装手册：中小学错题复习智能体（OpenEdu）

> 这本手册写给**不从事编程工作**的老师。你只要照着步骤做，不需要理解原理。
> 手册里的"命令"指的是**在终端窗口里输入的一行字**，复制粘贴后按回车即可。

---

## 一、安装前，需要准备什么

| 需要 | 说明 |
|---|---|
| 一台电脑 | macOS / Windows / Linux 都可以，建议内存 8GB 以上 |
| 一个 AI 模型账号和密钥 | 推荐 **DeepSeek**（国产大模型）。注册后在官网申请密钥，是一串 `sk-` 开头的字符 |
| 运行环境（二选一） | 想**最简单**：装一个叫 Docker 的软件；想**分步手动装**：电脑上要有 Python 和 Flutter 运行环境 |

> 关于 AI 模型：本工具**不自带 AI 大脑**，需要你填入自己的账号才能出题、答疑。
> 这是收费服务，但按用量计费、非常便宜（几块钱能用很久）。密钥会加密保存在你自己的机器上。

---

## 二、第一步：解压源码压缩包

1. 把提供的**源代码压缩包**（`.zip`）解压到你想要的位置，比如桌面。
2. 解压后能看到几个文件夹，其中两个最重要：
   - **`backend`**——后台服务，负责出题、答疑、存数据；
   - **`frontend`**——界面，老师和学生看到的部分。

下面两种方式**选一种**即可，推荐**方式 A**。

---

## 三、方式 A：一键启动（推荐，最简单）

适合不想折腾环境的人。

1. 先在电脑上安装 **Docker**（官网下载安装包，一路下一步即可）。
2. 在解压出来的**总目录**里打开终端窗口。
3. 输入下面这行命令，按回车：

```bash
docker compose up --build
```

4. **等待**。第一次会自动下载所需组件，可能需要十几分钟，之后就快了。
5. 看到启动完成的提示后，就可以打开软件使用了。

- 所有数据都保存在**你自己的电脑**上，不会上传到任何外部服务器。
- 想停止运行，在终端窗口按 `Ctrl + C`。

---

## 四、方式 B：分步启动（不想装 Docker）

这种方式需要电脑上已经装好 **Python（3.14 或更高）** 和 **Flutter（3.5 或更高）** 运行环境。
如果没装过，建议请懂技术的同事协助，或直接改用**方式 A**。

### 第 1 步：启动"后台服务"

后台服务负责出题、答疑和存取数据。在终端里进入 `backend` 目录，依次执行：

```bash
cd backend
uv sync
uv run uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

- 第一行：进入后台服务目录。
- 第二行：自动装好它需要的零件。
- 第三行：启动服务。**这个窗口启动后不要关**，关掉服务就停了。

服务默认开在电脑的 **8000 号通道**（端口）。

### 第 2 步：启动"界面"

**另外开一个终端窗口**，进入 `frontend` 目录，依次执行：

```bash
cd frontend
flutter pub get
flutter run --dart-define=API_BASE=http://<本机IP>:8000
```

> ⚠️ 把 `<本机IP>` 换成**你电脑在局域网里的 IP 地址**。
> - 怎么查：macOS 在「系统设置 → 网络」里看；Windows 在命令行输入 `ipconfig` 查看。
> - **不要填 `127.0.0.1`**。填了的话，自己电脑能用，但用平板或别的设备连就会报"请求失败"。

---

## 五、两种方式都要做的一步：配置 AI 模型

软件打开后，还需要把你的 AI 账号接进来（**只需做一次**）：

1. 进入「**模型管理**」→ 点「**添加模型**」。
2. 服务商选 **DeepSeek**（网址会自动带出来，不用改）。
3. 填写：
   - 模型名：例如 `deepseek-chat`；
   - 密钥：你在 DeepSeek 官网申请的那串 `sk-` 开头的字符。
4. 点「**设为默认**」。

> 没配置时，出题和答疑会提示"未配置模型"。
> 想完全不上网：服务商改选 **Ollama**，网址填 `http://localhost:11434`（前提是电脑上已安装本地模型）。

更详细的功能操作，请看《使用手册》。

## 六、常见问题

**Q：输入命令后提示"找不到 flutter 命令"？**
Flutter 没装，或装了没把它的路径加入系统。装好后重新开一个终端窗口再试。

**Q：后台服务起不来？**
按顺序检查：
- Python 版本是不是 3.14 或更高；
- 依赖有没有装成功（第二步有没有报错）；
- 8000 号通道是不是被别的程序占用了（换一个端口数字试试）。

**Q：界面打开了，但 AI 不出结果？**
检查「模型管理」里是否已有**默认模型**，以及密钥是否有效、账户是否还有余额。

**Q：用平板或别的设备连不上？**
`API_BASE` 必须填电脑的**局域网 IP**，不能填 `127.0.0.1`。另外确保设备和电脑连的是同一个网络。

**Q：怎么停止运行？**
在终端窗口按 `Ctrl + C` 即可。

**Q：重装或换电脑怎么办？**
把源码压缩包重新解压，按同样步骤来一遍即可。数据文件也在目录里，可以一起拷贝带走。
