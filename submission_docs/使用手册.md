# 使用手册：中小学错题复习智能体（OpenEdu）

> 这本手册是写给**不使用编程技术**的老师看的。你不需要懂技术，照着点就行。
> 电脑怎么装、怎么启动，请看《安装手册》；本手册只讲**装好之后怎么用**。

---

## 一、这是什么

一套帮学生"把错题真正改对"的学习工具。**老师**用它出题、布置任务、看学情；**学生**用它答题、复习、问 AI 老师。

核心是一条学习闭环：

**老师出题 → 学生作答 → 答错的题进入错题本 → 隔几天自动提醒复习 → 真正做对后"毕业"**

复习提醒的节奏是 **第 1 天、第 2 天、第 4 天、第 7 天、第 15 天**。最后那次答对了，这道题就算真正掌握、自动毕业；已经毕业的题，老师也可以随时拉回来再练。

适用范围是**中小学 1–9 年级**（小学和初中），语文、数学、英语等学科都能用。

---

## 二、第一次使用，请先做这一件事：添加 AI 模型

> ⚠️ **这一步不做，出题、答疑这些 AI 功能都用不了**，界面会提示"未配置模型"。

本工具**不自带 AI 大脑**，需要你填入自己的 AI 账号。首次填一次即可，之后一直有效。

1. 打开软件，进入「**模型管理**」；
2. 点「添加模型」，服务商选 **DeepSeek**（国产大模型，便宜好用）；
3. 填入你在 DeepSeek 官网申请的密钥（一串 `sk-` 开头的字符）；
4. 把这个模型「**设为默认**」。

- 密钥会**加密保存在你自己的机器上**，别人拿不到。
- 想换模型（通义千问、智谱、豆包等）随时可换。
- 想完全不上网，也可以用电脑本地运行的模型（Ollama），配置方法见《安装手册》。

## 三、老师能做什么

| 功能 | 能帮你做什么 |
|---|---|
| 教师工作台 | 进软件就能看到的总览：待办、最近任务、学生人数，以及错题分布、正确率、掌握度 |
| 班级与学生管理 | 建班级、加学生，查看某个学生的错题本和 AI 答题记录 |
| 资料库与知识点 | 上传教材/卷子/笔记，系统自动整理出"知识点目录" |
| 课件与课堂 | 在一个知识点上组织讲解内容，用于课堂演示和练习 |
| 智能出题 | 说一句话就能出题，逐题审阅后再保存 |
| 题库 | 题目长期保存、反复复用、可归档，还能查某道题被哪些任务用过 |
| 任务派发 | 把题目布置给单个学生或整个班，看进度、正确率、连续打卡天数 |
| 错题本 | 看学生的错题（含答案与解析），把已掌握的错题拉回重练 |
| 打印导出 | 把题目排成纸质练习卷直接打印 |
| AI 学习助手 | 一个对话框搞定：出题、查任务、查学情、查题库、答疑 |
| 模型管理 | 管理你的 AI 模型账号 |

下面挑重点说明。

### 1. 智能出题

- 选学科、年级、知识点、题型、数量；也可以**直接说一句话**，比如"出 3 道三年级分数选择题"。
- 题目会**一条条边生成边显示**出来，你可以逐题查看。
- 满意后**确认保存**；中途可以**停止**（保留已经出的题）或**整份重来**。
- 每题都带题干、选项和解析。

### 2. 题库

题目会长期保存下来，以后出卷直接拿来复用；暂时不用的可以归档；还能反查"这道题被哪些任务用过"。

### 3. 任务派发

把一组题目组成"任务"，派给**一个学生**或者**整个班级**。之后能看每个学生的完成进度、正确率和连续打卡天数。

### 4. 资料库与知识点

上传教材、卷子、笔记等资料后，系统会**自动整理出知识点目录**，出题和答疑时就能对准考点。

知识点按"学科 × 年级"管理，上传教材后会自动联动，不需要手工一条条录。

### 5. 课件与课堂

在一个知识点上组织有序的讲解内容，可以放图片素材、交互演示，也可以加"课堂练习"，用于课堂演示。

**课堂练习**由**老师代学生**录"对 / 错"，AI 会给出分级别的提示。这个过程**不计入学生成绩、也不进错题本**，纯粹用于课堂互动。

### 6. 教师工作台

- **任务区**：待办事项、最近任务、学生总数。
- **学情速览**：错题分布、正确率、掌握度，一眼看清全班情况。
- **学情分析**：可以按学科、年级、学期、知识点逐层往细里看。

### 7. 打印导出

把题库 / 任务 / 错题排成纸质练习卷，系统自动排版。

> ⚠️ 卷子**只印题目和作答空位，不含答案**，可以直接发给学生做。

### 8. AI 学习助手

统一的对话入口。你可以直接问：

- "出 3 道四年级分数选择题"
- "小明最近错题多吗"
- "今天有什么作业"

助手会用规整的卡片回答（错题情况、掌握度、进度等）。

**所有数字都来自系统里的真实数据，不会凭空编造。** 聊天记录会保留，下次打开可以接着聊。

## 四、学生能做什么

| 功能 | 说明 |
|---|---|
| 今日任务 | 逐题作答，自动批改并看解析，做完打卡 |
| 到期复习 | 系统按遗忘规律，把该复习的题推到前面 |
| 错题本 | 看自己的错题（**不显示答案**，避免直接抄） |
| 问 AI 老师 | 随时提问，AI 给适合年龄的讲解，并标注来源 |
| 导出练习卷 | 导出自己的错题练习卷去打印 |

### "问 AI 老师"的几个特点

- 回答会**标注来源**（来自哪份资料、哪个知识点），方便核对。
- 遇到图形类知识点，会**先演示一遍交互图形**再讲步骤，更直观。
- 有**内容安全审核**：不适合中小学生的内容会拒绝回答并说明原因。

---

## 五、用大白话解释"间隔复习"

学生做错的题会自动进错题本。系统按 **1、2、4、7、15 天**的节奏提醒复习——就像背单词，隔一段时间再看一次，记得更牢。

最后那次答对了，这道题就"毕业"。老师如果觉得还需要巩固，可以把已毕业的题**重新拉回**复习队列。

## 六、常见问题

**Q：提示"未配置模型"？**
说明还没添加 AI 模型。按第二节，在「模型管理」里添加并设为默认。

**Q：AI 出题很慢？**
模型越大越慢。可以在「模型管理」换更快的型号（名字里带 flash 的通常更快）。

**Q：学生端看不到答案？**
这是**刻意设计**——学生的错题本不显示答案，避免直接抄；老师端可以看到答案和解析。

**Q：课堂练习会算进成绩吗？**
不会。课堂练习由老师代录，不落作答记录、不进错题本，只用于课堂互动。

**Q：数据存在哪里？**
全部存在**你自己的机器**（或你自己部署的服务器）上，不会上传到任何外部服务器。

**Q：能离线使用吗？**
可以，但需要提前在电脑上安装本地模型（Ollama）。详见《安装手册》。

**Q：想换一个 AI 模型？**
进「模型管理」添加新模型，再把它设为默认即可，原来的模型会保留。
